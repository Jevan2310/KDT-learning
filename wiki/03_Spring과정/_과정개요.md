# Spring과정 — Java Spring 학생 목록 API 만들기

> 과정: Spring과정 · [노션 원문](https://app.notion.com/p/414848f71c9b80aeaf8ce05d15cd9731) · 최종 갱신일: 2026-11-12

## 과정 소개
Java와 Spring Boot로 **학생 정보를 관리하는 서비스**를 만든다.
**Thymeleaf**로 서버에서 화면을 만들고, **H2 데이터베이스**에 학생 정보를 저장한다. 이후 같은 데이터를 **JSON API**로 제공해 React 화면에도 연결한다.

## 학습 목표
과정 페이지의 완료 체크 항목이다.
- Java로 학생 객체와 목록을 만든다.
- Spring Boot 서버를 실행한다.
- Thymeleaf로 학생 목록을 표시한다.
- 폼으로 학생을 등록한다.
- H2에 학생 정보를 저장하고 조회한다.
- 같은 학생 데이터를 JSON으로 응답한다.
- React에서 학생 목록을 표시한다.

## 완성할 서비스

| 화면 | 흐름 |
|---|---|
| Thymeleaf 화면 | 학생 등록 폼 → Spring에서 입력 처리 → H2 저장 → 학생 목록 HTML 표시 |
| React 화면 | React에서 요청 → Spring에서 H2 조회 → JSON 응답 → React에서 목록 표시 |

| 요청 | 역할 | 배우는 회차 |
|---|---|---|
| `GET /hello` | 인사 문장 | [02](02_SpringBoot시작.md) |
| `GET /students` | Thymeleaf 학생 목록·등록 폼 | [03](03_Thymeleaf-학생목록.md) · [04](04_폼-학생등록.md) |
| `POST /students` | 학생 등록 | [04](04_폼-학생등록.md) |
| `GET /api/students` | 학생 목록 JSON | 06장 (예정) |
