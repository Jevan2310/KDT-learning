# 000. Spring 세팅부터 데이터 입력까지 — 02~04를 코드 하나로 복습

> 과정: Spring과정 · [노션 원문](https://app.notion.com/p/417848f71c9b8088b4ecddc95d3558bf) · 최종 갱신일: 2026-11-19

## 한눈에 보기
- 새 프로젝트(`www`) 하나로 **[02](02_SpringBoot시작.md)~[04](04_폼-학생등록.md)의 흐름을 짧게 다시 만든** 페이지다. 설명 없이 폴더 구조·컨트롤러·HTML 코드만 있다.
- **`GET /`** → `MainController.index()`가 이름 목록을 `Model`에 담고 `"index"`를 반환 → `templates/index.html`이 목록을 표시한다.
- HTML에서 `th:if`/`th:unless` + `#lists.isEmpty`로 **목록이 비었을 때와 있을 때**를 나누고, `th:each`로 이름을 하나씩 `<li>`에 넣는다.
- 폼(`th:action="@{/insert}" method="post"`)의 `<input name="hello">` 값을 **`POST /insert`** 메서드의 매개변수 `String hello`로 받아 목록에 추가하고 **`redirect:/`** 로 목록 화면으로 돌아간다.
- 목록은 컨트롤러 필드의 `List<String>`(메모리)이라 서버를 재시작하면 생성자의 초기 이름 3개만 남는다. 이 `www` 프로젝트를 [05](05_H2-JPA저장.md)·[06](06_JSON-API-React연결.md) 수업 코드에서 이어 쓴다.

> 💡 보충: 이 회차의 패키지는 `com.example.www`, 실행 클래스는 `WwwApplication`이다 (02~04 수업 화면의 `com.example.kdt`와 다른 새 프로젝트). 내 프로젝트 패키지에 맞춰 `package` 줄을 고친다.

## 학습 목표
강의에 학습 목표가 따로 없어 코드에서 정리했다.
- 새 Spring Boot 프로젝트에 `controller` 패키지와 `templates` HTML을 만든다.
- `@Controller` + `@GetMapping("/")`으로 HTML 화면을 응답한다.
- `Model`로 목록을 넘기고 Thymeleaf로 조건·반복 표시한다.
- 폼으로 입력값을 POST로 보내고 `@PostMapping`으로 받는다.
- 등록 후 `redirect:/`로 목록 화면으로 돌아간다.

## 핵심 개념

> 💡 보충: 이 회차는 코드만 있는 페이지다. 아래 설명은 [02](02_SpringBoot시작.md)~[04](04_폼-학생등록.md)에서 배운 내용을 이 코드에 맞춰 정리한 것이다.

### 1. 프로젝트 구성
수업 화면(IntelliJ)의 폴더 구조를 옮겼다.

```text
src/main/
├─ java/com.example.www/
│  ├─ controller/
│  │  └─ MainController.java
│  └─ WwwApplication.java      ← 실행 클래스 (main)
└─ resources/
   ├─ static/
   └─ templates/
      └─ index.html
```

- 컨트롤러는 **실행 클래스와 같은 패키지 또는 그 하위 패키지**(`controller`)에 둔다 ([02](02_SpringBoot시작.md)).
- HTML 템플릿은 `resources/templates/`에 둔다 ([03](03_Thymeleaf-학생목록.md)).

### 2. `@Controller` — 반환한 문자열 = HTML 이름

```java
@Controller // -> 문자열에 들어가 있는 HTML 이름을 찾아서 해당 HTML을 반환한다.
public class MainController {
```

- `return "index";` → `templates/index.html`을 찾아 화면으로 응답한다.
- `@RestController`였다면 `index`라는 **글자**가 그대로 응답된다 ([03](03_Thymeleaf-학생목록.md)).

### 3. 필드 목록과 생성자 초기 데이터

```java
List<String> nameList = new ArrayList<>();

public MainController() {
    nameList.add("한코딩");
    nameList.add("파이썬");
    nameList.add("자바");
}
```

- 목록이 **컨트롤러 필드**라서 요청 사이에 유지된다. 생성자는 Spring이 컨트롤러 객체를 만들 때 한 번 실행된다 ([04](04_폼-학생등록.md) 3장).
- 04는 `Student` 객체 목록이었고, 여기서는 **이름 문자열만** 담는 `List<String>`이다.

### 4. `GET /` — Model로 목록 전달

```java
@GetMapping("/")
public String index(Model model) {

    model.addAttribute("list", nameList);

    return "index";
}
```

- `@GetMapping("/")`은 `http://localhost:8080/` (주소 맨 끝 `/`) 요청을 처리한다.
- `"list"`라는 이름으로 넘겼으므로 HTML에서는 `${list}`로 읽는다.

### 5. Thymeleaf — 비었을 때와 있을 때

```html
<div th:if="${#lists.isEmpty(list)}">학생이 존재하지 않습니다.</div>
<ul th:unless="${#lists.isEmpty(list)}">
    <li th:each="name : ${list}" th:text="${name}"></li>
</ul>
```

| 속성 | 하는 일 |
|---|---|
| `th:if="${#lists.isEmpty(list)}"` | 목록이 **비었을 때만** 안내 문구 표시 |
| `th:unless="${#lists.isEmpty(list)}"` | 목록이 **비어 있지 않을 때만** `<ul>` 표시 |
| `th:each="name : ${list}"` | 목록의 이름마다 `<li>`를 하나씩 만든다 |
| `th:text="${name}"` | `<li>` 안의 글자를 이름으로 채운다 |

### 6. 폼 → `@PostMapping("/insert")`

```html
<form th:action="@{/insert}" method="post">
    이름 <input name="hello" />
    <button type="submit">전송</button>
</form>
```

```java
@PostMapping("/insert")
public String nameInsert(String hello) {
    nameList.add(hello);
    return "redirect:/";
}
```

| HTML | Java |
|---|---|
| `th:action="@{/insert}"` + `method="post"` | `@PostMapping("/insert")` |
| `<input name="hello" />` | 매개변수 `String hello` |

- 입력창의 **`name`과 매개변수 이름이 같아서** 입력값이 `hello`에 들어간다.

> 💡 보충: `@RequestParam`을 생략해도 **매개변수 이름과 같은 이름의 요청 값**을 받는다. Spring Boot 빌드 설정이 컴파일할 때 매개변수 이름을 남겨 두기 때문이다. 받을 이름을 분명히 하려면 04처럼 `@RequestParam(name = "hello") String hello`로 쓴다.

### 7. `redirect:/`
등록한 뒤 `"redirect:/"`를 반환하면 브라우저가 **`GET /`를 다시 요청**해 갱신된 목록을 받는다. 새로고침해도 POST가 다시 전송되지 않는다 ([04](04_폼-학생등록.md) 6장).

```text
이름 입력 → 전송
    ↓
POST /insert → nameList.add(hello)
    ↓
redirect:/ 응답
    ↓
브라우저가 GET / 요청 → index.html에 목록 표시
```

## 실습 정리

### 만든 것
이름 목록이 보이는 메인 페이지(`/`, 제목 "오늘은 금요일입니다")와, 아래 폼에서 이름을 입력해 **전송하면 목록 끝에 추가**되는 기능.

### 만드는 순서 (코드 기준)
1. 새 Spring Boot 프로젝트 `www` (Spring Web + Thymeleaf, [02](02_SpringBoot시작.md) 방식)
2. `com.example.www.controller` 패키지에 `MainController` 클래스 작성
3. `resources/templates/index.html` 작성
4. `WwwApplication` 실행 → `http://localhost:8080/` 접속

### 최종 코드

**`com/example/www/controller/MainController.java`**

```java
package com.example.www.controller;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;

import java.util.ArrayList;
import java.util.List;

@Controller // -> 문자열에 들어가 있는 HTML 이름을 찾아서 해당 HTML을 반환한다.
public class MainController {

    List<String> nameList = new ArrayList<>();

    public MainController() {
        nameList.add("한코딩");
        nameList.add("파이썬");
        nameList.add("자바");
    }

    @GetMapping("/")
    public String index(Model model) {

        model.addAttribute("list", nameList);

        return "index";
    }

    @PostMapping("/insert")
    public String nameInsert(String hello) {
        nameList.add(hello);
        return "redirect:/";
    }
}

```

**`resources/templates/index.html`**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>메인 페이지</title>
</head>
<body>
<h1>오늘은 금요일입니다</h1>
<div th:if="${#lists.isEmpty(list)}">학생이 존재하지 않습니다.</div>
<ul th:unless="${#lists.isEmpty(list)}">
    <li th:each="name : ${list}" th:text="${name}"></li>
</ul>

<form th:action="@{/insert}" method="post">
    이름 <input name="hello" />
    <button type="submit">전송</button>
</form>
</body>
</html>
```

> 💡 보충: `nameInsert`에는 빈 값 검사가 없어서 **빈 이름도 목록에 추가**된다. 04처럼 `trim()` + `isEmpty()`로 검사하면 막을 수 있다. `<html>`에 `xmlns:th="http://www.thymeleaf.org"`가 없어도 `th:` 속성은 동작한다 (이 선언은 IntelliJ 자동 완성·경고용).

## 헷갈리기 쉬운 점

> 💡 보충: 강의에 주의사항이 없어 02~04 내용을 이 코드에 맞춰 정리했다.

- **`<input name="hello">` ↔ 매개변수 `String hello`** 이름이 같아야 값이 들어온다. 다르면 `null`이 들어간다.
- **`th:action="@{/insert}"`와 `@PostMapping("/insert")`의 경로가 같아야** 한다.
- **주소창에 `/insert`를 입력하면 GET 요청**이라 405 오류가 난다. 등록은 폼 전송으로 확인한다.
- **`@RestController`로 바꾸면 `"index"`, `"redirect:/"`가 글자로 보인다.** HTML 화면은 `@Controller`.
- **`th:if`/`th:unless`는 둘 중 하나만 보인다.** 같은 조건 `${#lists.isEmpty(list)}`를 반대로 쓴다.
- **목록은 메모리에 있다.** 서버를 재시작하면 추가한 이름이 사라진다 (DB 저장은 [05](05_H2-JPA저장.md)).

## 빠른 참고 (치트시트)

| 하고 싶은 것 | 쓰는 것 | 예시 |
|---|---|---|
| HTML 화면 응답 | `@Controller` + 템플릿 이름 반환 | `return "index";` → `templates/index.html` |
| 메인 주소 처리 | `@GetMapping("/")` | `public String index(Model model)` |
| 화면에 목록 넘기기 | `Model` | `model.addAttribute("list", nameList);` |
| 비었을 때 안내 | `th:if` + `#lists.isEmpty` | `<div th:if="${#lists.isEmpty(list)}">…</div>` |
| 목록 반복 | `th:each` + `th:text` | `<li th:each="name : ${list}" th:text="${name}"></li>` |
| POST 폼 | `th:action` + `method="post"` | `<form th:action="@{/insert}" method="post">` |
| 입력값 받기 | 입력창 `name` = 매개변수 이름 | `<input name="hello" />` ↔ `String hello` |
| 등록 후 목록으로 | `redirect:` | `return "redirect:/";` |

## 확인 문제
강의에 확인 문제가 없어 코드에서 뽑았다.

<details><summary>Q. `GET /` 요청이 오면 어떤 순서로 화면이 만들어지는가?</summary>

`index(Model model)`이 실행되어 `nameList`를 `"list"`라는 이름으로 Model에 담고 `"index"`를 반환한다. `@Controller`라서 `templates/index.html`을 찾아, `${list}`로 목록을 채운 HTML을 응답한다.
</details>

<details><summary>Q. 폼에 이름을 입력하고 전송하면 값이 어떻게 `nameInsert`에 들어가는가?</summary>

폼이 `POST /insert`로 `hello=입력값`을 보낸다. `@PostMapping("/insert")` 메서드의 매개변수 이름이 `hello`라서 그 값이 들어간다 (입력창 `name`과 매개변수 이름이 같아야 한다).
</details>

<details><summary>Q. `nameInsert`가 `"index"`가 아니라 `"redirect:/"`를 반환하는 이유는?</summary>

브라우저가 `GET /`를 새로 요청하게 해서 갱신된 목록을 보여주고, 새로고침해도 POST(등록)가 다시 전송되지 않게 하려고. `"index"`를 반환하면 Model에 `list`가 없어 빈 목록 안내가 나온다.
</details>

<details><summary>Q. 목록이 비었을 때와 있을 때 HTML에서 무엇이 보이는가?</summary>

비었으면 `th:if="${#lists.isEmpty(list)}"`인 `<div>` "학생이 존재하지 않습니다."가, 있으면 `th:unless`인 `<ul>`이 보이고 `th:each`로 이름마다 `<li>`가 만들어진다.
</details>

<details><summary>Q. 서버를 재시작하면 목록은 어떻게 되는가? 왜?</summary>

추가한 이름은 사라지고 생성자의 "한코딩·파이썬·자바"만 남는다. 목록이 컨트롤러 객체의 필드(메모리)에 있기 때문이다.
</details>
