# 02. 콘솔 학생 관리 프로그램 만들기

> 과정: Node과정 · [노션 원문](https://app.notion.com/p/412848f71c9b807da9ebe905f06e3e56) · 최종 갱신일: 2026-11-12

## 한눈에 보기
- 터미널에서 **사용자 입력을 받는** 콘솔 프로그램을 만들었다. `npm init -y`로 프로젝트를 만들고 `npm install readline-sync`로 입력 패키지를 설치한 뒤, `require()`로 불러와 `readline.question()`으로 입력받는다. **입력 결과는 문자열**이다.
- 메뉴(1 등록 · 2 목록 · 3 삭제 · 0 종료)를 `while (true)`로 반복하고 `if / else if`로 기능을 나눈다. 종료는 `break`.
- 학생 이름은 배열에 `push()`로 저장하고(최대 3명), `for`문으로 `번호: 이름`을 출력한다. 삭제는 **번호 → `Number()` → 인덱스(`번호 - 1`) → `splice(인덱스, 1)`**.
- 입력값은 그대로 믿지 않고 검사한다 (`trim()`으로 빈 이름, 정수·범위로 삭제 번호).
- 마지막에 기능을 함수(`printMenu`, `createStudent`, `printStudents`, `deleteStudent`)로 나눴다. 프로그램을 끝내면 배열은 사라진다. **입력 → 검사 → 처리 → 출력** 흐름은 다음 회차 서버의 **요청 → 검사 → 처리 → 응답**과 같다.

## 학습 목표
- 입력 패키지를 설치하고 사용한다.
- 입력값을 변수와 배열에 저장한다.
- 반복문으로 입력과 메뉴를 반복한다.
- 조건문으로 선택한 기능을 실행한다.
- 번호를 검사하고 학생을 삭제한다.

프로그램 실행 예시:

```text
[메뉴]
1. 학생 등록
2. 학생 목록
3. 학생 삭제
0. 프로그램 종료
메뉴 선택:
```

## 핵심 개념

### 1. 사용자 입력은 어떻게 받을까? — `readline-sync`
지금까지는 코드에 직접 쓴 값을 사용했다.

```javascript
const name = "한코딩";

console.log(name);
```

이번에는 프로그램 실행 중에 사용자가 이름을 입력한다.

| 구분 | 역할 |
|---|---|
| 출력 | 프로그램이 사용자에게 정보를 보여줌 |
| 입력 | 사용자가 프로그램에 정보를 전달 |

- Node.js에도 기본 입력 기능이 있지만, 입력 코드를 단순하게 쓰려고 **외부 패키지 `readline-sync`** 를 쓴다. 👉 [패키지 사용 안내](https://github.com/anseki/readline-sync)
- 이 패키지는 **사용자가 입력하고 Enter를 누르면 결과를 반환한 뒤 다음 코드로 진행**한다.
- `sync`는 '동기식'이라는 뜻으로 **패키지 이름의 일부**다. Node.js 입력에 꼭 필요한 키워드가 아니다.
- 이번 실습에서는 `async/await`를 쓰지 않는다 (`rl.close()`도 필요 없다).

### 2. `require()`와 `question()`

```javascript
const readline = require("readline-sync");
```

- 설치한 패키지를 가져와 `readline`이라는 이름으로 쓴다. `readline`은 **직접 정한 변수 이름**이다.
- `require()`는 이번 프로젝트에서 **모듈을 가져오는 방법**이다.

```javascript
const name = readline.question("학생 이름: ");
```

- 질문을 보여주고, 입력받은 **문자열**을 `name`에 저장한다. Enter를 누를 때까지 기다린다.
- **터미널 입력을 기다리는 콘솔 실습용이다. HTTP 서버의 요청 처리 안에서 사용자 입력을 기다리는 용도로 쓰지 않는다.**

> 💡 보충: React에서 쓴 `import … from …`도 모듈을 가져오는 방법이다. 이번 Node 프로젝트는 `require()`를 쓰므로, `package.json`에 `"type": "module"`이 있으면 `require is not defined` 오류가 난다.

### 3. 배열에 저장하기 — `push()`
여러 이름을 관리하려면 배열을 쓴다. 배열 끝에 항목을 추가할 때는 `push()`.

```javascript
const students = [];
```

```javascript
students.push("한코딩");
students.push("이학생");

console.log(students);
```

**const 배열도 수정할 수 있을까?** `const`는 변수에 **다른 값을 재대입**하지 못하게 할 뿐, 배열 내부 변경까지 막지는 않는다.

```javascript
const students = [];

students.push("한코딩"); // 가능
```

```javascript
students = []; // 오류: 다른 배열을 재대입
```

**이번에는 일반 배열이므로 직접 변경해도 된다. React state 배열을 직접 변경하면 안 된다는 규칙과 구분한다** ([08_폼-배열state-할일앱](../01_React과정/08_폼-배열state-할일앱.md) 5장).

### 4. 반복문 — `for`와 `while`
같은 입력 코드를 여러 번 쓰는 대신 반복문을 쓴다.

```javascript
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

| 부분 | 역할 |
|---|---|
| `let i = 0` | 반복에 쓸 변수 생성 |
| `i < 3` | 반복을 계속할 조건 |
| `i++` | 한 번 실행한 뒤 값을 1 증가 |
| `{ }` | 반복할 코드 |

`i`는 `0`, `1`, `2`로 변하며 세 번 실행된다.

**정해진 횟수가 아니라 조건이 참인 동안** 반복할 때는 `while`을 쓴다 (예: 유효한 이름이 세 개 모일 때까지).

```javascript
while (조건) {
  // 조건이 참인 동안 반복
}
```

**`while (true)`와 `break`** — `true`는 항상 참이라 메뉴를 계속 반복한다. 종료 메뉴에서 `break`를 만나면 반복문을 빠져나오고, 그 뒤에 실행할 코드가 없으면 프로그램이 끝난다.

> 💡 보충: 수업 코드의 `continue`는 이번 반복의 나머지를 건너뛰고 **다시 메뉴 출력으로** 돌아간다. `break`는 반복문 자체를 끝낸다 ([03_JavaScript](../01_React과정/03_JavaScript.md) 7장).

### 5. 빈 이름은 등록하지 않기 — `trim()`
입력값은 그대로 믿지 말고 필요한 조건을 검사한다.

```javascript
const name = readline.question("학생 이름: ").trim();
```

`trim()`은 문자열 **양끝의 공백을 제거**한다.

```javascript
"  한코딩  ".trim() // "한코딩"
"   ".trim()       // ""
```

강의의 처리 흐름:
1. 학생이 세 명보다 적으면 입력받는다.
2. **빈 이름이면 안내만 출력한다.**
3. **유효한 이름이면 배열에 추가한다.**
4. 세 명이 되면 더 이상 추가하지 못하게 `if`문으로 막는다.

빈 입력은 배열에 추가되지 않으므로 학생 수도 늘지 않는다.

> 💡 보충: 수업 코드(아래 실습 정리)에는 `trim()`과 빈 이름 검사가 빠져 있어, Enter만 눌러도 빈 이름이 등록된다. 등록 부분을 다음처럼 바꾸면 강의 설명대로 동작한다.
> ```javascript
> const name = readline.question("input name:").trim();
>
> if (name === "") {
>     console.log("이름을 입력해주세요.");
>     continue; // 함수로 나눈 최종 코드 ②에서는 return;
> }
> ```

### 6. 목록을 번호와 함께 출력하기
배열을 통째로 찍는 대신 학생을 한 줄씩 표시한다.

```javascript
for (let i = 0; i < students.length; i++) {
    console.log(`${i + 1}번: ${students[i]}`)
}
```

| 코드 | 뜻 |
|---|---|
| `students.length` | 학생 수 |
| `students[i]` | 해당 위치의 이름 |
| `i + 1` | 사용자에게 보여줄 번호 (인덱스는 0부터, 번호는 1부터) |

강의는 목록 출력을 **함수**로 만들었다. 함수의 `students`는 호출할 때 전달받는 **매개변수**다. `"\n"`은 줄바꿈 문자다.

```javascript
function printStudents(students) {
  console.log("\n[학생 목록]");

  if (students.length === 0) {
    console.log("등록된 학생이 없습니다.");
    return;
  }

  for (let i = 0; i < students.length; i++) {
    console.log(`${i + 1}. ${students[i]}`);
  }
}
```

```javascript
printStudents(students);
```

결과 예시:

```text
[학생 목록]
1. 한코딩
2. 이학생
3. 박학생
```

### 7. 메뉴를 반복해서 표시하기 — 입력은 문자열
강의 본문의 메뉴 코드 (등록을 먼저 끝낸 뒤 1 목록 · 2 삭제 · 3 종료):

```javascript
while (true) {
  console.log("\n[메뉴]");
  console.log("1. 학생 목록");
  console.log("2. 학생 삭제");
  console.log("3. 프로그램 종료");

  const menu = readline.question("메뉴 선택: ").trim();

  if (menu === "1") {
    printStudents(students);
  } else if (menu === "2") {
    console.log("삭제 기능을 준비하고 있습니다.");
  } else if (menu === "3") {
    console.log("프로그램을 종료합니다.");
    break;
  } else {
    console.log("1~3 중에서 선택해주세요.");
  }
}
```

**`question()`의 결과는 문자열**이다. 그래서 숫자 `1`이 아니라 **문자열 `"1"`** 과 비교한다.

```javascript
menu === "1"
```

수업 최종 코드는 `cmd == 1`처럼 `==`로 비교했고, 코드 주석으로 차이를 정리했다.

```javascript
// == 안에 있는 값만 보고 동일 여부를 확인함 1 == "1" -> true
// === 안에 있는 값과 타입도 동일 여부를 확인함 1 === "1" -> false
```

### 8. 번호로 학생 삭제하기 — `Number()`와 `splice()`
이름이 같은 학생도 있을 수 있으므로 **현재 목록의 번호**로 고른다.

```text
1. 한코딩
2. 이학생
3. 박학생

삭제할 학생 번호: 2
```

**① 문자열 → 숫자: `Number()`** — 숫자로 바꿀 수 없는 문자열은 `NaN`(Not a Number)이 된다.

```javascript
// "1" -> 1
// "Hello" -> 안 됨 ->  NaN (Not a Number)
const answer = readline.question("삭제할 학생 번호: "); 
const number = Number(answer);
```

**② 목록 번호 → 배열 인덱스: `번호 - 1`**

| 목록 번호 | 배열 인덱스 |
|---|---|
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |

```javascript
const index = number - 1;
```

**③ 삭제: `splice()`** — `index` 위치에서 항목 1개를 지운다. **원본 배열이 바뀐다.**

```javascript
students.splice(index, 1);
```

강의 본문의 삭제 코드 (7장 메뉴의 `"2"` 처리 내용을 교체):

```javascript
if (students.length === 0) {
  console.log("삭제할 학생이 없습니다.");
} else {
  printStudents(students);

  const answer = readline.question("삭제할 학생 번호: ");
  const number = Number(answer);

  if (number < 1 || number > students.length) {
    console.log("목록에 있는 번호를 입력해주세요.");
  } else {
    const index = number - 1;
    const deletedName = students[index];

    students.splice(index, 1);

    console.log(`${deletedName} 학생을 삭제했습니다.`);
  }
}
```

**입력 조건 읽기**

| 조건 | 의미 |
|---|---|
| `!Number.isInteger(number)` | 정수가 아님 |
| `number < 1` | 첫 번째 번호보다 작음 |
| `number > students.length` | 목록 범위를 벗어남 |

- `!`: 참·거짓 반전 / `||`: 또는 — 하나라도 참이면 전체 조건이 참
- 잘못된 번호는 삭제하지 않고 안내한다.
- **삭제 후 목록 번호는 다시 매겨진다. 이 번호는 영구 ID가 아니라 현재 배열 위치다.**

> 💡 보충: 강의 표에는 `!Number.isInteger(number)`가 있지만 위 코드의 `if`에는 빠져 있다. 그래서 `abc`(→ `NaN`)나 `1.5`를 입력하면 검사를 통과해 "undefined 학생을 삭제했습니다."가 나오고 **첫 번째 학생이 지워진다** (`NaN`과의 비교는 항상 `false`, `splice`는 `NaN`·`0.5`를 `0`으로 처리). 표대로 세 조건을 모두 넣는다.
> ```javascript
> if (!Number.isInteger(number) || number < 1 || number > students.length) {
> ```

### 9. 프로그램 종료 후 데이터는 어떻게 될까?
학생 목록은 **실행 중인 프로그램의 메모리**에 있다. 종료하고 다시 실행하면 **새 빈 배열에서 시작**한다. 파일이나 데이터베이스에 저장하는 기능은 아직 없다.

이번에 연습한 흐름: **입력 → 검사 → 데이터 처리 → 결과 출력**

| 콘솔 프로그램 | 서버 프로그램 ([03_서버-데이터보내기](03_서버-데이터보내기.md)) |
|---|---|
| 터미널 입력 | 클라이언트 요청 |
| 메뉴와 입력값 검사 | 요청과 전달 데이터 검사 |
| 배열 조회·삭제 | 서비스 데이터 조회·삭제 |
| 터미널 출력 | 클라이언트에 응답 |

### 정리

| 개념 | 역할 |
|---|---|
| `readline-sync` | 입력 후 다음 코드로 진행하는 콘솔 입력 패키지 |
| `require()` | 모듈 가져오기 |
| `question()` | 질문을 출력하고 **문자열**로 입력받기 |
| `push()` | 배열 끝에 항목 추가 |
| `for`·`while` | 조건에 따라 반복 |
| `trim()` | 문자열 양끝 공백 제거 |
| `Number()` | 숫자로 변환 (안 되면 `NaN`) |
| `Number.isInteger()` | 정수인지 확인 |
| `splice()` | 배열의 지정 위치에서 항목 삭제·변경 |
| `break` | 반복문 종료 |

### 프로젝트 준비
`student-manager` 폴더를 만들고 VS Code로 연다.

```text
학습 폴더
├─ my-profile-react
├─ node-basic
└─ student-manager
```

VS Code 터미널에서 프로젝트 정보를 만들고 입력 패키지를 설치한다.

```bash
npm init -y
```

- `npm init`: `package.json` 생성 / `-y`: 기본값으로 진행

```bash
npm install readline-sync
```

같은 폴더에 `students.js`를 만든다. 수업 화면(VS Code 탐색기)도 같은 구조였다.

```text
student-manager
├─ node_modules/
├─ package.json
├─ package-lock.json
└─ students.js
```

| 파일·폴더 | 역할 |
|---|---|
| `node_modules` | 설치한 패키지 파일 |
| `package.json` | 프로젝트와 설치 패키지 정보 |
| `package-lock.json` | 설치한 패키지 버전 정보 |
| `students.js` | 직접 작성할 프로그램 |

**설치는 프로젝트를 준비할 때 한 번만** 한다. 실행할 때마다 다시 설치하지 않는다. 실행은 언제나:

```bash
node students.js
```

### 단계 흐름
> 💡 보충: 강의 본문(5~9장)은 "이름 세 명을 먼저 입력받고 → 1 목록 · 2 삭제 · 3 종료 메뉴"로 설계되어 있다. 수업에서는 처음부터 **"1 등록 · 2 목록 · 3 삭제 · 0 종료" 메뉴 하나**로 바꿔 진행했고, 최종 코드도 수업 방식이다. 개념(`while (true)`·`break`, `for` 출력, `Number`, `splice`, 함수)은 같다.

1. 이름 한 명 입력받기 (`require` + `question`)
2. 메뉴 뼈대: `while (true)` 안에 메뉴 출력 + `if / else if` 분기
3. 1번 등록: `push()`로 배열에 추가 → `count`로 3명 제한, 0번 종료에 `break`
4. 2번 목록: 0명이면 안내, 아니면 `for`로 `번호: 이름` 출력
5. 3번 삭제: 번호 입력 → 인덱스 계산 → `splice` → 최종 코드 ①
6. 기능을 함수로 나누기 → 최종 코드 ②

### 최종 코드 ① — `while` 안에 모든 기능 (`students.js`)

```javascript
const readline = require("readline-sync");

// 세 명이 등록 가능한 배열이 필요하다.
const students = [];

console.log("=== 학생 관리 프로그램 ===");

let count = 0;

while(true) {
    console.log("1. 학생 등록");
    console.log("2. 학생 목록");
    console.log("3. 학생 삭제");
    console.log("0. 프로그램 종료");
    const cmd = readline.question("command: ");

    if (cmd == 1) {
        if (count == 3) {
            console.log("더 이상 학생을 등록할 수 없습니다.");
            continue;
        }

        const name = readline.question("input name:");
        students.push(name);
        
        count++;

        console.log("학생 등록이 완료되었습니다.");

        // == 안에 있는 값만 보고 동일 여부를 확인함 1 == "1" -> true
        // === 안에 있는 값과 타입도 동일 여부를 확인함 1 === "1" -> false
    } else if (cmd == 2) {
        // 학생이 한 명도 등록되어 있지 않은 경우
        if (count == 0) {
            console.log("등록된 학생이 존재하지 않습니다.");
            continue;
        }

        for (let i = 0; i < students.length; i++) {
            console.log(`${i + 1}번: ${students[i]}`)
        }

    } else if (cmd == 3) {
            if (count == 0) {
                console.log("등록된 학생이 존재하지 않습니다.");
                continue;
            }

            // 사람 눈에 보이는 숫자
            // 1. -> 0
            // 2. -> 1
            // 3. -> 2
            const deleteNo = readline.question("delete Student No: ");
            const deleteIdx = Number(deleteNo) - 1; // 입력 받은 번호에서 1을 뺌으로써 삭제할 학생의 인덱스를 구한다.

            if (deleteNo > count || deleteNo < 0) {
                console.log("해당 학생은 존재하지 않습니다.");
                continue;
            } else {
                students.splice(deleteIdx, 1);
                console.log(`${deleteNo}번째 학생을 삭제했습니다.`);
                count--;
            }

    } else if (cmd == 0) {
        console.log("프로그램을 종료합니다.");
        break;
    } else {
        console.log("해당 명령어는 존재하지 않습니다.");
    }

}
```

### 최종 코드 ② — 기능을 함수로 나누기 (`students.js`)
메뉴 출력·등록·목록·삭제를 함수로 만들고, 아래 `while`문(강사 주석: "controller")은 **입력을 받아 알맞은 함수를 부르는 역할**만 한다. 함수 안에서는 `continue` 대신 `return`으로 함수를 끝낸다.

```javascript
const readline = require("readline-sync");

// 세 명이 등록 가능한 배열이 필요하다.
const students = [];

console.log("=== 학생 관리 프로그램 ===");

let count = 0;

// 프로그램 메뉴 출력
function printMenu() {
    console.log("1. 학생 등록");
    console.log("2. 학생 목록");
    console.log("3. 학생 삭제");
    console.log("0. 프로그램 종료");
}

// 학생 등록
function createStudent() {
    if (count == 3) {
        console.log("더 이상 학생을 등록할 수 없습니다.");
        return;
    }

    const name = readline.question("input name:");
    students.push(name);

    count++;

    console.log("학생 등록이 완료되었습니다.");
}

// 학생 목록 출력
function printStudents() {
    // 학생이 한 명도 등록되어 있지 않은 경우
    if (count == 0) {
        console.log("등록된 학생이 존재하지 않습니다.");
        return;
    }

    for (let i = 0; i < students.length; i++) {
        console.log(`${i + 1}번: ${students[i]}`)
    }

}

// 학생 삭제
function deleteStudent() {
    if (count == 0) {
        console.log("등록된 학생이 존재하지 않습니다.");
        return;
    }

    // 사람 눈에 보이는 숫자
    // 1. -> 0
    // 2. -> 1
    // 3. -> 2
    const deleteNo = readline.question("delete Student No: ");
    const deleteIdx = Number(deleteNo) - 1; // 입력 받은 번호에서 1을 뺌으로써 삭제할 학생의 인덱스를 구한다.

    if (deleteNo > count || deleteNo < 0) {
        console.log("해당 학생은 존재하지 않습니다.");
        return;
    } else {
        students.splice(deleteIdx, 1);
        console.log(`${deleteNo}번째 학생을 삭제했습니다.`);
        count--;
    }

}










// controller 컨트롤을 하는 역할
while (true) {
    printMenu();
    const cmd = readline.question("command: ");

    if (cmd == 1) {
        createStudent();
    } else if (cmd == 2) {
        printStudents();
    } else if (cmd == 3) {
        deleteStudent();
    } else if (cmd == 0) {
        console.log("프로그램을 종료합니다.");
        break;
    } else {
        console.log("해당 명령어는 존재하지 않습니다.");
    }

}
```

> 💡 보충: 최종 코드 ①·②의 삭제 검사 `deleteNo > count || deleteNo < 0`에는 빈틈이 있다.
> - `0`이나 그냥 Enter(빈 입력) → 검사를 통과하고 `deleteIdx`가 `-1` → `splice(-1, 1)`은 **마지막 학생**을 지운다.
> - `abc`, `1.5` → 검사를 통과하고 `splice(NaN, 1)`·`splice(0.5, 1)` → **첫 번째 학생**이 지워진다.
>
> 숫자로 바꾼 값으로 정수·범위를 검사하면 막힌다 (핵심 개념 8의 조건 표).
> ```javascript
> const number = Number(deleteNo);
>
> if (!Number.isInteger(number) || number < 1 || number > count) {
> ```
> 또 등록에 빈 이름 검사가 없으므로 핵심 개념 5의 보충 코드를 넣는다. `count`는 항상 `students.length`와 같은 값이라 `students.length`를 써도 된다.

## 헷갈리기 쉬운 점
- **`npm install`은 프로젝트를 준비할 때 한 번.** 실행할 때는 `node students.js`만.
- **패키지는 그 프로젝트 폴더에 설치된다.** 다른 폴더에서 설치했다면 `readline-sync`를 찾지 못한다.
- **`question()`의 결과는 언제나 문자열.** `===`로 비교하려면 `"1"`과 비교한다 (`menu === 1`은 거짓).
- **`const` 배열도 `push()`·`splice()`로 내용은 바꿀 수 있다.** 다른 배열을 재대입(`students = []`)하는 것만 오류. 단, React state 배열은 직접 바꾸지 않는다.
- **목록 번호 = 인덱스 + 1.** 삭제할 때는 번호에서 1을 뺀다.
- **삭제하면 뒤의 번호가 당겨진다.** 번호는 영구 ID가 아니다.
- **`Number("abc")`는 `NaN`.** `NaN`과의 비교(`<`, `>`)는 모두 `false`라서 범위 검사만으로는 걸러지지 않는다. `Number.isInteger()`도 함께 쓴다.
- **`splice()`는 원본 배열을 바꾼다.** 음수 인덱스(`-1`)는 끝에서부터 센다.
- **`while (true)`는 `break`가 없으면 끝나지 않는다.** 멈출 때는 `Ctrl + C`.
- **입력은 출력 전용 패널(Output)이 아니라 터미널(Terminal)에서** 한다.
- **프로그램을 끝내면 학생 목록은 사라진다.** 메모리에만 있다.

**실행이 안 될 때 확인할 것**

| 증상 | 확인할 내용 |
|---|---|
| `readline-sync`를 찾지 못함 | 현재 프로젝트에서 패키지를 설치했는지 |
| `students.js`를 찾지 못함 | 터미널 위치와 파일 이름 |
| `require is not defined` | React 프로젝트가 아닌 별도 폴더인지, `"type": "module"` 설정이 있는지 |
| 입력할 수 없음 | VS Code의 터미널에서 실행했는지 |
| 삭제할 학생이 잘못 선택됨 | 목록 번호에서 1을 뺐는지 (1번 → 인덱스 0) |
| 메뉴 선택이 동작하지 않음 | 문자열 `"1"`·`"2"`·`"3"`과 비교했는지 |

## 확인 문제
강의에 별도 "💬 확인하기"는 없어서, 본문의 질문형 제목과 "직접 확인하기"에서 뽑았다.

<details><summary>Q. (강의 질문) 사용자 입력은 어떻게 받나? `readline.question("학생 이름: ")`은 어떻게 동작하나?</summary>

`npm install readline-sync`로 설치하고 `const readline = require("readline-sync");`로 불러온다. `question()`은 질문을 출력하고 사용자가 입력 후 **Enter를 누를 때까지 기다렸다가** 입력값을 **문자열**로 돌려준다. 그다음 코드로 진행한다.
</details>

<details><summary>Q. `npm init -y`와 `npm install readline-sync`는 각각 무엇을 하나? 실행할 때마다 다시 해야 하나?</summary>

`npm init -y`: `package.json`을 기본값으로 만든다. `npm install readline-sync`: 패키지를 `node_modules`에 설치하고 `package.json`·`package-lock.json`에 기록한다. **프로젝트를 준비할 때 한 번**만 하고, 실행은 `node students.js`만 한다.
</details>

<details><summary>Q. (강의 질문) `const students = [];`로 만든 배열에 `push()` 할 수 있나? `students = [];`는?</summary>

`push()`는 된다. `const`는 재대입만 막고 배열 내부 변경은 막지 않는다. `students = [];`는 다른 배열을 재대입하므로 오류다.
</details>

<details><summary>Q. 콘솔 프로그램의 일반 배열은 `push()`로 직접 바꿨다. React state 배열도 그렇게 해도 되나?</summary>

안 된다. React state 배열은 직접 변경하지 않고 새 배열을 만들어 `set함수`로 바꾼다 ([08_폼-배열state-할일앱](../01_React과정/08_폼-배열state-할일앱.md)). 이번 콘솔 프로그램은 일반 배열이라 직접 바꿔도 된다.
</details>

<details><summary>Q. `for (let i = 0; i < 3; i++)`에서 `i`는 어떤 값으로 변하고 몇 번 실행되나?</summary>

`0`, `1`, `2`로 변하며 세 번 실행된다. `i = 3`이 되면 `i < 3`이 거짓이라 멈춘다.
</details>

<details><summary>Q. `"  한코딩  ".trim()`과 `"   ".trim()`의 결과는? 빈 이름 검사에 어떻게 쓰나?</summary>

`"한코딩"`과 `""`. 입력값에 `trim()`을 붙인 뒤 `""`이면 안내만 출력하고 배열에 추가하지 않는다. 공백만 입력한 경우도 빈 이름으로 걸러진다.
</details>

<details><summary>Q. 메뉴에서 1을 입력했는데 `if (menu === 1)`이 실행되지 않는다. 왜인가?</summary>

`question()`의 결과는 문자열 `"1"`이다. `===`는 값과 자료형이 모두 같아야 참이므로 `"1" === 1`은 거짓이다. `menu === "1"`로 비교한다. (`==`는 자료형을 맞춰 비교해 `"1" == 1`이 참이라 수업 코드의 `cmd == 1`은 동작한다.)
</details>

<details><summary>Q. `while (true)` 메뉴는 어떻게 끝나나? 2단계 코드에서 0을 눌러도 메뉴가 계속 나온 이유는?</summary>

종료 메뉴에서 `break`를 만나면 반복문을 빠져나오고, 뒤에 실행할 코드가 없어 프로그램이 끝난다. 2단계 코드는 `cmd == 0`에 `break`가 없어서 안내만 출력하고 계속 반복했다.
</details>

<details><summary>Q. 목록에서 2번 학생을 지우려면 `splice`에 무엇을 넣나? 지운 뒤 3번 학생의 번호는?</summary>

번호 2 → 인덱스 1 → `students.splice(1, 1);` 지운 뒤 원래 3번 학생은 **2번**이 된다. 목록 번호는 영구 ID가 아니라 현재 배열 위치다.
</details>

<details><summary>Q. `Number("abc")`의 결과는? 삭제 번호로 `abc`나 `1.5`를 막으려면 어떤 조건이 필요한가?</summary>

`NaN`. `NaN < 1`, `NaN > 길이`는 모두 거짓이라 범위 검사만으로는 통과한다. `!Number.isInteger(number) || number < 1 || number > students.length`처럼 **정수 검사**를 함께 넣는다.
</details>

<details><summary>Q. 최종 코드 ①에서 학생이 3명일 때 삭제 번호로 `0`을 입력하면 어떻게 되나?</summary>

`"0" > 3`, `"0" < 0`이 모두 거짓이라 검사를 통과한다. `deleteIdx = -1`이 되고 `splice(-1, 1)`은 **마지막 학생**을 지운다. 검사를 `number < 1`로 해야 한다.
</details>

<details><summary>Q. (강의 질문) 프로그램을 종료한 뒤 다시 실행하면 학생 목록은?</summary>

빈 배열에서 다시 시작한다. 목록은 실행 중인 프로그램의 메모리에만 있고, 파일·DB 저장은 아직 없다.
</details>

<details><summary>Q. 콘솔 학생 관리의 "터미널 입력 / 입력값 검사 / 배열 조회·삭제 / 터미널 출력"은 서버 프로그램에서 각각 무엇에 해당하나?</summary>

클라이언트 요청 / 요청과 전달 데이터 검사 / 서비스 데이터 조회·삭제 / 클라이언트에 응답.
</details>
