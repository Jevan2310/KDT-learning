## 과정 소개
백엔드의 역할과 Node.js가 등장한 배경을 알아보고, **서버가 보내준 데이터를 React 화면에 표시**한다.

완성할 흐름: **React에서 목록 요청 → Node.js에서 JSON 응답 → React에서 목록 표시**

## 학습 목표
- 백엔드가 하는 일을 설명할 수 있다.
- Node.js 서버를 실행할 수 있다.
- 서버에서 보낸 JSON을 확인할 수 있다.
- React 화면에 서버 데이터를 표시할 수 있다.

## 실습 폴더 한눈에 보기
회차마다 새 폴더를 만든다. 강의에서 쓴 이름 기준이다.

```text
학습 폴더
├─ my-profile-react   ← React과정에서 만든 Vite React 프로젝트 (04회차에서 다시 사용)
├─ node-basic         ← 01회차: hello.js, tasks.js
├─ student-manager    ← 02회차: students.js (readline-sync 설치)
└─ student-server     ← 03·04회차: server.js (express, cors 설치)
```

| 회차 | 폴더 | 준비 (처음 한 번) | 실행 | 결과 확인 |
|---|---|---|---|---|
| 01 | `node-basic` | 없음 | `node hello.js`, `node tasks.js` | 터미널 |
| 02 | `student-manager` | `npm init -y` → `npm install readline-sync` | `node students.js` | 터미널 (입력도 터미널에서) |
| 03 | `student-server` | `npm init -y` → `npm install express` | `node server.js` (종료 `Ctrl + C`) | 브라우저 `http://localhost:3000/…` |
| 04 | `student-server` + React 프로젝트 | 서버에 `npm install cors` | 서버 `node server.js` + React `npm run dev` (터미널 2개) | 브라우저 `http://localhost:5173` |
