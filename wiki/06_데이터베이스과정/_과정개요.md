# 데이터베이스과정 — SQL부터 Spring 연동까지

> 과정: 데이터베이스과정 · [노션 원문](https://app.notion.com/p/41a848f71c9b804c9d96e589bd9017b9) · 최종 갱신일: 2026-11-18

## 과정 소개
데이터를 저장하는 구조를 이해하고, **SQL**로 필요한 데이터를 조회·변경한다.
**MySQL**에서 직접 실행한 SQL을 **Spring과 MyBatis**로 연결해 실제 서비스(API)에서 사용해 본다.

- 수업일: 2026-11-18
- 실습에는 **가상의 학생 정보**만 쓴다 (예: 한코딩, 김자바, `han@example.com`).

## 학습 목표
과정 페이지의 학습 목표다.
- 데이터베이스와 테이블의 역할을 설명한다.
- 저장할 데이터에 맞게 테이블을 만든다.
- SQL로 데이터를 추가·조회·수정·삭제한다.
- 여러 테이블의 데이터를 JOIN으로 연결한다.
- MyBatis의 Mapper를 이용해 Spring에서 SQL을 실행한다.
- AI가 작성한 SQL의 동작과 변경 대상을 확인한다.

## 사용하는 도구

| 도구 | 역할 |
|---|---|
| MySQL(MariaDB) Community Server | 데이터를 저장하고 SQL을 실행하는 DBMS |
| DBeaver Community | DB에 접속해 테이블을 확인하고 SQL을 작성하는 도구 |
| IntelliJ IDEA | Java와 Spring 코드를 작성하는 개발 도구 |
| Spring Boot | 요청을 받아 데이터를 처리하는 백엔드 |
| **MyBatis** | 작성한 SQL과 Java 메서드·객체를 연결하는 도구 |
| Gradle | 프로젝트에 필요한 라이브러리와 빌드를 관리하는 도구 |

## 실습 예제 — 학생 관리
하나의 예제를 단계적으로 확장한다.

```text
학생 정보를 저장할 테이블 만들기          ← 01·02
                ↓
학생 추가·조회·수정·삭제                  ← 02·03·04
                ↓
반 정보를 별도 테이블로 분리              ← 05
                ↓
학생과 반을 JOIN으로 조회                 ← 05
                ↓
Spring과 MyBatis에서 SQL 실행             ← 06
```

**실습 데이터 구조** — 학생 한 명은 최대 한 반에 소속되고, 한 반에는 여러 학생이 소속될 수 있다.

| 테이블 | 저장할 정보 | 만드는 회차 |
|---|---|---|
| `students` | 학생 번호, 이름, 이메일, 등록일, 소속 반 번호 | [02](02_테이블-데이터추가.md) (반 번호 `class_id`는 [05](05_테이블관계-JOIN.md)에서 추가) |
| `classes` | 반 번호, 반 이름 | [05](05_테이블관계-JOIN.md) |

**최종 연결 구조**

```text
클라이언트의 HTTP 요청
          ↓
Spring Controller
          ↓
MyBatis Mapper
          ↓
Mapper XML에 작성한 SQL
          ↓
MySQL
```

DBeaver에서는 같은 MySQL에 접속해 저장된 데이터와 SQL 실행 결과를 확인한다.

## 강의 목차
노션 과정 페이지 본문의 목차다. 이 과정은 목차 번호와 하위 페이지(회차) 번호가 같다.

### 01. 데이터베이스 이해와 실습 환경 준비
데이터를 어디에, 어떻게 저장하는지 이해한다.
- 변수·배열에 저장하는 것과 DB에 저장하는 것의 차이
- 데이터베이스·DBMS·SQL의 관계
- 테이블·행·열의 개념
- MySQL과 DBeaver 설치 및 연결
- 호스트·포트·사용자·비밀번호 이해하기
- 실습용 데이터베이스 만들기

### 02. 테이블 만들고 데이터 추가하기
저장할 데이터의 구조를 정하고 학생 정보를 추가한다.
- `CREATE TABLE`로 테이블 만들기
- 자료형: `INT`, `VARCHAR`, `DATE`
- 기본키 `PRIMARY KEY`
- 자동 번호 `AUTO_INCREMENT`
- 필수값 `NOT NULL`
- 중복 제한 `UNIQUE`
- `INSERT`로 데이터 추가하기

### 03. 필요한 데이터 조회하기
조건에 맞는 데이터를 찾고 원하는 순서로 조회한다.
- `SELECT`와 `FROM`
- 필요한 열만 조회하기
- `WHERE`와 비교 연산자
- `AND`, `OR`로 조건 연결하기
- `LIKE`로 이름 검색하기
- `ORDER BY`로 정렬하기
- `LIMIT`으로 조회 개수 제한하기
- `IS NULL`로 값이 없는 데이터 찾기

### 04. 데이터 수정·삭제와 트랜잭션
변경할 대상을 확인하고 데이터를 수정·삭제한다.
- `UPDATE`로 데이터 수정하기
- `DELETE`로 데이터 삭제하기
- `WHERE`가 없을 때 발생하는 일
- 변경 전에 `SELECT`로 대상 확인하기
- 트랜잭션과 자동 커밋 이해하기
- `START TRANSACTION`, `COMMIT`, `ROLLBACK`
- 데이터 변경 결과 확인하기

### 05. 테이블 관계와 JOIN 이해하기
학생과 반 정보를 나누어 저장하고 연결해서 조회한다.
- 테이블을 나누는 이유
- 기본키와 외래키
- 일대다 관계
- `INNER JOIN`으로 연결된 데이터 조회하기
- `LEFT JOIN`으로 연결되지 않은 데이터도 조회하기
- `COUNT`, `GROUP BY`로 반별 학생 수 구하기

### 06. Spring과 MyBatis — 작성한 SQL을 서비스에서 실행하기
직접 작성한 SQL을 Mapper로 연결해 백엔드에서 실행한다.
- MyBatis의 역할과 JPA와의 차이
- Gradle 의존성과 MySQL 접속 설정
- 조회 결과를 담을 Java 클래스 만들기
- `@Mapper` 인터페이스 작성하기
- Mapper XML에 SQL 작성하기
- `namespace`와 SQL `id`의 연결 이해하기
- `#{...}`로 SQL에 값 전달하기
- 학생 목록·상세 조회 API 만들기
- 추가·수정·삭제로 확장하기
- DBeaver에서 실행 결과 확인하기

## 실습 환경 한눈에 보기

| 회차 | 어디서 | 무엇을 | 결과 확인 |
|---|---|---|---|
| 01 | MySQL 설치 + DBeaver 연결 | `school` 데이터베이스 생성 | DBeaver 결과 영역 (`SELECT DATABASE();` → `school`) |
| 02~05 | DBeaver의 SQL 편집기 (MySQL 연결) | `USE school;` 후 SQL을 **한 문장씩 선택해 실행** (`Ctrl + Enter`) | DBeaver 결과 영역 |
| 06 | IntelliJ의 새 Spring Boot 프로젝트 `student-mybatis` (Gradle, Spring Web + MyBatis + MySQL 드라이버) | Mapper·XML·Controller 작성 후 서버 실행 (8080) | 브라우저 `http://localhost:8080/students` + 개발자 도구 Console의 `fetch` + DBeaver 조회 |

- 각 회차는 **앞 회차의 데이터를 그대로 이어서** 쓴다. 02에서 넣은 학생 5명을 03~06에서 계속 사용한다.
- 강의는 MySQL 기준이고, **H2**를 쓰는 경우의 명령도 함께 안내한다 (03·04·05·06). H2를 쓰면 `USE school;`은 생략한다.

> 💡 보충: 강의의 설치 화면은 Windows 기준이다. macOS에서 설치하는 법과 단축키 차이(`Ctrl` → `Cmd`)는 [MySQL-DBeaver](../00_개발환경/MySQL-DBeaver.md)의 보충에 적었다.

## 학습할 때 기억할 점
과정 페이지의 안내다.
- SQL은 복사해서 실행하기 전에 **대상 테이블과 조건**을 확인한다.
- 수정·삭제 전에는 같은 조건으로 조회해 변경 대상을 확인한다.
- 오류가 나면 오류 메시지와 테이블 구조를 함께 살펴본다.
- AI가 작성한 SQL도 직접 실행 결과를 확인한다.
- 비밀번호나 실제 개인정보를 공개 저장소에 올리지 않는다.
