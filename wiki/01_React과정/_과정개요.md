# React과정 — 직접 사용하는 첫 웹 앱 만들기

> 과정: React과정 · [노션 원문](https://app.notion.com/p/React-40a848f71c9b80bdb043ea4bb00b42e3) · 최종 갱신일: 2026-11-09

## 과정 소개
HTML·CSS·JavaScript의 역할부터 시작해, React를 이용하여 웹 앱(할 일 앱)을 만든다.

## 학습 목표
- 화면에서 수정하고 싶은 부분의 코드를 찾을 수 있다.
- 컴포넌트·props·state의 역할을 구분할 수 있다.
- 할 일을 추가·삭제하고 완료 상태를 바꿀 수 있다.
- AI가 생성 및 수정한 코드를 파악할 수 있다.

**HTML · CSS · 브라우저**

- CSS로 색상·여백·배치 바꾸기
- 개발자 도구 살펴보기

### 02. JavaScript로 동작 넣기
**변수 · 함수 · 객체 · 배열 · 이벤트**
- 값을 저장하고 사용하는 방법
- 함수로 동작 정의하기
- 객체와 배열로 데이터 표현하기
- 클릭 이벤트로 화면 바꾸기
- 콘솔에서 결과와 오류 확인하기

### 03. React 시작하기
**React의 역할 · 프로젝트 실행 · JSX**
- React를 사용하는 이유
- 프로젝트 실행과 파일 구조
- 첫 컴포넌트와 JSX
- JavaScript 값을 화면에 표시하기
- 스타일 적용하기

### 04. 컴포넌트로 화면 구성하기
**컴포넌트 · props · 목록 · 조건부 표시**
- 화면을 작은 단위로 나누기
- props로 데이터 전달하기
- 같은 컴포넌트 재사용하기
- `map`과 `key`로 목록 표시하기
- 조건에 따라 다른 화면 보여주기

### 05. state로 화면 바꾸기
**이벤트 · useState · 렌더링**
- 클릭 이벤트 처리하기
- 일반 변수와 state의 차이
- state 변경과 화면 갱신
- 이전 상태를 기준으로 업데이트하기

### 06. 할 일 앱 완성하기 (투두 리스트)
**입력 폼 · 추가 · 삭제 · 완료 전환**
- 입력값을 state와 연결하기
- 폼 제출과 빈 입력 검사
- 배열에 새로운 항목 추가하기

- `map`으로 완료 상태 바꾸기

### 07. AI와 함께 기능 개선하기
**요청 작성 · 코드 비교 · 동작 검증**
- 현재 코드와 원하는 동작 전달하기
- 작은 기능 하나씩 요청하기
- 수정 전후 코드 비교하기
- 정상 입력과 예외 상황 확인하기
- 변경 내용을 내 말로 설명하기

### 08. 서버와 연결되는 흐름 살펴보기
**API · JSON · fetch · 비동기 처리 · useEffect 기초**
