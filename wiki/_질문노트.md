# 질문 노트 — 공통

> 최종 갱신일: 2026-11-09

특정 강의에 속하지 않는 질문과 답을 모은다 (예: 개발 공부 방법, 용어, 여러 강의에 걸친 질문).
강의 내용 질문은 해당 강의 wiki 파일의 `## 질문 노트`에 적는다. 형식은 `../CLAUDE.md` 5장.

<details><summary>Q. 답안 쓸 때 쓸만한 마크다운 문법은? <sub>2026-11-09 · 연습 중</sub></summary>

**A.** (강의 밖 내용) 답안.md에 자주 쓰는 것만 추렸다.

| 쓰고 싶은 것 | 이렇게 쓴다 | 주의 |
|---|---|---|
| 문제 번호 제목 | `## 1` | `#` 뒤에 한 칸 띄우기 |
| 목록 | `- 항목`, `1. 항목` | `-` 뒤에 한 칸 |
| 굵게 | `**중요**` | |
| 태그 이름 하나 | `` `<li>` `` | 백틱(`)으로 감싸야 태그가 사라지지 않는다 |
| 코드 여러 줄 | ` ```html ` … ` ``` ` | 언어 이름을 붙이면 색이 들어간다 |
| 체크박스 | `- [x] 완료`, `- [ ] 미완료` | |
| 인용 (문제 옮겨 적기) | `> 문제 내용` | |
| 구분선 | `---` | 위아래 빈 줄 |
| 줄바꿈 | 빈 줄 하나 | Enter 한 번은 앞 줄과 이어질 수 있다 (HTML과 비슷) |

(2026-11-13 보강) JSX·React 코드는 ` ```jsx `, HTML은 ` ```html `로 감싸면 코드로 보이고 색도 들어간다. 표(`| … |`)의 한 칸 안에서는 **Enter로 줄을 바꾸면 표가 깨진다**. 한 줄로 이어 쓰거나 `/`로 나눈다.
