# 개발환경 — Visual Studio Code + Node.js

> 과정: 개발환경 (React과정 준비) · [노션 원문](https://app.notion.com/p/Visual-Studio-Code-Node-js-408848f71c9b802f9abaf5e03f1763b6) · 최종 갱신일: 2026-11-09

## 한눈에 보기
- React 수업에 쓸 도구 4가지(Chrome, VS Code, Node.js, npm)를 설치하고 버전을 확인한다.
- VS Code에서는 **파일 하나가 아니라 프로젝트 폴더 전체**를 열고, 내장 터미널에서 명령을 실행한다.
- `npm install` → `npm run dev` → 터미널에 나온 주소를 브라우저로 열기 순서로 리액트 프로젝트를 실행한다.
- 오늘의 핵심 흐름: **파일 수정 → 저장 → 화면 확인**.

## 도구별 역할

| 도구 | 역할 |
|---|---|
| Chrome | 만든 웹 화면을 확인하고 오류를 살펴보는 브라우저 |
| Visual Studio Code | 프로젝트 파일을 열고 코드를 작성하는 편집기 |
| Node.js | 개발 도구와 JavaScript 프로그램을 실행하는 환경 |
| npm | 프로젝트에 필요한 패키지를 설치하고 실행 명령을 사용하는 도구. Node.js 설치 시 함께 설치된다 |

- 이미 설치되어 있으면 다시 설치하지 말고, 실행 여부와 버전부터 확인한다.

## 설치·확인 절차

### 1. 설치하기
강사가 안내하는 버전에 맞춰 설치한다.
- Chrome: <https://www.google.com/intl/ko_kr/chrome/>
- Visual Studio Code: <https://code.visualstudio.com/>
- Node.js: <https://nodejs.org/ko/download>

### 2. 프로젝트 폴더 열기
1. VS Code에서 **파일 → 폴더 열기**를 선택한다.
2. 적절한 위치에 프로젝트 폴더를 만든 뒤 연다.
3. **터미널 → 새 터미널**을 선택한다.

- 왼쪽 파일 목록(탐색기)에 프로젝트 파일들이 보이면 폴더 전체가 열린 것이다.

### 3. Node.js와 npm 확인하기
터미널에 한 줄씩 입력한다. 각각 버전 번호가 나오면 확인 완료.

```bash
node -v
npm -v
```

### 4. 리액트 프로젝트 실행하기
프로젝트 생성은 강의 참고 링크의 안내를 따른다: [한코딩 연구실 - 프로젝트 생성 안내](https://hancoding.kr/theory/3?note=72)

```bash
npm install     # ① 필요한 패키지 설치
npm run dev     # ② 개발 서버 실행
```

③ 터미널에 표시된 주소를 브라우저에서 연다.

- 실행 중에는 터미널을 열어 둔다.
- 개발 서버를 끌 때는 그 터미널에서 `Ctrl + C`.

### 5. 화면 직접 바꿔 보기
강사가 안내한 파일에서 이름·소개 문장을 바꾸고 저장한 뒤, 브라우저에 바로 반영되는지 확인한다. 아직 코드 전체를 이해할 필요는 없다.

## 자주 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| Node.js 버전 확인 | `node -v` |
| npm 버전 확인 | `npm -v` |
| 프로젝트 패키지 설치 | `npm install` |
| 개발 서버 실행 | `npm run dev` |
| 개발 서버 종료 | 터미널에서 `Ctrl + C` |

> 💡 보충: `npm install`은 프로젝트의 `package.json`에 적힌 패키지를 `node_modules` 폴더에 내려받는다. 프로젝트를 새로 받았거나 `node_modules`가 없을 때 한 번 실행하면 되고, 매번 할 필요는 없다. 평소에는 `npm run dev`만 실행한다.

## 문제 생겼을 때
- **`node`/`npm` 명령을 찾을 수 없다고 나올 때**: VS Code를 완전히 종료한 뒤 다시 열어 확인한다. 그래도 안 되면 도움을 요청한다.
- **설치 중 오류**: 화면을 그대로 두고 도움을 요청한다.
- 도움을 요청할 때 알려줄 것: 운영체제, 막힌 단계, 입력한 명령, 오류 메시지 또는 화면 캡처.

> 💡 보충: `node`를 설치하기 전에 열어 둔 터미널은 새 설치 경로(PATH)를 모른다. 그래서 "명령을 찾을 수 없다"가 나오면 터미널(또는 VS Code)을 새로 여는 것이 첫 번째 해결책이다.
