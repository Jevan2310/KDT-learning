# 00. 인텔리제이 단축키 — IntelliJ IDEA에서 자주 쓰는 단축키

> 과정: 개발환경 (Spring과정 00회차) · [노션 원문](https://app.notion.com/p/415848f71c9b803ab4b1ea784a3fcf70) · 최종 갱신일: 2026-11-12

## 한눈에 보기
- Java·Spring 수업에서 IntelliJ IDEA로 코드를 쓸 때 자주 쓰는 단축키를 **분류별(편집·주석·코드 작성·정리·검색·이동·리팩터링·실행·디버깅·창·설정)** 로 정리한 표다. 강의는 표 하나로 되어 있다.
- **Windows와 macOS의 키가 다르다.** 대체로 `Ctrl` → `⌘`, `Alt` → `⌥`로 바뀌지만, 현재 줄 삭제·선택 영역 확장·자동 완성·실행·특정 줄 이동처럼 **규칙대로 바뀌지 않는 것이 많다.**
- 수업 코드에 바로 나온 단축키: **`Alt + Insert`(⌘ + N)** 로 생성자·getter·setter 만들기, **`Ctrl + Shift + Enter`(⌘ + ⇧ + Enter)** 로 줄 끝에 `;` 붙이기 ([01_Java기초](../03_Spring과정/01_Java기초.md)).
- IntelliJ 설치와 JDK 설정은 [IntelliJ-JDK](IntelliJ-JDK.md) 참고.

## 키 기호 읽는 법

> 💡 보충: 강의 표의 macOS 열에 쓰인 기호다.
>
> | 기호 | 키 |
> |---|---|
> | `⌘` | Command |
> | `⇧` | Shift |
> | `⌥` | Option |
> | `⌃` | Control |
> | `⌫` | Delete (Windows의 Backspace 위치) |

## 단축키 표

### 편집

| 기능 | Windows | macOS |
|---|---|---|
| 실행 취소 | Ctrl + Z | ⌘ + Z |
| 다시 실행 | Ctrl + Shift + Z | ⌘ + ⇧ + Z |
| 현재 줄 / 선택 영역 복제 | Ctrl + D | ⌘ + D |
| 현재 줄 삭제 | Ctrl + Y | ⌘ + Delete(⌫) |
| 현재 줄 아래에 새 줄 추가 | Shift + Enter | ⇧ + Enter |
| 줄 위 / 아래로 이동 | Alt + Shift + ↑ / ↓ | ⌥ + ⇧ + ↑ / ↓ |
| 선택 영역 확장 | Ctrl + W | ⌥ + ↑ |
| 선택 영역 축소 | Ctrl + Shift + W | ⌥ + ↓ |
| 클립보드 기록에서 붙여넣기 | Ctrl + Shift + V | ⌘ + ⇧ + V |

### 주석

| 기능 | Windows | macOS |
|---|---|---|
| 한 줄 주석 설정 / 해제 | Ctrl + / | ⌘ + / |
| 블록 주석 설정 / 해제 | Ctrl + Shift + / | ⌘ + ⌥ + / |

### 코드 작성

| 기능 | Windows | macOS |
|---|---|---|
| 기본 자동 완성 | Ctrl + Space | ⌃ + Space |
| 현재 구문 완성 | Ctrl + Shift + Enter | ⌘ + ⇧ + Enter |
| 빠른 수정 / 제안 표시 | Alt + Enter | ⌥ + Enter |
| 매개변수 정보 표시 | Ctrl + P | ⌘ + P |
| 문서 설명 보기 | Ctrl + Q | F1 |
| 생성자·Getter·Setter 등 생성 | Alt + Insert | ⌘ + N |
| if·try/catch 등으로 감싸기 | Ctrl + Alt + T | ⌘ + ⌥ + T |

- **현재 구문 완성**: 커서가 줄 어디에 있든 그 줄 끝에 `;`를 붙여 준다 ([01_Java기초](../03_Spring과정/01_Java기초.md) 3번 "코드 읽기").
- **생성자·Getter·Setter 생성**: 클래스 안에서 누르면 메뉴가 뜬다. 필드를 고르면 `getName()`, `setName()` 같은 메서드를 만들어 준다. 수업 `Student` 클래스 코드의 `// alt + insert (Ins)` 주석이 이 단축키다.

> 💡 보충: **빠른 수정(Alt + Enter / ⌥ + Enter)** 은 빨간 줄(오류) 위에서 누르면 `import` 추가 같은 해결 방법을 제안한다. `List`를 쓰고 import를 빠뜨렸을 때 가장 자주 쓴다.

## 문제 생겼을 때

> 💡 보충: 강의 원문에는 없는, 단축키가 안 먹을 때 흔한 원인
> - **Mac에서 F1~F12 키가 밝기·소리 조절로 동작함**: `fn`을 함께 누르거나, 시스템 설정 → 키보드에서 "F1, F2 등의 키를 표준 기능 키로 사용"을 켠다.
> - **Mac에서 ⌃ + Space가 입력 소스(한/영) 전환으로 동작함**: macOS 기본 단축키와 겹친다. 시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스에서 바꾸거나, IntelliJ 설정의 Keymap에서 자동 완성 키를 바꾼다.
> - **노트북에 Insert 키가 없음 (Windows)**: 메뉴 **Code → Generate…** 로 같은 기능을 쓴다.
> - **표와 다른 동작을 함**: 설정 열기(Ctrl + Alt + S / ⌘ + ,) → **Keymap**에서 현재 키맵(Windows / macOS)을 확인한다. 기능 이름으로 검색하면 지정된 단축키가 나온다.
> - **단축키가 기억나지 않음**: 기능 / 명령 검색(Ctrl + Shift + A / ⌘ + ⇧ + A)에 기능 이름을 입력하면 실행할 수 있고, 단축키도 함께 보인다.
