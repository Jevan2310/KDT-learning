# 01. git 설치와 환경설정 — 설치하고 내 이름·이메일 등록하기

> 과정: Git협업과정 · [노션 원문](https://app.notion.com/p/41ce6d97109c80c196b0ffcc0cf01231) · 최종 갱신일: 2026-11-20

## 한눈에 보기
- Git 공식 사이트에서 운영체제에 맞는 설치 파일을 받는다. 설치할 때 **Git Bash**를 넣고, 기본 브랜치 이름을 **`main`**으로 정한다.
- 설치가 끝나면 처음 한 번 `git config --global`로 **이름과 이메일**을 등록한다. 모든 버전 기록에 "누가 바꿨는지"로 이 정보가 남는다. GitHub와 함께 쓰므로 **GitHub 계정의 이름·이메일**로 등록한다.
- `git config --list`로 전체 설정을, `git config user.name`처럼 하나씩도 확인할 수 있다.
- 설정은 적용 범위가 3가지다: `--system`(컴퓨터 전체) · `--global`(내 계정의 모든 저장소) · `--local`(지금 저장소만).

## 학습 목표
강의 페이지에 학습 목표가 따로 없어 본문 제목으로 정리했다.
- Git을 설치하고 설치 여부·버전을 확인한다.
- 사용자 이름·이메일과 기본 브랜치 이름을 설정한다.
- 설정한 값을 확인한다.
- 설정 범위(`--system` / `--global` / `--local`)를 구분한다.

## 핵심 개념

### 1. Git 설치
1. Git 공식 사이트에 들어가 **Downloads** 메뉴에서 운영체제에 맞는 버전을 받는다.
2. 설치 과정의 주요 옵션
   - **Git Bash 설치 (필수)** — 강의는 Git Bash에서 명령을 친다.
   - **기본 브랜치명 `main`** 설정
   - 텍스트 에디터 선택 (기본: vim)

화면별로 무엇을 고르는지는 [00_개발환경/git](../00_개발환경/git.md)의 설치 화면 표(11개)에 있다.

> 💡 보충: macOS
> - Git Bash는 Windows용이다. Mac에서는 **터미널**에서 같은 명령을 친다.
> - 터미널에서 `git --version`을 입력하면, 설치되어 있으면 버전이 나오고 없으면 개발자 도구(Command Line Tools) 설치 창이 뜬다.

### 2. 사용자 정보 설정 (필수)
- 이름과 이메일을 설정한다 (강의: Git Bash에서 진행).
- **모든 버전 내역에 이 정보가 쓰인다** — 누가, 언제 수정했는지 기록된다.
- GitHub와 함께 쓰므로 **GitHub 사이트의 계정명과 이메일**을 등록해야 한다. GitHub 가입이 먼저다.

```bash
# 0. Git이 정상 설치되었는지 확인
git --version

# 1. 사용자 정보 설정
git config --global user.name "YourName"
git config --global user.email "your.email@example.com"

# 2. 기본 브랜치명 설정
git config --global init.defaultBranch main

# 3. 설정 확인
git config --list

# 4. 특정 설정 확인
git config user.name
git config user.email
```

> 💡 보충: 공개 저장소에 올리면 커밋에 적힌 이메일도 누구나 볼 수 있다. 이메일을 드러내고 싶지 않으면 GitHub의 **Settings → Emails**에 나오는 `숫자+아이디@users.noreply.github.com` 주소를 `user.email`로 등록하면 된다.

### 3. 초기 설정 명령어

| 명령 | 하는 일 |
|---|---|
| `git --version` | Git 설치 여부와 버전 확인. 정상 설치되었는지 볼 때 쓴다 |
| `git config --global user.name "YourName"` | 사용자 이름을 전역으로 설정 — 모든 저장소에서 쓸 이름 (중요) |
| `git config --global user.email "your.email@example.com"` | 사용자 이메일을 전역으로 설정 — 모든 저장소에서 쓸 이메일 (중요) |
| `git config --global init.defaultBranch main` | 저장소를 만들 때 기본 브랜치 이름을 `main`으로. 최근에는 `master` 대신 `main`을 권장한다 |
| `git config --list` | 현재 Git의 모든 설정 확인 (전역·지역 설정 모두 표시) |
| `git config user.name` | 현재 설정된 사용자 이름만 확인 |
| `git config user.email` | 현재 설정된 이메일 주소만 확인 |

### 4. Git 설정의 범위 (참고)

| 옵션 | 적용 범위 | 저장 파일 |
|---|---|---|
| `--system` | 이 컴퓨터의 모든 사용자, 모든 저장소 | `/etc/gitconfig` |
| `--global` | 현재 사용자의 모든 저장소 | `~/.gitconfig` |
| `--local` | 현재 저장소만 | `.git/config` |

> 💡 보충
> - 같은 설정이 여러 곳에 있으면 **좁은 범위가 이긴다**: `--local` > `--global` > `--system`. 그래서 특정 저장소에서만 다른 이메일을 쓰려면 그 저장소 안에서 `git config user.email "…"`(옵션 없이 = `--local`)로 넣으면 된다.
> - 값이 어느 파일에서 왔는지는 `git config --show-origin user.name`으로 볼 수 있다. macOS의 기본 git은 시스템 설정 파일에 이미 `init.defaultBranch=main`이 들어 있는 경우가 있다.

## 실습 정리
1. GitHub에 가입한다.
2. Git을 설치한다 (Git Bash, 기본 브랜치 `main`).
3. Git Bash(Mac은 터미널)에서 위 코드 블록 0~4를 차례로 실행한다.
4. `git config user.name`, `git config user.email`에 GitHub 계정 정보가 나오면 끝.

## 헷갈리기 쉬운 점
- `user.name`·`user.email`은 **GitHub 로그인 정보가 아니다.** 커밋에 "작성자"로 적히는 이름표다. GitHub에 올릴 때의 로그인은 push할 때 따로 한다 ([03_원격저장소](03_원격저장소.md)).
- `--global`은 이 컴퓨터의 내 계정 전체에 적용되므로 **한 번만** 하면 된다. 저장소마다 다시 할 필요가 없다.
- 확인 명령 `git config user.name`에는 값을 넣지 않는다. 값을 넣으면 설정이 바뀐다.

## 빠른 참고 (치트시트)

| 하고 싶은 것 | 쓰는 것 | 예시 |
|---|---|---|
| 설치 확인 | `git --version` | `git version 2.50.1` 같은 줄이 나오면 설치됨 |
| 이름 등록 | `git config --global user.name` | `git config --global user.name "hancoding"` |
| 이메일 등록 | `git config --global user.email` | `git config --global user.email "han@example.com"` |

| 전체 설정 보기 | `git config --list` | |
| 값 하나 보기 | `git config <키>` | `git config user.email` |

## 확인 문제

<details><summary>Q. 사용자 이름·이메일을 꼭 설정해야 하는 이유는?</summary>

모든 버전(커밋)에 "누가, 언제 수정했는지"가 이 정보로 기록되기 때문이다. GitHub와 함께 쓰므로 GitHub 계정의 이름·이메일로 등록한다.
</details>

<details><summary>Q. `--global`로 설정한 값은 어디에 적용되고, 어느 파일에 저장되나?</summary>

현재 사용자의 **모든 저장소**에 적용되고 `~/.gitconfig`에 저장된다. 지금 저장소에만 적용하려면 `--local`(`.git/config`), 컴퓨터의 모든 사용자에게는 `--system`(`/etc/gitconfig`).
</details>

<details><summary>Q. `git config --global init.defaultBranch main`은 무엇을 바꾸나?</summary>

앞으로 `git init`으로 저장소를 만들 때 처음 생기는 브랜치 이름을 `main`으로 정한다. 과거 기본값은 `master`였다.
</details>

<details><summary>Q. 내 이메일만 확인하려면 어떤 명령을 쓰나?</summary>

`git config user.email`. 전체 설정은 `git config --list`.
</details>
