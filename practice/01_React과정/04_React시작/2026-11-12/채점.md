```jsx
    </>
  )
}

export default App
```

- 파일 역할을 보기 기호 대신 자기 말로 정확히 설명
- 처음 만든 React 프로젝트에서 CSS 2회차 내용(`max-width` + `margin: auto`, `border-box`)을 스스로 연결
