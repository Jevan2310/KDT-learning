## 문제 2 (버그 찾기)

App.jsx에 버그가 5개 있어요. 빠진 줄도 버그 하나로 쳐요. 코드를 답안.md에 붙여 넣고 표로 쓰세요. 줄 번호는 답안.md 기준이에요.
import "./App.css";

function App() {
  return (
    <h1 class="title">안녕하세요, 한코딩입니다!</h1>
    <!-- 소개 문장 -->
    <p>React를 배우고 있습니다.<br></p>
  );
}

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 35 | return에 태그가 두개 반환됨. | <> <h1> </h1>  <p> <p/> </>| jsx에서는 return에 하나의 태그만 반환 가능해서 <></>나 <div></div>로 묶어줘야함|
| 36 | <!-- 소개 문장 --> | {/* 소개 문장 */} | 주석처리가 HTML 용으로 됨.|
| 35 | class="title" | className ="title" | 기능은 같은데 명령어가 jsx와 html이 다름 |
| 37 | <br> | <br /> | html에서 사용하는 태그가 적힘.
| 40 | ___ | export default App | 빼먹음. export가 있어야 main.jsx에서 받아줌. |
