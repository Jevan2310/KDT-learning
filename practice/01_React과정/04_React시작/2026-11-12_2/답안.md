## 문제 1 (코드 읽기)

화면에 보이는 글자 ①~⑤를 쓰세요.
function App() {
  const city = "서울";
  const price = 1500;
  const menu = { name: "아메리카노", size: "L" };

  return (
    <div>
      <p>city</p>                          {/* ① */}
      <p>{city}에서 주문</p>                {/* ② */}
      <p>{price * 2}원</p>                  {/* ③ */}
      <p>{menu.name} ({menu.size})</p>     {/* ④ */}
      <p>${menu.name}</p>                  {/* ⑤ */}
    </div>
  );
}

- 서울에서 주문
- 3000원
- 아메리카노 (L)
- $아메리카노

## 문제 2 (버그 찾기)

화면에 제목, 사진, 취미가 나와야 하는데 버그가 4개 있어요.
- 이미지 파일은 public/profile.png에 있어요.
- 여러 줄이 버그 하나일 수도 있어요.
- 줄 번호는 답안.md 기준이에요.

import "./App.css";

function App() {
  const profile = {
    name: "한코딩",
    hobby: "러닝",
    imageUrl: "/public/profile.png"
  };

  const title = document.querySelector("h1");
  title.textContent = `안녕하세요, ${profile.name}입니다!`;

  return (
    <div className="card">
      <h1></h1>
      <img src="profile.imageUrl" alt="프로필 이미지" />
      <p>취미는 profile.hobby입니다.</p>
    </div>
  );
}

export default App;

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 42 43 | 42, 43줄 문장 전체 | 삭제 후 <h1>안녕하세요, {profile.name}입니다!</h1>
| jsx는 return에 넣기.|
| 48 | "profile.imageUrl" | {profile.imageUrl} | {}로 넣어야함. "" 은 HTML에서 주소를 넣는 방법임. JSX에서 객체는 {} 사용
| 49 | profile.hobby | {profile.hobby} | 객체를 불러오려면 {}써야함. 
| 39 | "/public/profile.png" | "profile.png" | 경로에 public은 쓰지 않고 public에 있는 파일은 파일이름만 써서 불러온다| 

## 문제 3 (설명하기)

JSX에서 **따옴표 " "**와 **중괄호 {}**는 각각 언제 쓰는지 내 말로 설명하세요. 예시 코드를 하나 넣어 주세요.

- "" 는 글자 그대로 경로를 작성하는 것으로 사용함.
- { }는 변수에 담긴 값을 사용함. 객체도 포함
