### 문제 2
| 원래 코드 | 고친 코드 | 이유 |
|---|---|---|
| `imageUrl: "/public/profile.png"` | `imageUrl: "/profile.png"` | public 파일은 `/파일이름`으로 쓴다 |
| `const title = document.querySelector("h1");` + `title.textContent = …` / `<h1></h1>` | 두 줄 삭제, `<h1>안녕하세요, {profile.name}입니다!</h1>` | React에서는 DOM을 직접 고치지 않고 JSX에 데이터를 `{}`로 넣는다 (이 시점엔 `h1`이 없어 `null` 오류도 남) |
| `src="profile.imageUrl"` | `src={profile.imageUrl}` | 따옴표는 글자 그대로, 변수 값은 `{}` |
| `취미는 profile.hobby입니다.` | `취미는 {profile.hobby}입니다.` | `{}`가 없으면 글자 그대로 나온다 |

### 문제 3
따옴표는 **고정된 글자**를 그대로 쓸 때(`className="card"`, `src="/profile.png"`), 중괄호는 **변수·객체 속성·계산 결과** 같은 JavaScript 값을 쓸 때(`src={profile.imageUrl}`, `<h1>{profile.name}</h1>`) 쓴다.

### 문제 4 (모범 답안)
```jsx
import "./App.css";

function App() {
  const profile = {
    name: "한코딩",
    intro: "직접 사용하는 서비스를 만들고 싶습니다.",
    goalCount: 3,
    imageUrl: "/profile.png"
  };

  return (
    <div className="card">
      <h1>안녕하세요, {profile.name}입니다!</h1>
      <img
        className="profile-image"
        src={profile.imageUrl}
        alt={`${profile.name}의 프로필 이미지`}
      />
      <p>{profile.intro}</p>
      <p>목표 {profile.goalCount}개 중 1개 완료, 남은 목표 {profile.goalCount - 1}개</p>
    </div>
  );
}

export default App;
```
```css
.profile-image {
  width: 120px;
}
```
