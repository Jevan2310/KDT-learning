## 문제와 피드백 (2026-11-12 14:08 제출)

### 문제 1 — ✅
- 18줄 "React는 안 뜸. 이유는 text라는 객체로 설정됨", 19줄 "Badge는 label만 연결이 됨" → 원리 정답 (보내는 이름 `text` ≠ 읽는 이름 `label`)
- HTML·CSS 두 배지는 따로 적지 않았지만 "React만 안 뜸"으로 답함 (감점 안 함)
- 참고 (용어): `text`는 객체가 아니라 **props의 이름**이다. 객체는 `props` 하나이고, 세 번째 배지에서는 `props = { text: "React" }`가 된다. `label`이 없으니 `props.label`은 `undefined`가 되어 **빈 배지**가 된다 (`<span>`은 있고 글자만 없음)

### 문제 2 — ✅ (4군데 모두 찾음)
- 30줄 `movieCard` → `MovieCard` — "컴포넌트는 대문자로 시작" ✅
- 33줄 `<h2>props.title</h2>` → `<h2>{props.title}</h2>` — "JSX에서 변수는 `{}`" ✅
  - 표에는 34줄로 적음 (34줄은 `<p>{props.genre}</p>`). 고친 코드가 정확해서 감점 안 함
- 37줄 뒤(표에는 38줄) 빠진 `export default MovieCard;` — "App으로 보내는 export가 생략됨" ✅
- 39줄 `./component/` → `./components/` — "경로의 폴더 이름이 정확해야 함" ✅
- 참고: 소문자 이름이 안 되는 이유 — JSX에서 `<movieCard />`처럼 소문자로 쓰면 React는 `div`, `p` 같은 **HTML 태그**로 여긴다. 그래서 컴포넌트 이름은 대문자로 시작한다

### 문제 3 — ✅
- "3번 복사하면 카드 모양을 바꿀 때 3곳 모두 고쳐야 함. 컴포넌트 하나로 만들면 한 곳만 바꿔서 관리할 수 있다" → 정답 (한 곳 수정)
- 참고: **props** 쪽 장점을 한 문장 더하면 완성 — "내용만 props로 바꿔 넣어서 **같은 모양, 다른 내용**의 카드를 여러 개 만들 수 있다"

### 문제 4 — ✅
- 빌드(`vite build`)·ESLint 오류 없음
- 요구사항 체크
  - ✅ `src/components/ProfileCard.jsx` 3줄 `function ProfileCard(props)` — 대문자, 파일 안 바깥에 정의
  - ✅ 5~8줄 `<div className="card">` 안에 `<h2>이름: {props.name}</h2>`, `<p>소개: {props.intro}</p>`
  - ✅ 12줄 `export default ProfileCard;`
  - ✅ `App.jsx` 2줄 `import "./App.css";`, 4줄 `import ProfileCard from "./components/ProfileCard.jsx";` — export·import 짝, 경로 맞음
  - ✅ 9~11줄 `ProfileCard` 3번, 이름 한코딩·파이썬·자바 (별명)
  - ✅ 보내는 `name`·`intro` = 받는 `props.name`·`props.intro`
  - ✅ 카드 3장 모두 같은 `.card` 모양
- 참고: 10·11줄 `intro`가 둘 다 `"백엔드 도구 1"`로 같음 (복사 후 안 고친 것으로 보임). `name`이 달라서 재사용은 확인됨, 감점 안 함

제출한 코드 (사본: 이 폴더의 `App.jsx`, `components/ProfileCard.jsx`, `App.css`):
```jsx
// src/components/ProfileCard.jsx
function ProfileCard(props) {
  return (
    <div className="card">
      <h2>이름: {props.name}</h2>
      <p>소개: {props.intro}</p>
    </div>
  );
}

export default ProfileCard;
```
```jsx
// src/App.jsx
import "./App.css";

import ProfileCard from "./components/ProfileCard.jsx";

function App() {
  return (
    <div>
      <ProfileCard name="한코딩" intro="프론트엔드 개발자" />
      <ProfileCard name="파이썬" intro="백엔드 도구 1" />
      <ProfileCard name="자바" intro="백엔드 도구 1" />
    </div>
  );
}

export default App;
```

## 정답

### 문제 1
`HTML`, `CSS`, (빈 배지). 세 번째는 `label`이 아니라 `text`로 보냈는데 `Badge`는 `props.label`을 읽으므로 값이 `undefined`라서 아무 글자도 안 보인다.

### 문제 2
| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 30 | `function movieCard(props)` | `function MovieCard(props)` | 소문자로 시작하면 HTML 태그로 여긴다. 컴포넌트는 대문자 |
| 33 | `<h2>props.title</h2>` | `<h2>{props.title}</h2>` | `{}`가 없으면 글자 그대로 나온다 |
| 37 뒤 | (빠짐) | `export default MovieCard;` | 내보내야 다른 파일에서 `import`할 수 있다 |
| 39 | `"./component/MovieCard.jsx"` | `"./components/MovieCard.jsx"` | 폴더 이름이 `components`다. 경로가 틀리면 파일을 못 찾는다 |

### 문제 3
카드를 복사해 붙이면 모양을 바꿀 때 복사한 곳을 모두 고쳐야 하지만, 컴포넌트로 만들면 **한 곳만** 고치면 된다. 그리고 바뀌는 내용(이름·소개)만 **props로 넣어 주면** 같은 틀로 다른 내용의 카드를 여러 개 만들 수 있다.
