## 문제 1 (코드 읽기)

화면에 보이는 배지 글자 3개를 쓰고, 세 번째 배지가 왜 그렇게 보이는지 한 줄로 쓰세요.
function Badge(props) {
  return <span className="badge">{props.label}</span>;
}

function App() {
  return (
    <div>
      <Badge label="HTML" />
      <Badge label="CSS" />
      <Badge text="React" />
    </div>
  );
}

- React는 안뜸. 이유는 text라는 객체로 설정됨.
- Badge는 laberl만 객체로 연결이 됨.

## 문제 2 (버그 찾기)

App.jsx에서 MovieCard를 가져와 영화 카드 하나를 보여 주려는데 버그가 4개 있어요.
- 두 파일을 답안.md에 붙여 넣고 표로 쓰세요.
- 줄 번호는 답안.md 기준이에요.
- 빠진 줄도 버그 하나로 쳐요.
- 파일 위치는 src/components/MovieCard.jsx와 src/App.jsx예요.

src/components/MovieCard.jsx
function movieCard(props) {
  return (
    <div className="card">
      <h2>props.title</h2>
      <p>{props.genre}</p>
    </div>
  );
}
src/App.jsx
import MovieCard from "./component/MovieCard.jsx";

function App() {
  return (
    <div>
      <MovieCard title="첫 번째 영화" genre="애니메이션" />
    </div>
  );
}

export default App;

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 34 | <h2>props.title</h2> | <h2>{props.title}</h2> | 변수는 태그 안에서 {} 로 해야 JSX에서 읽힘 |
| 30 |function movieCard(props) | function MovieCard(props) | 컴포넌트는 첫 알파벳 대문자로 시작해야함 |
| 38 | ___ | export default MovieCard; | 컴포넌트에서 App로 보내는 export가 생략됨| 
| 39 | import MovieCard from "./component/MovieCard.jsx"; | import MovieCard from "./components/MovieCard.jsx"; | 컴포넌트 불러올때 경로 디렉토리가 정확히 입력되어야함.


## 문제 3 (설명하기)

카드 코드를 세 번 복사해서 붙이는 것과 비교해서, 컴포넌트 + props로 만들면 무엇이 좋은지 내 말로 2~3문장으로 설명하세요.

- 카드 코드를 3번 복사해서 붙이면 카드모양을 바꿀때, 3곳 모두 고쳐야함.
- 컴포넌트 하나로 만들면 한곳만 바꿔서 관리할 수 있다.
