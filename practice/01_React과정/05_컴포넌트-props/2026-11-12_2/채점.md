## 1차 제출 기록 (2026-11-12 15:04)

### 문제 1 — 🔺
- 표: ① `React` / `3시간` / `props 복습`, ② `today` / `21시간` / `메모 없음`, ③ `CSS` / `2시간` / `(빈칸)` → 9칸 모두 정답 (`"today"` 글자 그대로, `"2" + 1` 이어 붙이기, 기본값, `""`는 기본값 안 나옴 함정까지)
- 빠진 것: 문제의 둘째 요구 — ② 내일 목표, ③ 메모가 **왜** 그렇게 나오는지 한 줄씩
- 힌트: 개념정리 2부 ⑤의 `"3"` vs `{3}` 표, ⑧의 "부모가 보낸 값" 표

### 문제 2 — ✅ (4군데 모두 찾음)
- 39줄 `MenuCard(name, price)` → `MenuCard({name, price})` — "구조 분해는 `{}`로 묶어야 함" ✅
- 44줄 `props.price + 500` → `price + 500` — "구조 분해했는데 `props.`로 읽으면 안 읽힘" ✅
- 50줄 `props.text = …` 삭제 + 58줄 `text="할인"` → `text="오늘만 할인"` — "자식은 수정하지 않고 표시만, 값은 부모 App에서" ✅
- 57줄 `price="4500"` → `price={4500}` — "따옴표 안이면 문자열, 숫자는 `{}`" ✅
- 고친 코드를 연습장에서 `components/MenuCard.jsx`·`SaleBadge.jsx`로 나눠 직접 확인함. 빌드·ESLint 오류 없음 (사본: `문제2_확인/`)
- 참고: 39줄의 `{}`가 없으면 첫 번째 매개변수 `name`에 **props 객체 전체**가 들어간다. 그래서 `{name}`을 화면에 그릴 때 오류가 난다

### 문제 3 — ✅
- (1) a O · b X · c O · d X → 모두 정답
  - 참고: a·c의 이유가 "어떻게 나누는지"(컴포넌트 하나 + 내용은 App)로 적힘. 기준 표 말로는 "**같은 구조가 여러 번 반복**되니까"
- (2) "자식은 props를 읽기만 하고 바꾸지 않음, 바꾸려면 부모 App에서 내용을 작성" → 다른 값 보여 주는 방법 ✅, 역할 나눔(값은 부모가 정함) ✅
  - 참고: "왜"를 한 줄 더하면 완성 — 값을 정하는 건 부모라서, 자식이 바꾸면 어디서 바뀌었는지 찾기 어렵다. 개발 중에는 React가 막아서 `TypeError`가 난다

## 2차 제출 기록 (2026-11-12 15:17)

### 문제 1 — ✅
- ② "문자열 2와 숫자 1이 더해져서 21" ✅ — 문자열 + 숫자는 이어 붙이기
- ③ "문자열 `""`이 그대로 반영, 문자열 자체가 빈칸" ✅ — 빈 글자를 **보냈으니** 그 값이 쓰인다
  - 참고: 한 단계 더 — 기본값은 **안 보냈을 때(`undefined`)만** 쓰인다. `""`는 "값을 보낸 것"이라 기본값으로 바뀌지 않는다

### 문제 4 — ✅ (첫 제출)
- 빌드·ESLint 오류 없음. 화면을 그려서 확인함:
  - 카드 1: `이름: 한코딩` / `소개: 프론트엔드 개발자입니다.` / `목표 3 → 다음 주 4개`
  - 카드 2: `이름: 파이썬` / `소개: 소개를 준비하고 있습니다.` / `목표 5 → 다음 주 6개`
  - 카드 3: `이름: 자바` / `소개: 백엔드 도구2` / `목표 2 → 다음 주 3개`
- 요구사항 체크
  - ✅ `ProfileCard.jsx` 1줄 `{name, intro = "소개를 준비하고 있습니다.", goalCount}` — 구조 분해 + 기본값, 본문에 `props.` 없음
  - ✅ 4~6줄 `<h2>` 이름, `<p>` 소개, `<p>` 목표 → `{goalCount + 1}`
  - ✅ `App.jsx` 5줄 `const myName = "한코딩"`, 9줄 `name={myName}`
  - ✅ 12줄 카드 2는 `intro` 없이 → 기본값 표시
  - ✅ `goalCount={3}`·`{5}`·`{2}` 숫자로 전달 → 4·6·3 (이어 붙지 않음)
  - ✅ props 값을 바꾸지 않음, 카드 3장 `.card` 유지
- 참고: 6줄 `목표 {goalCount}  →`에 "개"가 빠짐 (문구 차이, 감점 안 함). 15줄 `intro = "…"`처럼 `=` 앞뒤에 띄어쓰기를 해도 동작하지만 보통은 붙여 쓴다
- 참고: 연습장에 쓰지 않는 `components/SaleBadge.jsx`가 남아 있음 (동작과 무관)

## 정답

### 문제 1
| 카드 | 제목 | 내일 목표 | 메모 |
|---|---|---|---|
| ① | React | 3시간 | props 복습 |
| ② | today | 21시간 | 메모 없음 |
| ③ | CSS | 2시간 | (빈칸) |

- ② `hours="2"`는 문자열이라 `"2" + 1`이 이어 붙어 `"21"`이 된다 (`subject="today"`도 변수가 아니라 글자 그대로)
- ③ `memo=""`는 빈 글자를 **보낸 것**이다. 기본값은 안 보냈을 때(`undefined`)만 쓰이므로 빈칸이 된다

### 문제 2
| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 39 | `function MenuCard(name, price)` | `function MenuCard({ name, price })` | `{}`가 없으면 `name`에 props 객체 전체가 들어간다 |
| 44 | `{props.price + 500}` | `{price + 500}` | 구조 분해로 받으면 `props`라는 변수가 없다 |
| 50·58 | `props.text = "오늘만 할인";` / `text="할인"` | 50줄 삭제, `<SaleBadge text="오늘만 할인" />` | props는 읽기 전용. 다른 값은 부모가 보낸다 |
| 57 | `price="4500"` | `price={4500}` | 따옴표면 문자열이라 `"4500" + 500` → `4500500` |

### 문제 3
- (1) a O (같은 구조 12번 반복) · b X (한 번만 쓰는 제목 한 줄) · c O (같은 구조의 후기가 여러 개) · d X (문장 하나)
- (2) 값을 정하는 건 부모라서, 자식이 직접 바꾸면 어디서 값이 바뀌었는지 찾기 어렵다 (개발 중에는 React가 막아 오류가 난다). 다른 값을 보여 주려면 부모가 보내는 props 값을 바꾼다

### 문제 4 (모범 답안)
```jsx
// src/components/ProfileCard.jsx
function ProfileCard({ name, intro = "소개를 준비하고 있습니다.", goalCount }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>{intro}</p>
      <p>목표 {goalCount}개 → 다음 주 {goalCount + 1}개</p>
    </div>
  );
}

export default ProfileCard;
```
```jsx
// src/App.jsx
import "./App.css";
import ProfileCard from "./components/ProfileCard.jsx";

function App() {
  const myName = "한코딩";

  return (
    <div>
      <ProfileCard name={myName} intro="프론트엔드를 공부합니다." goalCount={3} />
      <ProfileCard name="파이썬" goalCount={5} />
      <ProfileCard name="자바" intro="백엔드를 공부합니다." goalCount={2} />
    </div>
  );
}

export default App;
```

## 잘한 점
- 2부 함정(`"today"`, `"2" + 1`, `""`와 기본값)을 표 예측에서 첫 제출에 모두 맞힘
- 버그 4개를 찾은 뒤 연습장에서 파일로 나눠 직접 돌려 확인함
- 구조 분해 + 기본값 + 변수·숫자 `{}` 전달을 한 번에 동작시킴 (기본값이 카드 2에만 나옴)
