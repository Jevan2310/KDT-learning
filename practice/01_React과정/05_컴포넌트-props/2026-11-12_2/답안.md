## 문제 1 (코드 읽기)

카드 3장에 보이는 글자를 표에 채우세요. 빈칸이면 (빈칸)이라고 쓰면 돼요. 그다음 ② 카드의 내일 목표와 ③ 카드의 메모가 왜 그렇게 나오는지 한 줄씩 쓰세요.
function StudyCard({ subject, hours = 1, memo = "메모 없음" }) {
  return (
    <div className="card">
      <h2>{subject}</h2>
      <p>내일 목표: {hours + 1}시간</p>
      <p>{memo}</p>
    </div>
  );
}

function App() {
  const today = "React";

  return (
    <div>
      <StudyCard subject={today} hours={2} memo="props 복습" />
      <StudyCard subject="today" hours="2" />
      <StudyCard subject="CSS" memo="" />
    </div>
  );
}
| 카드 | 제목 | 내일 목표 | 메모 |
|---|---|---|---|
| ① | React | 내일 목표: 3시간 | props 복습 |
| ② | today | 내일 목표: 21시간 | 메모 없음 |
| ③ | CSS | 내일 목표: 2시간 | (빈칸) |

- 문자열 2와 숫자 1이 더해져서 21
- 문자열 ""이 그대로 반영. 즉 문자열 자체가 빈칸임.

## 문제 2 (버그 찾기)

아메리카노 카드와 할인 배지를 보여 주려고 해요. 카드에는 가격 4500원과 사이즈업 5000원이 나오고, 배지에는 "오늘만 할인"이 나와야 해요. 그런데 버그가 4개 있어요.
- 코드를 답안.md에 붙여 넣고 표에 쓰세요. 줄 번호는 답안.md 기준이에요.
- 고칠 곳이 두 줄에 걸치면 고친코드 칸에 둘 다 써도 돼요.

function MenuCard(name, price) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>가격: {price}원</p>
      <p>사이즈업: {props.price + 500}원</p>
    </div>
  );
}

function SaleBadge(props) {
  props.text = "오늘만 할인";
  return <span className="badge">{props.text}</span>;
}

function App() {
  return (
    <div>
      <MenuCard name="아메리카노" price="4500" />
      <SaleBadge text="할인" />
    </div>
  );
}

export default App;
| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 39 | function MenuCard(name, price) | function MenuCard({name, price}) | 구조분해 할당시 {} 중괄호로 묶어야함.|
| 44 | <p>사이즈업: {props.price + 500}원</p> | <p>사이즈업: {price + 500}원</p> | 구조분해 할당했는데 props.xxx하면 안읽힘.|
| 50 |   props.text = "오늘만 할인"; | 삭제 | 자녀 컴포넌트에서는 변수를 수정하지 않고 화면 표시만 함|

| 58 | <SaleBadge text="할인" /> | <SaleBadge text="오늘만 할인" /> | 부모 App에서 변수내용 부여| 
| 57 | <MenuCard name="아메리카노" price="4500" /> | <MenuCard name="아메리카노" price={4500} /> | 숫자는 중괄호 안에 넣어야 숫자로 읽힘 ""안에 있으면 문자열로 처리됨

## 문제 3 (설명하기)

(1) 쇼핑몰 화면을 만든다고 할 때, 아래 4개를 각각 컴포넌트로 나눌지 O/X와 이유를 쓰세요.
- a. 사진, 이름, 가격이 있는 같은 모양의 상품 카드 12개
- b. 페이지 맨 위의 <h1>오늘의 특가</h1> 한 줄
- c. 작성자, 별점, 내용이 있는 후기가 상품마다 여러 개
- d. 페이지 맨 아래의 안내 문장 <p> 하나

| 보기 | 나눌까(O/X) | 이유 |
|---|---|---|
| a | 나눔 | 상품카드 하나의 컴포넌트를 만들고 안에 내용을 App.jsx에 관리 |
| b | 안나눔 | App.jsx 하나만 작성하면되고 수가 하나여서 해당 기능만 작성하는게 오히려 심플|
| c | 나눔 | 후기라는 컴포넌트를 하나로 다루고 App.jsx에서 후기내용을 관리 |
| d | 안나눔 | 페이지 맨아래 하나 문장이므로 해당 문장만 하나 작성하는게 심플 |

(2) 자식 컴포넌트가 받은 props를 직접 바꾸면 안 되는 이유를 쓰세요. 그리고 화면에 다른 값을 보여 주고 싶을 때는 어떻게 하는지 함께 1~2문장으로 쓰세요.
- 자식 컴포넌트는 props를 읽기만 하고 바꾸지 않음.
- props 를 바꾸려면 부모 App.jsx에서 내용을 작성해야함.
