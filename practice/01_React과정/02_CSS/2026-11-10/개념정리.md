## 2부

### ④ 선택자 — "누구에게" 적용할지 고르기

**무엇인지**
선택자는 CSS 규칙의 맨 앞에 와서 **어느 요소에 스타일을 줄지** 고르는 부분이다. 1부에서 쓴 `h1`, `p`는 태그 이름으로 고르는 **태그 선택자**였다.

**왜 필요한지**
`p { color: blue; }`는 페이지의 **모든 p**를 바꾼다. "소개 문장 하나만 파랗게" 하고 싶다면? 그 요소에 HTML로 **이름표**를 붙이고, CSS에서 그 이름표로 고르면 된다. 이 이름표가 `class`와 `id`다.

🏫 **비유**: 학교 공지
- 태그 선택자 = "**모든 학생**은 …" — 전원에게
- 클래스 선택자 = "**축구부**는 …" — 같은 동아리 여러 명에게
- ID 선택자 = "**학번 2401번**은 …" — 딱 한 명에게

**어떻게 쓰는지**

1) **태그 선택자** — 태그 이름 그대로
```css
p {
  color: gray;
}
```
→ 모든 `p`가 회색

2) **클래스 선택자** — HTML에 `class` 속성으로 이름을 붙이고, CSS에서 **점(`.`) + 이름**으로 고른다
```html
<p class="intro">직접 사용하는 서비스를 만들고 싶습니다.</p>
<p>저는 웹 개발을 공부하고 있습니다.</p>
```
```css
.intro {
  color: blue;
}
```
→ `class="intro"`가 붙은 첫 번째 p만 파랑. 두 번째 p는 그대로.
- 같은 클래스를 **여러 요소**에 붙일 수 있다. 다른 문단에도 `class="intro"`를 붙이면 그 문단도 파래진다. 태그가 달라도 된다 (`<h2 class="intro">`).

3) **ID 선택자** — HTML에 `id` 속성, CSS에서 **샵(`#`) + 이름**
```html
<h1 id="page-title">한코딩의 자기소개</h1>
```
```css
#page-title {
  color: purple;
}
```
- id는 **문서에서 하나만** 쓴다. 같은 id를 두 요소에 붙이지 않는다.
- 🔗 HTML 3회차의 `label for="email"` ↔ `input id="email"`이 바로 이 id다. id가 문서에 하나뿐이라서 label이 정확히 그 입력 칸을 찾을 수 있었다.

4) **전체 선택자 `*`** — 모든 요소. 박스 모델(CSS #7)에서 `* { box-sizing: border-box; }`로 쓴다. 지금은 "모든 요소"라는 뜻만 알면 된다.

| 선택자 | HTML 쪽 | CSS 쪽 | 대상 |
|---|---|---|---|
| 태그 | `<p>` (그대로) | `p` | 모든 p |
| 클래스 | `class="intro"` | `.intro` | intro 이름표가 붙은 요소 전부 (여러 개 가능) |
| ID | `id="page-title"` | `#page-title` | 그 id를 가진 요소 하나 |
| 전체 | — | `*` | 모든 요소 |

⚠️ HTML에는 점·샵을 **붙이지 않는다.** 점·샵은 CSS에서 "이건 클래스야 / id야"라고 알려주는 표시다.

**어느 것을 쓸까?** 강의는 **클래스 중심**으로 쓴다.
- 태그 선택자: 페이지 전체의 기본 모양 (예: `body`, 모든 `h2`)
- 클래스: 특정 요소들만 꾸밀 때. 여러 곳에 다시 쓸 수 있어서 가장 많이 쓴다
- id: 하나뿐이라 다시 쓸 수 없다. label 연결처럼 "딱 하나를 가리킬 때" 쓴다

**이름 짓기**: 클래스·id 이름에는 띄어쓰기를 쓰지 않는다. 여러 단어는 `-`로 잇는다 (`profile-card`, `page-title`). 무슨 역할인지 알 수 있게 짓는다.

**흔한 실수** — "특정 요소만 스타일이 안 먹을 때" 먼저 볼 것
- CSS에서 점을 빼먹음: `intro { }` → "intro라는 **태그**"를 찾는다. 그런 태그는 없으니 아무것도 안 바뀐다
- HTML에 점을 붙임: `class=".intro"` ✗ → `class="intro"` ✓
- 철자가 다름: HTML은 `class="intro"`인데 CSS는 `.into` → 연결되지 않는다
- 같은 id를 여러 요소에 붙임

### ⑤ 규칙이 겹칠 때 — 누가 이길까?

**무엇인지**
한 요소에 규칙 여러 개가 걸리고 **같은 속성**을 서로 다른 값으로 정하면, 하나만 적용된다. 어느 것이 이기는지 정하는 것이 우선순위다.

**왜 알아야 하는지**
실제 CSS는 "모든 문단은 회색" 같은 **넓은 규칙**과 "소개 문장만 파랑" 같은 **좁은 규칙**을 함께 쓴다. 우선순위를 모르면 "분명히 썼는데 왜 색이 안 바뀌지?"에서 막힌다.

**규칙 1 — 더 구체적인 선택자가 이긴다 (클래스 > 태그)**
```css
p {
  color: gray;
}

.intro {
  color: blue;
}
```
```html
<p class="intro">소개 문장</p>
<p>보통 문장</p>
```
→ 소개 문장은 **파랑**, 보통 문장은 **회색**.
- `p`는 "모든 문단", `.intro`는 "intro 이름표가 붙은 것만" → 더 좁게 콕 집은 쪽이 **더 구체적**이다.
- 🏫 "모든 학생은 체육복"과 "축구부는 축구 유니폼"이 같이 있으면, 축구부 학생은 유니폼을 입는다.
- 구체성이 다르면 **순서와 상관없다.** `.intro`를 위에, `p`를 아래에 써도 결과는 같다.

> 💡 보충: id 선택자는 클래스보다도 더 구체적이다 (id > 클래스 > 태그).

**규칙 2 — 구체성이 같으면 뒤에 쓴 것이 이긴다**
```css
h1 {
  color: blue;
}

h1 {
  color: purple;
}
```
→ 제목은 **보라색**. 둘 다 태그 선택자라 구체성이 같으니 나중 공지를 따른다.

**겹치는 속성만 겨룬다 — 다른 속성은 합쳐진다**
```css
p {
  color: gray;
  font-size: 18px;
}

.intro {
  color: blue;
}
```
→ `<p class="intro">`의 `color`는 `.intro`가 이겨서 파랑. `font-size`는 겨룰 상대가 없으니 `p` 규칙대로 **18px**.
이긴 규칙이 진 규칙 **전체를 지우는 것이 아니다.** 같은 속성끼리만 겨룬다.

**상속 — 부모의 스타일이 자식에게 내려간다**
HTML은 요소 안에 요소가 들어가는 구조다 (HTML #11 중첩). 바깥 요소를 **부모**, 안에 들어 있는 요소를 **자식**이라고 한다. `body` 안의 `h1`, `p`, `li`는 모두 `body`의 자식이다 (더 깊이 들어 있어도 마찬가지).
```css
body {
  color: #334155;
  font-family: sans-serif;
}
```
→ `h1`, `p`, `li`에 따로 쓰지 않아도 **모두** 이 글자색·글꼴이 된다. 그래서 페이지의 기본 글자 모양을 `body` 한곳에서 정한다.
- **모든 속성이 상속되지는 않는다.** 글자 관련(색, 글꼴, 크기, 줄 높이)은 내려가지만, 여백(`margin`, `padding`)·테두리(`border`)는 내려가지 않는다. body에 테두리를 줬는데 모든 문단에 테두리가 생기면 곤란하니까.
- **직접 건 규칙이 상속보다 우선한다.** `body { color: #334155; }`와 `p { color: gray; }`가 있으면 p는 회색이다. 부모에게 물려받은 값보다 나에게 직접 준 값이 이긴다.

| 상황 | 이기는 것 |
|---|---|
| 태그 vs 클래스 | 클래스 (더 구체적) |
| 같은 종류끼리 | 뒤에 쓴 것 |
| 부모에게 물려받은 값 vs 나에게 직접 건 규칙 | 직접 건 규칙 |
| 서로 다른 속성 | 겨루지 않고 둘 다 적용 |

**화면에서 확인하기 — 개발자 도구 (F12)**
요소를 고르면 오른쪽에 그 요소에 걸린 규칙이 모두 보이고, **진 선언에는 줄이 그어져** 있다. "왜 이 색이지?" 할 때 본다. 개발자 도구에서 바꾼 값은 파일에 저장되지 않는다.

**흔한 실수**
- 색이 안 바뀌면 오타만 찾는다 → **다른 규칙에 졌을 수도** 있다
- 이긴 규칙이 진 규칙의 다른 속성까지 없앤다고 생각한다
- 모든 속성이 상속된다고 생각한다

### ⑥ 글자·배경 꾸미기

**무엇인지** — 글자와 배경의 모양을 바꾸는 속성들이다.

| 속성 | 바꾸는 것 | 예 |
|---|---|---|
| `color` | 글자색 | `color: #2563eb;` |
| `background-color` | 배경색 | `background-color: #f1f5f9;` |
| `font-size` | 글자 크기 | `font-size: 28px;` |
| `font-weight` | 글자 굵기 | `font-weight: bold;` |
| `font-family` | 글꼴 | `font-family: sans-serif;` |
| `line-height` | 줄 높이 (줄 간격) | `line-height: 1.6;` |
| `text-align` | 요소 안 글 정렬 | `text-align: center;` |

**강의 예제**
```css
body {
  background-color: #f1f5f9;
  color: #334155;
  font-family: sans-serif;
  line-height: 1.6;
}

h1 {
  color: #2563eb;
  font-size: 28px;
}

h2 {
  font-size: 20px;
}
```
→ 페이지 바탕은 연한 회색, 글자는 짙은 회청색, 고딕 계열 글꼴, 줄 간격은 넉넉하게. 제목만 파랗고 크게.
- `body`에 기본 글자 모양을 한 번 주고(⑤ 상속), 다르게 보여야 할 것(h1, h2)만 따로 덮어쓴다.

**색 쓰는 법 두 가지**
- **이름**: `blue`, `red`, `gray`, `white` … 쉽지만 종류가 적다
- **색상 코드**: `#` + 6자리 (예: `#2563eb`). 앞 2자리는 빨강, 가운데 2자리는 초록, 뒤 2자리는 파랑의 **양**이다. 0~9, a~f로 쓰고 `00`이 가장 적고 `ff`가 가장 많다.
  - `#000000` 검정 (셋 다 없음), `#ffffff` 흰색 (셋 다 가득), `#ff0000` 빨강
  - 외울 필요는 없다. 색 고르는 도구나 디자인에서 복사해 쓴다
- ⚠️ `#`가 두 군데 나온다: 선택자 자리의 `#page-title`은 **id**, 값 자리의 `#2563eb`는 **색**이다. 위치로 구분한다.

**크기 단위 `px`**
- 화면의 점 하나 크기를 뜻하는 단위다.
- 숫자와 `px`를 **붙여 쓴다**: `28px` ✓ / `28 px` ✗ / `28` ✗ (단위가 없으면 적용되지 않는다)

> 💡 보충: 브라우저의 기본 글자 크기는 보통 16px이다.

**`line-height`는 단위 없이**
- `line-height: 1.6` = 글자 크기의 **1.6배**를 줄 높이로 쓴다. 글자가 16px이면 줄 높이는 25.6px.
- 글자 크기를 바꿔도 비율대로 따라가서 편하다. `1`은 빽빽하고, `1.6`~`1.8`은 읽기 편하다.

**`font-family`와 대체 글꼴**
- `font-family: sans-serif;` → 고딕(획 끝에 장식이 없는) 계열 글꼴.
- 쉼표로 여러 개를 쓰면 **앞에서부터** 쓸 수 있는 것을 쓴다: `font-family: "폰트이름", sans-serif;` → 폰트이름을 못 쓰면 sans-serif. 웹폰트(CSS #10)에서 다시 나온다.

**`font-weight`**: `bold`(굵게), `normal`(보통). h1~h6은 기본이 굵다.

**`text-align`**: `left` / `center` / `right`. 요소 **안의 글**을 정렬한다. 요소(상자) 자체를 가운데로 옮기는 것이 아니다. 상자를 가운데 놓는 법은 박스 모델(CSS #7)에서 배운다.

**흔한 실수**
- 단위를 빠뜨리거나 띄어 씀: `font-size: 28;`, `28 px`
- `#`를 빠뜨림: `color: 2563eb;`
- 속성 이름 철자: `backgroud-color`, `font-szie` → 그 줄만 조용히 무시된다 (오류 메시지도 없다)
- 글자색과 배경색이 비슷해서 글이 안 보임

### 🔁 복습 포인트 (복습 대기열)

- **`link`는 종료 태그 없음** (HTML #2): 감쌀 글자가 없는 요소는 종료 태그가 없다. `<link ...>` 한 줄로 끝.
- **모양 vs 태그** (HTML #9): 태그는 **하는 일**로 고르고, 모양은 CSS가 맡는다. 버튼처럼 보여야 해도 이동하는 링크는 `a`.
- **HTML 속성 vs CSS 속성** (CSS #2): `color`, `font-size`는 CSS 속성이라 태그에 바로 못 쓰고 CSS 파일·`<style>`·`style` 속성 안에 쓴다. 반대로 오늘 배운 `class`, `id`는 **HTML 속성**이다.
- **이유를 한 문장으로** (공통): "무엇이 틀렸다"에서 멈추지 말고 "**왜** 안 되는지"까지.
- **마무리 확인** (공통): 제출 전에 `lang`, 파일 이름·태그 철자, 버그 개수 세어 보기.
