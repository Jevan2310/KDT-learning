## 문제 2 (코드 읽기)

style.css
body {
  color: black;
  font-size: 16px;
}

p {
  color: gray;
}

.note {
  color: green;
  font-size: 20px;
}

p {
  color: navy;
}

index.html의 <body> 안
<p>A</p>
<p class="note">B</p>
<div>C</div>
<div class="note">D</div>

A, B, C, D 각각의 글자색과 글자 크기를 쓰고, 이유를 한 줄씩 써 주세요. 이유에는 어느 규칙이 이겼는지, 아니면 어디서 물려받았는지를 쓰면 돼요.

- A: 색 네이비 / 크기 16px — 이유: p태그를 보면 색이 회색이랑 남색이 있는데, 더 아래있는것이 우선순위
p태그에는 폰트 사이즈가 없어 베이스인 body태그의 폰트가 그대로 이어짐.
- B: 색 그린 / 크기 20픽셀 - 이유: 바디, 태그, 모다 클래스가 가장 구체적이라서 먼저 우선됨
- C: 색 블랙 / 크기 16픽셀 - 이유: diV 태그 없음. id나 클래스 없음 따라서 바디태그 css가 적용됨
- D: 색 그린 / 크기 20픽셀 - 이유: div 태그없음. 클래스 우선 이라서 note 클래스의 속성이 적용됨

## 문제 5 (설명하기)

1. 친구가 이렇게 썼어요.
.intro {
  color: blue;
}

p {
  color: gray;
}
   그리고 이렇게 물어요. "뒤에 쓴 게 이긴다면서, 왜 <p class="intro">는 회색이 아니라 파란색이야?" 친구에게 설명해 주세요.

- 태그보다 클래스가 구체적이어서 클래스가 우선이야. 뒤에 쓰는게 이기는 것은 같은 태그/클래스/id 일때만 해당돼.

2. 🔁 class와 color는 둘 다 "속성"이라고 불러요. 둘은 무엇이 다른가요? 각각 어디에 쓰는지 예를 하나씩 들어 설명해 주세요.

- class 는 html에서 요소를 그룹화 한다. <p class = "intro">html의 속성은 이런식으로 쓰임
- color는 css에서 모양을 바꿔준다. p { color : red;} css는 이런식으로 쓰임.

- 잘모르겟어. 설명해줘
