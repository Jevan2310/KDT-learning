## 1부

### ① CSS란?

**무엇인지**
CSS(Cascading Style Sheets)는 HTML 요소가 **어떻게 보일지** 정하는 언어다. 색, 글자 크기, 글꼴, 간격, 배치 같은 것들이다.

**왜 필요한지**
HTML만 쓰면 브라우저가 정한 기본 모양으로만 보인다. 흰 바탕, 검은 글씨, 기본 글꼴. HTML 1회차에 만든 `index.html`을 열었을 때 모습이 바로 그것이다. CSS는 여기에 **옷을 입힌다.**

🏠 **비유**: HTML은 집의 **뼈대와 방 구성**이다 ("여기는 거실, 여기는 부엌"). CSS는 **벽지·가구·조명**이다. 뼈대는 그대로 두고 인테리어만 바꿀 수 있다.

| 바꾸고 싶은 것 | 담당 |
|---|---|
| 자기소개 문장, 목록 항목 추가 | HTML (내용) |
| 제목의 색과 크기 | CSS (모양) |
| 카드의 배경색과 여백 | CSS |
| 이미지의 크기와 모양 | CSS |

🔗 HTML 1회차 문제 6에서 이렇게 썼다. "글씨 크기는 추후에 CSS로 관리가 가능하다. 따라서 h 태그는 글의 구조를 구분하기 위함이다." 그 **CSS**를 이제 배운다.

### ② CSS를 HTML에 붙이는 세 가지 방법

"제목을 파란색으로" 하는 같은 스타일을 세 가지 방법으로 쓸 수 있다.

**1) 인라인 스타일**: 태그에 `style` 속성을 직접 쓴다
```html
<h1 style="color: blue;">안녕하세요!</h1>
```

**2) 내부 스타일**: `<head>` 안에 `<style>` 태그를 두고 그 안에 쓴다
```html
<head>
  <style>
    h1 {
      color: blue;
    }
  </style>
</head>
```

**3) 외부 스타일**: CSS를 **별도 파일**(`style.css`)에 쓰고, HTML에서 연결한다
```html
<!-- index.html의 <head> 안 -->
<link rel="stylesheet" href="style.css">
```
```css
/* style.css */
h1 {
  color: blue;
}
```

| 방법 | 어디에 쓰나 | 적용 범위 | 특징 |
|---|---|---|---|
| 인라인 | 태그의 `style` 속성 | 그 요소 **하나** | 빠르지만 요소가 많아지면 관리가 어렵다 |
| 내부 | `<head>`의 `<style>` | 그 HTML 파일 **하나** | 한 파일 안에서 관리 |
| **외부** | 별도 `.css` 파일 | `link`로 연결한 **모든 페이지** | HTML(내용)과 CSS(모양)를 나눌 수 있다. **강의 실습 방식** |

**왜 외부 스타일을 쓸까?**
- 페이지가 10개여도 CSS 파일 하나만 고치면 **모든 페이지가 한 번에** 바뀐다.
- HTML 파일에는 내용만, CSS 파일에는 모양만 들어가서 **읽기 쉽다.** 역할 나누기다.

**`link` 태그 뜯어보기**

| 부분 | 뜻 |
|---|---|
| `link` | 외부 파일을 연결하는 태그. **종료 태그가 없다** (감쌀 글자가 없으니까. 3회차 기준 그대로) |
| `rel="stylesheet"` | 연결하는 파일이 **스타일 시트(CSS)**라는 뜻 (`rel`은 relation, "관계") |
| `href="style.css"` | 파일 **위치**. `a` 태그의 `href`와 같은 이름이다. 같은 폴더에 있으면 파일 이름만 쓴다 |

```
my-profile/
├── index.html    ← <link rel="stylesheet" href="style.css">
└── style.css     ← 같은 폴더라서 이름만 쓰면 된다
```

**흔한 실수** — CSS가 **통째로** 안 먹을 때 먼저 볼 것
- `href`의 파일 이름과 실제 파일 이름이 다르다 (`style.css` ↔ `styles.css`)
- CSS 파일이 다른 폴더에 있다
- HTML이나 CSS 파일을 **저장**하지 않았다
- `link`를 `<head>` 밖에 썼다 (`<head>` 안에 두는 것이 원칙)

### ③ CSS 문법

```css
h1 {
  color: blue;
  font-size: 28px;
}
```

| 부분 | 이름 | 뜻 |
|---|---|---|
| `h1` | **선택자** | 어느 요소에 적용할지 고른다 ("모든 h1에게") |
| `{ }` | 중괄호 | 이 선택자에 줄 스타일을 묶는다 |
| `color` | **속성** | 무엇을 바꿀지 (글자색) |
| `:` | 콜론 | 속성과 값을 잇는다 |
| `blue` | **값** | 어떻게 바꿀지 (파란색) |
| `;` | 세미콜론 | 선언 하나가 끝났다는 표시 |

- `color: blue;` 한 줄을 **선언**이라고 한다. 한 선택자에 선언을 여러 개 쓸 수 있다.
- 마지막 선언에도 `;`를 붙이는 습관을 들인다. 나중에 줄을 추가할 때 실수가 줄어든다.
- 문장으로 읽으면 이렇다: "**모든 h1**의 **글자색**을 **파란색**으로, **글자 크기**를 **28px**로."

⚠️ **"속성"이 두 번 나온다**

| | HTML 속성 | CSS 속성 |
|---|---|---|
| 예 | `href`, `alt`, `class`, `id` | `color`, `font-size` |
| 어디에 | 태그 안 | CSS 규칙 안 |
| 모양 | `이름="값"` (등호, 따옴표) | `이름: 값;` (콜론, 세미콜론) |
| 예시 | `<a href="https://github.com/">` | `color: blue;` |

**주석**: CSS 주석은 `/* 메모 */`이다. HTML 주석 `<!-- 메모 -->`와 모양이 다르다.

**흔한 실수**
- **세미콜론 빠뜨리기**: `color: blue font-size: 28px;` → 두 줄이 한 덩어리가 돼서 **둘 다** 적용되지 않는다
- **HTML 습관으로 쓰기**: `color="blue"` ✗ → `color: blue;` ✓
- **값에 따옴표**: `color: "blue";` ✗ → 색 이름은 따옴표 없이 쓴다
- **중괄호 짝**: `{`를 열었으면 `}`로 닫는다. HTML 3회차의 "태그 짝 맞추기"와 같은 습관이다
