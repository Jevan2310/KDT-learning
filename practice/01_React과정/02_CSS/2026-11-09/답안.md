## 1 
문제 1 (개념)

아래 A~C는 모두 p 글자를 초록색으로 만드는 코드예요.

A.
<p style="color: green;">오늘의 할 일</p>

B.
<head>
  <style>
    p {
      color: green;
    }
  </style>
</head>

C.
<head>
  <link rel="stylesheet" href="main.css">
</head>
/* main.css */
p {
  color: green;
}

1. A, B, C는 각각 어떤 방법인가요? (방법 이름)
- 첫번째는 인라인 방법
- 두번째는 내부 스타일
- 세번째는 외부 스타일

2. 한 HTML 문서에 p가 3개 있어요. A, B, C 방식으로 썼을 때 각각 몇 개의 p가 초록색이 될까요?
   - A는 첫 번째 p 하나에만 style을 썼다고 생각하세요.

- A는 한개 - 적용된 P 하나만 style이 반영됨.
- B는 p태그 3개 전부
- C도 p태그 3개 전부

문제 5 (설명하기)

친구가 이렇게 썼는데 제목이 파란색이 안 된대요.
<h1 color="blue">안녕하세요</h1>
친구에게 설명하듯 써 주세요.

1. 왜 안 바뀌는지 => 인라인으로 작성된 방법이 잘못됨.
2. 어떻게 고치는지. 세 가지 방법 중 2가지 이상을 코드로 보여 주세요.
인라인    <h1 style="color: blue">안녕하세요</h1>
또는
  <head>
    <style>
        h1 {
            color: blue;
        }
    </style>
  </head>
  <body>
    <h1>안녕하세요</h1>
  </body>

3. 그중 어떤 방법을 추천하고, 왜 그런지
추천은 위에 없는 방법중 외부 스타일 방법을 추천하고, css 코드가 길어질 경우 유지보수 하기 위해 따로 관리하는 것이 좋아보임.
