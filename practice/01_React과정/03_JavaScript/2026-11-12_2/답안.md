
## 문제 1 (코드 읽기)

콘솔에 나오는 값 ①~⑤를 쓰세요.
const book = { title: "처음 배우는 JS", page: 300 };
const fruits = ["사과", "바나나", "포도"];
const members = [
  { name: "한코딩", role: "프론트" },
  { name: "파이썬", role: "백엔드" }
];

function double(num) {
  return num * 2;
}

console.log(book.title);          // ①
console.log(fruits[1]);           // ②
console.log(fruits.length);       // ③
console.log(members[0].role);     // ④
console.log(double(book.page));   // ⑤

1) 처음 배우는 JS
2) 바나나
3) 3
4) 프론트
5) 600


## 문제 2 (버그 찾기)

버튼을 누를 때마다 화면 글자가 "좋아요 1개", "좋아요 2개"…로 바뀌어야 하는데 버그가 3개 있어요.
- HTML에는 버그가 없어요.
- 빠진 줄도 버그 하나로 쳐요.
- JS 코드를 답안.md에 붙여 넣고 표로 쓰세요. 줄 번호는 답안.md 기준이에요.

<p id="like-message">좋아요 0개</p>
<button id="like-button" type="button">좋아요</button>
const likeMessage = document.querySelector("like-message");
const likeButton = document.querySelector("#like-button");

let likeCount = 0;

function addLike() {
  likeCount++;
}

likeButton.addEventListener("click", addLike());

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 38 | "like-message" | "#like-message" | #이 없으면 id를 못읽음 |
| 47 | addLike() | addLike | 함수에 맡기는 형태라서 직접실행이 아니기 때문 |
| 45 | ___ |   likeMessage.textContent = `좋아요 ${likeCount}개`; | 화면에 보이는 텍스트가 안바껴서 좋아요가 오르는게 안보임.|
