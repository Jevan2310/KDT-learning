## 문제 2 (코드읽기)

아래 코드를 실행하면 콘솔에 무엇이 나오는지 ①~④를 쓰세요.
let score = 10;
score += 5;
score++;

const userName = "한코딩";

console.log(score);                              // ①
console.log(`${userName}님 점수: ${score}점`);    // ②
console.log("10" + 5);                           // ③
console.log(11 % 4);                             // ④

## 문제 3 (버그 찾기)

"한코딩님, 첫 응원 감사합니다!"가 콘솔에 나와야 하는데 버그가 3개 있어요. 코드를 답안.md에 붙여 넣고 표로 쓰세요. 줄 번호는 답안.md 기준이에요.

const userName = "한코딩";
const cheerCount = 0;

cheerCount++;

if (cheerCount = 1) {
  console.log('${userName}님, 첫 응원 감사합니다!');
} else {
  console.log("응원해 주세요!");
}

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 34 | const | let cheerCount = 0; | const는 상수라서 변동되면 안됨|
| 39 | '${userName}님, 첫 응원 감사합니다!' | `${userName}님, 첫 응원 감사합니다!`| 작은 따옴표는 안됨 백틱으로 써야함.|
| 38 | cheerCount = 1 | cheerCount === 1 | if 조건에는 불린 형태가 들어가야함.|
