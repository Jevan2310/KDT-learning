## 정답

### 문제 1
| 담을 값 | const / let | 종류 |
|---|---|---|
| a. 사용자 이름 `"한코딩"` | `const` | 문자열 |
| b. 좋아요 수 `0` | `let` | 숫자 |
| c. 로그인 여부 `false` | `let` | 불리언 |
| d. 나이 `"25"` | `const` | **문자열** (따옴표로 감싸면 글자) |

### 문제 2
① `16` (10 → 15 → 16) ② `한코딩님 점수: 16점` ③ `105` (문자열 + 숫자는 이어 붙이기) ④ `3` (11을 4로 나눈 나머지)

### 문제 3
| 원래 코드 | 고친 코드 | 이유 |
|---|---|---|
| `const cheerCount = 0;` | `let cheerCount = 0;` | 값이 바뀌어야 하는데 `const`에는 다시 넣을 수 없다 (`++`에서 TypeError) |
| `if (cheerCount = 1)` | `if (cheerCount === 1)` | `=`는 넣기, `===`가 같은지 비교 |
| `'${userName}님, …'` | `` `${userName}님, …` `` | `${}`는 백틱 안에서만 값으로 바뀐다 |

### 문제 4
브라우저는 HTML을 위에서부터 읽는다. `script`를 `</body>` 바로 위에 두면 요소가 다 만들어진 뒤에 JS가 실행되어 그 요소를 찾을 수 있다. 위에 두면 JS는 실행되지만 아직 없는 요소를 못 찾는다.

### 문제 5 (요구 문구 그대로 맞춘 예)
```javascript
console.log("JavaScript 연결 완료!");

const userName = "한코딩";
let attendCount = 0;

attendCount++;
attendCount++;
attendCount++;

if (attendCount >= 3) {
  console.log(`${userName}님, 출석 ${attendCount}번 완료!`);
} else {
  console.log("출석이 부족해요");
}
```

## 잘한 점
- `"10" + 5` → `105`, `const`에 `++`, `=` vs `===`, 작은따옴표 vs 백틱 등 JS 1부의 함정을 첫 제출에 다 잡음
- 설명하기(문제 4)를 첫 제출에 원리대로 씀. 버그 표의 이유도 모두 원리상 맞음
- 코드 작성에서 `const`/`let`을 값이 바뀌는지에 따라 정확히 고름
