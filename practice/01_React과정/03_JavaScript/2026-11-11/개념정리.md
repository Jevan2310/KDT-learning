## 1부

### ① JavaScript가 하는 일과 연결

**무엇인지**
웹페이지의 **동작**을 맡는 프로그래밍 언어다.

| 기술 | 맡는 일 | 자기소개 페이지에서 |
|---|---|---|
| HTML | 내용 (뼈대) | 소개 문장과 버튼 만들기 |
| CSS | 모양 (옷) | 글자와 버튼 꾸미기 |
| JavaScript | **동작** (움직임) | 버튼을 누르면 소개 문장 바꾸기 |

**어떻게 연결하는지**
`index.html`과 같은 폴더에 `script.js`를 만들고, **`</body>` 바로 위**에 연결한다.
```html
  <script src="script.js"></script>
</body>
```
- 왜 거기냐면: 브라우저는 HTML을 **위에서부터** 읽는다. 맨 아래에 두면 버튼·문단이 다 만들어진 **뒤에** JS가 실행되어 그 요소들을 찾을 수 있다.
- CSS는 `link`(종료 태그 없음), JS는 `<script></script>`(종료 태그 **있음**)다.

**결과 확인 — 콘솔**
```javascript
console.log("JavaScript 연결 완료!");
```
- `console.log()`는 값을 **콘솔**에 출력한다. F12 → **Console** 탭에 글자가 보이면 연결 성공.
- 콘솔은 **개발자용 확인창**이다. 웹페이지 화면에는 아무것도 안 보인다. 화면을 바꾸는 법은 2부 ⑥.
- 오류가 나면 Console에 **빨간 글씨**로 나온다. JS가 안 돌면 Console부터 본다.

**흔한 실수**
- `script`를 `head`에 넣어서 요소를 못 찾는다
- `console.log`를 화면에 글자를 띄우는 것으로 착각한다
- 파일 이름(`script.js`)이 다르거나 저장을 안 했다

### ② 변수 — `const`와 `let`

**무엇인지**
값을 담아 두고 **이름으로 다시 쓰는 상자**다.
```javascript
const userName = "한코딩";

let cheerCount = 0;
cheerCount = 1;
```
읽는 법: `const`(상자를 만든다) `userName`(상자 이름) `=`(넣는다) `"한코딩"`(넣을 값).

| 키워드 | 언제 |
|---|---|
| `const` | 한 번 넣고 **다시 넣지 않을 때** — **기본으로 쓴다** |
| `let` | 나중에 **다른 값을 다시 넣어야 할 때** (횟수, 점수) |
| `var` | 옛날 방식 — **쓰지 않는다** |

```javascript
const userName = "한코딩";
userName = "이개발"; // 오류: const에는 다시 넣을 수 없다
```

**고르는 기준**: 일단 `const`로 쓰고, 값이 바뀌어야 하는 것만 `let`.

**흔한 실수**
- 바뀌어야 하는 횟수를 `const`로 만들어서 오류가 난다
- 습관처럼 전부 `let`으로 쓴다

---

### ③ 값의 종류 (자료형)

| 종류 | 예 | 쓰는 곳 |
|---|---|---|
| 문자열 | `"한코딩"` | 이름·문장 — **따옴표**로 감싼다 |
| 숫자 | `25`, `1.5` | 개수·금액 — 따옴표 없이 |
| 불리언 | `true`, `false` | 참·거짓 (켜짐/꺼짐) — 따옴표 없이 |
| `null` | `null` | **일부러** "값 없음"이라고 표시 |
| `undefined` | `undefined` | **아직** 아무 값도 안 넣음 |

- `25`(숫자)와 `"25"`(문자열)는 **다른 값**이다. 생긴 건 비슷해도 따옴표가 있으면 글자다.
- `null` vs `undefined`: 빈칸에 "없음"이라고 **써 둔 것**이 `null`, 아직 **손도 안 댄 칸**이 `undefined`.

> 💡 보충: `25 + 1`은 `26`(계산)이지만 `"25" + 1`은 `"251"`(글자 이어 붙이기)이 된다. 숫자와 문자열을 구분해야 하는 이유다.

### ④ 값 바꾸기와 템플릿 리터럴

**`=`는 "넣기"다** (수학의 "같다"가 아니다)
```javascript
let count = 0;
count = count + 1;   // 지금 값(0)에 1을 더해서 다시 넣는다 → 1
```
줄여 쓰기 — 셋 다 같은 뜻:
```javascript
count = count + 1;
count += 1;
count++;            // 1 늘리기 (줄이기는 count--)
```

**계산**: `+` `-` `*` `/`, 나머지 `%`
- `11 / 5` → `2.2` (나눈 결과 그대로), `11 % 5` → `1` (나머지)

**템플릿 리터럴 — 문자열 안에 값 끼워 넣기**
**백틱**(`` ` ``, 키보드 숫자 1 왼쪽)으로 감싸고, 넣을 값은 `${ }` 안에 쓴다.
```javascript
const userName = "한코딩";
const message = `${userName}님, 환영합니다!`;

console.log(message);   // 한코딩님, 환영합니다!
```
```javascript
const completedCount = 3;
console.log(`완료한 학습 목표는 ${completedCount}개입니다.`);
```

**흔한 실수**
- 백틱 대신 작은따옴표 `'`를 써서 `${userName}`이 글자 그대로 나온다
- `const`로 만든 값에 `++`를 해서 오류가 난다

### ⑤ 조건문 `if / else` (+ 반복문 맛보기)

**무엇인지**
조건이 **참이면 이 코드, 거짓이면 저 코드**를 실행한다.
```javascript
let cheerCount = 5;

if (cheerCount >= 5) {
  console.log("응원을 많이 받았어요!");
} else {
  console.log("응원해 주세요!");
}
```
→ `cheerCount`가 5라서 "응원을 많이 받았어요!"가 출력된다.

**비교 연산자** — 조건 `( )` 안에 쓴다

| 연산자 | 뜻 |
|---|---|
| `===` | 같은가 (값과 종류까지) |
| `!==` | 다른가 |
| `>` / `<` | 큰가 / 작은가 |
| `>=` / `<=` | 크거나 같은가 / 작거나 같은가 |

⚠️ `=` 하나는 **넣기**, `===` 세 개는 **같은지 묻기**.

**갈래가 여러 개면 `else if`** — 강의 예제(숫자 → 요일)처럼
```javascript
if (num === 1) {
  console.log("월요일");
} else if (num === 2) {
  console.log("화요일");
} else {
  console.log("해당 요일은 존재하지 않습니다.");
}
```
위에서부터 차례로 보고, **처음 참인 곳 하나만** 실행한다.

> 💡 보충: 강의 예제는 `num == 1`(등호 2개)을 썼다. `prompt()`로 받은 값은 문자열(`"1"`)인데, `==`는 종류를 맞춰서 비교해 주기 때문에 동작한다. 기본은 `===`를 쓰고, 문자열을 숫자로 비교하려면 `Number(num) === 1`처럼 바꿔서 비교한다.

**반복문 맛보기 (강의 수업 중 예제)**
```javascript
for (let i = 1; i <= 3; i++) {
  console.log(i);   // 1, 2, 3
}
```
읽는 법: `i`를 1로 시작 ; `i`가 3 이하인 동안 ; 한 바퀴 돌 때마다 1씩 늘린다.
- `continue`: 이번 바퀴만 건너뛰기 / `break`: 반복을 끝내기

**흔한 실수**
- 조건에 `=` 하나를 쓴다 (`if (count = 5)`)
- `{ }` 짝이 안 맞는다

---

### 1부 한 줄 정리
- JS는 **동작**, `</body>` 바로 위에서 연결, 확인은 **Console**
- 변수는 **`const` 기본**, 바뀌는 값만 `let`
- `=`는 넣기, `===`는 비교, 문자열에 값 넣기는 **백틱 + `${}`**

## 2부 (2026-11-12)

### ⑥ DOM — 요소 찾고 글자 바꾸기

**무엇인지**
브라우저는 HTML을 읽어서 JS가 만질 수 있는 구조로 만들어 둔다. 이것이 **DOM**이다. 지금은 "**JS로 HTML 요소를 찾아서 글자를 바꿀 수 있다**"까지만 알면 된다.

**어떻게 쓰는지 — 찾기 → 바꾸기 두 단계**
```html
<p id="intro-message" class="intro">직접 사용하는 서비스를 만들고 싶습니다.</p>
```
```javascript
const introMessage = document.querySelector("#intro-message");   // 1. 찾기
introMessage.textContent = "오늘부터 나의 첫 웹 앱을 만듭니다!";    // 2. 글자 바꾸기
```
→ **웹페이지 화면**의 문장이 바뀐다 (`console.log`와 달리 화면에 보인다).

`querySelector("선택자")` — CSS 선택자와 같은 모양으로 **처음 일치하는 요소 하나**를 찾는다.

| 선택자 | 찾는 것 |
|---|---|
| `"h1"` | 첫 번째 `h1` |
| `".intro"` | `intro` 클래스를 가진 첫 번째 요소 |
| `"#intro-message"` | 이 id를 가진 요소 |

- 강의 방식: `class`는 CSS 꾸미기용으로 두고, JS로 찾을 요소에 `id`를 붙인다.
- `textContent`: 요소 안의 글자를 읽거나 바꾼다.
- 못 찾으면 `null`이 돌아온다. 그 상태로 `.textContent`를 바꾸면 Console에 빨간 오류가 난다.

**흔한 실수**
- `#`을 빼먹는다 (`"intro-message"` → 그런 태그를 찾으니 `null`)
- HTML의 id와 선택자의 철자가 다르다
- `script`를 위에 둬서 요소가 아직 없다 (1부 ①)

### ⑦ 함수 — 코드 묶음에 이름 붙이기

**무엇인지**
여러 줄의 코드를 묶고 이름을 붙여 두는 것. **만들기(선언)와 실행(호출)은 다르다.** 레시피를 써 두는 것과 실제로 요리하는 것이 다른 것처럼.
```javascript
function showMessage() {      // 선언: 만들어 두기만 한다 (아직 실행 안 됨)
  console.log("반갑습니다!");
}

showMessage();                // 호출: 이름 + () → 이때 안의 코드가 실행된다
```

**매개변수 — 함수에 값 건네주기**
```javascript
function greet(name) {
  console.log(`${name}님, 반갑습니다!`);
}

greet("한코딩");   // 한코딩님, 반갑습니다!
greet("이개발");   // 이개발님, 반갑습니다!
```
같은 함수를 값만 바꿔서 여러 번 쓸 수 있다.

**`return` — 결과를 돌려주기**
```javascript
function add(num1, num2) {
  return num1 + num2;
}

const result = add(10, 20);   // 함수가 돌려준 30이 result에 들어간다
console.log(result);          // 30
```

> 💡 보충: `console.log`는 Console에 **보여 주기만** 하고, `return`은 값을 **부른 곳으로 돌려준다**. 결과를 변수에 담아 다시 쓰려면 `return`이 필요하다.

**흔한 실수**
- 선언만 하고 호출을 안 한다 → 아무 일도 안 일어난다
- 호출할 때 `()`를 빼먹는다

### ⑧ 클릭 이벤트 — `addEventListener`

**무엇인지**
**이벤트**는 브라우저에서 일어나는 사건이다 (클릭, 키보드 입력 등). `addEventListener`로 "**이 사건이 일어나면 이 함수를 실행해 줘**"라고 등록한다.
```html
<button id="cheer-button" type="button">응원 보내기</button>
```
```javascript
const cheerButton = document.querySelector("#cheer-button");

function addCheer() {
  console.log("클릭!");
}

cheerButton.addEventListener("click", addCheer);
```
읽는 법: `cheerButton`에 `"click"`이 일어나면 `addCheer`를 실행한다.

⚠️ **괄호 없이 함수 이름만** 넘긴다.

| 쓴 것 | 뜻 | 결과 |
|---|---|---|
| `addCheer` | 함수를 **맡겨 두기** | 클릭할 때마다 실행 ✅ |
| `addCheer()` | **지금 바로** 실행 | 페이지 열자마자 한 번 실행되고, 클릭엔 반응 안 함 ❌ |

비유: 괄호 없음 = 전화번호를 **맡겨 두는 것**, 괄호 있음 = 그 자리에서 **바로 전화 거는 것**.

> 강의에는 HTML에 `onclick="함수()"`를 직접 쓰는 방식도 나왔지만, 기본 방법은 `addEventListener`다.

### ⑨ 데이터와 화면은 따로 바꾼다

⑥~⑧을 합친 강의의 응원 버튼:
```html
<p id="cheer-message">응원을 0번 받았습니다.</p>
<button id="cheer-button" type="button">응원 보내기</button>
```
```javascript
const cheerMessage = document.querySelector("#cheer-message");
const cheerButton = document.querySelector("#cheer-button");

let cheerCount = 0;

function addCheer() {
  cheerCount++;                                                    // ① 데이터(변수) 바꾸기
  cheerMessage.textContent = `응원을 ${cheerCount}번 받았습니다.`;   // ② 화면 바꾸기
}

cheerButton.addEventListener("click", addCheer);
```
흐름: **클릭 → `addCheer` 실행 → 숫자 +1 → 화면 문장 갱신**

- **①만 하면 숫자는 늘어도 화면은 그대로다.** 변수를 바꿔도 화면이 저절로 바뀌지 않는다.
- 값은 실행 중에만 기억하므로 **새로고침하면 0부터** 다시 시작한다.

> 💡 보충: React는 이 ①②를 **state** 하나로 해결한다 (07회차). 이 불편함을 알고 가면 React가 왜 필요한지 보인다.

### ⑩ 객체·배열·화살표 함수

**객체 — 이름표 붙은 서랍** (`{ }`, 꺼낼 때 `.이름`)
```javascript
const person = { name: "한코딩", age: 34 };

console.log(person.name);   // 한코딩
console.log(person.age);    // 34
```

**배열 — 번호 붙은 줄** (`[ ]`, 꺼낼 때 `[번호]`, **0부터**)
```javascript
const goals = ["HTML 이해하기", "CSS로 꾸미기", "JavaScript로 동작 만들기"];

console.log(goals[0]);       // HTML 이해하기 (첫 번째)
console.log(goals.length);   // 3 (항목 수)
```

**객체가 들어 있는 배열** — 목록의 항목마다 정보가 여러 개일 때
```javascript
const users = [
  { id: 0, name: "한코딩", age: 34 },
  { id: 1, name: "파이썬", age: 28 }
];

console.log(users[1].name);   // 파이썬 — [1]로 항목을 고르고, .name으로 속성을 꺼낸다
```

| | 묶는 기호 | 꺼내는 법 | 언제 |
|---|---|---|---|
| 객체 | `{ }` | `.이름` | 한 대상의 여러 정보 (이름, 나이) |
| 배열 | `[ ]` | `[번호]` (0부터) | 같은 종류 여러 개를 순서대로 (목표 목록) |

**화살표 함수** — 함수를 짧게 쓰는 다른 모양
```javascript
function greet(name) {
  return `${name}님, 반갑습니다!`;
}
```
```javascript
const greet = (name) => `${name}님, 반갑습니다!`;   // 위와 같은 함수
```
지금은 **`=>`가 보이면 "함수구나"**만 알면 된다. React 코드에 자주 나온다.

**흔한 실수**
- 첫 번째 항목을 `[1]`로 꺼낸다 (0부터다)
- 없는 번호(`goals[3]`)를 꺼내면 `undefined`

### 2부 한 줄 정리 + React로 이어지는 곳
- 화면 바꾸기: `querySelector`로 **찾고** → `textContent`로 **바꾼다**
- 함수는 **선언과 호출이 다르고**, 이벤트에는 **괄호 없이** 넘긴다
- 일반 JS에서는 **데이터와 화면을 따로** 바꿔야 한다
- 객체는 `.이름`, 배열은 `[0]`부터

| JS 2부 | React에서 |
|---|---|
| 함수 | 컴포넌트가 함수다 — `function App()` (04회차) |
| 객체 | props로 값을 넘긴다 (05회차) |
