## 3
문제 3 (개념)

각 상황에 가장 알맞은 태그 하나씩을 고르세요.
- (가) 할 일 목록에서 **"삭제"**를 누르면 그 항목이 지워진다
- (나) **"내 GitHub 보러 가기"**를 누르면 GitHub 페이지로 이동한다
- (다) 이메일을 적는 칸
- (라) 이메일 칸 앞에 붙는 "이메일"이라는 이름표
- (마) "저는 웹 개발을 공부합니다"에서 "웹 개발"만 나중에 색을 바꾸려고 묶기
- (바) 프로필 사진, 이름, 소개 문단을 특별한 의미 없이 한 덩어리로 묶기

추가 질문: (가)~(라)에서 고른 태그 중 종료 태그가 없는 것은 무엇인가요?

- (가): botton 태그
- (나): a 태그가 링크 이동할때 사용. 단 나중에 JS배우면 button 태그로 링크 걸수 있음.
- (다): input 태그
- (라): label 태그
- (마): span 태그로 인라인 묶고 css에서 바꾸기
- (바): div 태그

- 추가질문: 아 미안 button이 아니고 Input이다.
