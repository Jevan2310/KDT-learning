## 약한 점 → 다음에 볼 것
- **button은 종료 태그가 있다** — 1·2회차 연속 같은 오해. 종료 태그 없는 요소는 감쌀 글자가 없는 것 (img, input, br, hr, meta)
- **태그 짝 맞추기**: `<a>…</button>`, CSS 하위 목록 `</ul>` 빠뜨림
- **a vs button**: 이동은 a. 처음에 "a 또는 button", button에 href·alt를 붙임
- **label**: 입력 칸의 이름표 (처음에 span으로 답함)
- **버그 찾기에서 href 주소** (`https://` 없는 주소) 놓침 — 1회차와 같은 패턴
- 근거 없는 수정 (`h2` → `h1`)
- 철자: `botton`, `stong`, `KDsT`, `GitHb`, `lable`
