## 문제와 피드백

### 문제 1 (개념) — ✅
- 내 답: (가) JavaScript (나) HTML (다) CSS → 모두 정답

### 문제 2 (개념) — 🔺
- 1번 ✅ 시작 태그 `<p>` / 내용 / 종료 태그 `</p>`
- 2번 1차 ❌ "p 태그?" → 2차 ✅ "요소"
  - 정답: **요소**. `<p>`, `</p>` 각각이 태그이고, 시작 태그 + 내용 + 종료 태그 전체가 요소다
- 3번 1차 🔺 `img` ✅, `a` ❌ → 2차 "button?" ❌ → 답 공개
  - 정답: `img`, `input` (`br`, `hr`, `meta`도). 감쌀 내용이 없는 요소라 종료 태그가 없다
  - `a`, `button`은 문구를 감싸므로 종료 태그가 있다
  - 직접 쓴 `index.html`에 이미 `meta`, `br`가 있었다

### 문제 3 (코드 읽기) — 1차 🔺 → 2차 ✅
- 1번 ✅ 공부 기록
- 2번 1차: `h1` "오늘의 공부" 빠뜨림, 문단이 두 줄로 나뉜다고 답함 → 2차: `h1` 추가, "Enter로 줄 바꿔도 브라우저에는 안 보임"
- 정답 화면: "오늘의 공부"(h1) / "HTML을 배웠다. 내일은 CSS를 배운다."(한 줄 — Enter는 공백 하나가 됨) / 주석은 안 보임

### 문제 4 (버그 찾기) — 🔺
| 실수 | 1차 | 2차 |
|---|---|---|
| `ul` 안 `p` → `li` | ✅ | |
| `strong` 닫는 순서 (안쪽부터) | ✅ 이유 설명 정확 | |
| `a`에 `href` 없음 | 🔺 `herf=""` | 🔺 `href="gihub.com"` |
| `h3` → `h1` (대표 제목) | ❌ | ✅ |
| `img`에 `alt` 없음 | ❌ | ✅ `alt="내 사진"` |

- `href` 정답: `href="https://github.com/"`. `https://`가 없으면 브라우저는 같은 폴더의 `github.com` 파일을 찾는다 (강의 밖 보충)

### 문제 5 (코드 작성) — 🔺
- 1차: 요구사항 8/10. ❌ 문단 `p` 2개 (`p` 하나 안에서 `<br>`로 나눔), ❌ 중첩 목록 없음
- 2차: 문단 `p` 2개 ✅ (`<P>` 대문자는 3차에 소문자로 고침)
- 3차: 중첩 목록 시도. 하지만 `<li>HTML</li>`를 먼저 닫고 그 뒤에 `<ul>`을 둠 → `ul` 바로 안에 `ul`이 들어간 구조 (26~31줄)
  - 화면에서는 들여쓰기가 되어 맞아 보이지만, 브라우저가 틀린 구조를 알아서 보정해 준 것이다
  - 정답:
    ```html
    <ul>
        <li>HTML
            <ul>
                <li>HTML 기본 구조</li>
                <li>태그와 속성</li>
                <li>폼과 입력 요소</li>
            </ul>
        </li>
        <li>CSS</li>
        <li>JavaScript</li>
        <li>React</li>
    </ul>
    ```
- 좋았던 점: 기본 구조(DOCTYPE, lang, meta charset·viewport, title) 완벽, 들여쓰기 깔끔, h1 → h2 계층, 링크 문구가 목적지를 알려줌, img + alt, 주석

### 문제 6 (설명하기) — ✅
- 숫자 = 목차 계층, 글씨 크기는 CSS로 관리, h 태그는 구조 구분용 → 핵심 정확
- 덧붙이면: 구조가 맞아야 화면 낭독기 같은 보조 기술도 문서를 이해한다

## 약한 점 → 다음에 볼 것
- **중첩 목록**: 안쪽 `ul`은 `<li>`와 `</li>` 사이에 들어간다. 들여쓰기가 아니라 태그를 여닫는 위치가 구조를 정한다
- **태그 vs 요소** 용어, **종료 태그 없는 요소** (`img`, `input`, `br`, `hr`, `meta`)
- 아는 개념을 코드에 적용하기: 문제 6은 완벽히 설명했는데 문제 4의 `h3`는 놓쳤다
- `href`에는 `https://`부터 전체 주소
