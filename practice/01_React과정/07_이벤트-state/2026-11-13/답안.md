
## 문제 1 (코드 읽기)

실행하지 말고 예측해서 표에 쓰세요. 표 칸 안에서는 Enter로 줄을 바꾸지 말고 /로 나눠 주세요.

```jsx
import { useState } from "react";

const members = [
  { id: 1, name: "한코딩", stars: 2 },
  { id: 2, name: "파이썬", stars: 0 },
  { id: 3, name: "자바", stars: 1 },
];

function LikeButton() {
  let likes = 0;

  function handleLike() {
    likes = likes + 1;
    console.log("좋아요:", likes);
  }

  return (
    <div>
      <p>좋아요 {likes}개</p>
      <button type="button" onClick={handleLike}>좋아요</button>
    </div>
  );
}

function StarBoard() {
  const [count, setCount] = useState(0);
  const starMembers = members.filter((member) => member.stars > 0);

  function handleCheer() {
    setCount(count + 1);
    console.log("응원:", count);
  }

  return (
    <section>
      <p>별 받은 사람 {starMembers.length}명</p>
      <p>응원 {count}번 {count && "🎉"}</p>
      <button type="button" onClick={handleCheer}>응원하기</button>
    </section>
  );
}
```

| 번호 | 답 | 이유 |
|---|---|---|
| ① LikeButton 3번 클릭 — Console 3줄 | 좋아요: 3 | 변수가 likes에 반영됨.|
| ① LikeButton 3번 클릭 — 화면 `<p>` | 좋아요 0개| 리액트가 자동 랜덩링이 되지 않아서 화면은 초기 설정한 화면 그대로 유지됨|
| ② StarBoard 클릭 전 — 화면 `<p>` 2줄 | 별 받은 사람 2명 / 응원 0번 0| 클릭전이라서 화면이 초기 찍힌대로 보여짐, 비교값이 불린이 아니고 count라서 count가 0이 뜬다.|
| ③ StarBoard 2번 클릭 후 — Console 2줄 | 응원: 1 | 지금 현재 화면으로 랜더링 된 상태여서 현재 값을 보여줌. 다음값은 다음클릭때보여줌. 즉 화면보다 1느림 |
| ③ StarBoard 2번 클릭 후 — 화면 `<p>` 2줄 | 별 받은 사람 2명 / 응원 2번 🎉| setCount가 실행되고 count에 새로 저장된 값이 랜더링 되면서 화면에 가장 최신 값이 보여짐|

## 문제 2 (버그 찾기)

동작해야 하는 것: +1을 누를 때마다 걸음 수가 1씩 오르고, 초기화를 누르면 0이 돼요. 버그는 4개예요. 코드를 답안.md에 붙여 넣고, 줄 번호는 답안.md 기준으로 써 주세요.

```jsx
import useState from "react";

function StepCounter() {
  const [count, setCount] = useState(0);

  function handleAdd() {
    count = count + 1;
  }

  return (
    <section>
      <h2>오늘 걸음 {count}보</h2>
      <button type="button" onClick={handleAdd()}>+1</button>
      <button type="button" onClick={setCount(0)}>초기화</button>
    </section>
  );
}

export default StepCounter;

```

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 63 | useState | { useState } | 함수를 직접 불러와야함. export 이름 형태|
| 69 | count = count + 1; | setCount(count + 1); | setCount 함수로 값을 넣어줘야 랜더링할때 count 값이 저장되면서 새로운값이 랜더링 됨|
| 75 | {handleAdd()} | {handleAdd} | 함수값은 화살표 함수를 이용해야함. 해당 위치에서는 함수를 호출하면 안됨.|
| 76 | {setCount(0)}| {() => setCount(0)} | 75번화 같은 이유이고, 값을 지정해 주려면 화살표 함수로 감싼다.|




## 문제 3 (설명하기)

내 말로 써 주세요. 비유를 써도 좋아요.
1. onClick={handleCheer}와 onClick={handleCheer()}는 무엇이 다른가요? 각각 언제 실행되는지 쓰세요.
- onClick={handleCheer}은 함수를 넘기는 것이고
- onClick={handleCheer()}은 함수를 호출하는 것이다. 
- 따라서 onClick={handleCheer()}은 지금 바로 실행되면서 화면이 그리는중 실행이라 화면에 안생긴다. console에서는 오류창이 뜬다.
2. let count = 0으로 만든 변수를 버튼으로 올려도 화면 숫자가 그대로인 이유를 두 가지 쓰고, 대신 무엇을 써야 하는지 쓰세요.
- 일반변수는 react가 기억하지 못한다. 다시 랜더링하더라도 함수가 처음부터 다시 실행되면서 값은 초기값 그대로 설정된다. 따라사 useState를 이용한다. 
- const [count, setCount] = useState(0); // 이렇게 선언을 해준다.
- setCount(count + 1); setCount 함수안에 값을 늘려준다.

3. setCount(count + 1) 바로 다음 줄의 console.log(count)에 새 값이 안 찍히는 이유를 쓰세요.
- setCount가 값을 늘리기 위해 예약을 하고 console이 먼저 실행되서 기존 값이 그대로 보인다. 다음 버튼을 눌러야 다음 번호가 뜬다.
