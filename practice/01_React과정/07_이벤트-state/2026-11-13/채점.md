### 문제 3
1. `onClick={handleCheer}`는 함수를 **맡겨 두는 것** → **클릭할 때** 실행된다. `onClick={handleCheer()}`는 함수를 **지금 호출하는 것** → **화면을 그리는 순간** 실행되고, 그 결과(값)가 `onClick`에 들어간다.
2. ① 일반 변수를 바꿔도 React에 알리지 않으니 **화면을 다시 그리지 않는다**. ② 다시 그리더라도 컴포넌트 함수가 처음부터 실행되면서 `let count = 0`이 또 실행돼 **값이 사라진다**. → `const [count, setCount] = useState(0);`로 state를 만들고 `setCount`로 바꾼다.
3. `setCount`는 다음 렌더링에 쓸 값을 **예약**할 뿐이다. 지금 실행 중인 함수 안의 `count`는 **이번 화면의 값으로 고정**(스냅샷)돼 있어서, 바로 다음 줄에서는 예전 값이 찍힌다.

## 모범 답안 — 문제 4

제출 코드도 정답이다. 이름 짝(`cups` ↔ `setCups`)과 파일·컴포넌트 이름을 맞춘 모양:

```jsx
// src/components/WaterCounter.jsx
import { useState } from "react";

function WaterCounter() {
  const [cups, setCups] = useState(0);

  function handleDrink() {
    setCups(cups + 1);
    console.log("클릭 직후 cups:", cups);
  }

  return (
    <section>
      <h2>오늘 물 {cups}잔</h2>
      {cups >= 8 ? <p>오늘 목표 달성! 🎉</p> : <p>목표까지 {8 - cups}잔</p>}
      <button type="button" onClick={handleDrink}>한 잔 마셨어요</button>
      <button type="button" onClick={() => setCups(0)}>다시 시작</button>
    </section>
  );
}

export default WaterCounter;
```
