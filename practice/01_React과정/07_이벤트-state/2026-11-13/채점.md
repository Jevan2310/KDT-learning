## 1차 제출 기록 (2026-11-13)

### 문제 1 — 🔺
- ① Console `좋아요: 3` — 마지막 줄만 씀(3줄 `1 / 2 / 3` 요구). 값이 오른다는 건 맞음 ✅ (감점 안 함)
- ① 화면 `좋아요 0개` — "리액트가 자동 렌더링이 되지 않아서" ✅
- ② `별 받은 사람 2명 / 응원 0번` — **`filter` 개수 2명 ✅ (🔁 06 #8 — 지난 연습에서 3번 틀린 것을 맞힘)**. `{count && "🎉"}`에서 `count`가 `0`이면 `0`이 찍혀 실제는 `응원 0번 0` ❌ (🔁 06 #5 — `&&`의 0, 세 번째로 놓침)
- ③ Console `응원: 1` — 마지막 줄만 씀(2줄 `0 / 1` 요구). 이유 "현재 렌더링 값을 보여 줌, 화면보다 1 느림" ✅ (스냅샷 이해)
- ③ 화면 `별 받은 사람 2명 / 응원 2번 🎉` ✅
- 참고: 푸는 중 연습장에서 `StarBoard`를 실행해 봄 (`useState is not defined` — import 줄 빠짐 질문). 결과를 봤는지는 확인 안 됨
- 힌트: ② `count`가 `0`일 때 `{count && "🎉"}`가 돌려주는 값 (06 2부 개념정리 ⑥ 문지기 비유)

### 문제 2 — ✅ (4군데)
- 63줄 `useState` → `{ useState }` — "이름 export 형태" ✅
- 69줄 `count = count + 1;` → `setCount(count + 1);` — "set 함수로 값을 넣어야 다시 렌더링" ✅
- 75줄 `{handleAdd()}` → `{handleAdd}` — "함수를 호출하면 안 됨" ✅
  - 참고: 이유 앞부분 "함수값은 화살표 함수를 이용해야 함"은 76줄 이야기. 75줄은 이름만 넘기면 됨
- 76줄 `{setCount(0)}` → `{() => setCount(0)}` — "값을 지정하려면 화살표 함수로 감싼다" ✅

### 문제 3 — ✅
- (1) "함수를 넘기는 것 / 호출하는 것, `()`는 지금 바로·화면 그리는 중 실행" ✅
  - 보강: 넘긴 함수는 **클릭할 때** 실행된다는 말이 빠짐 (질문이 "각각 언제")
- (2) "React가 기억하지 못함, 다시 렌더링하면 함수가 처음부터 실행돼 초기값" + `useState`·`setCount` ✅
  - 보강: 이유 ①을 "바꿔도 React가 **화면을 다시 그리지 않는다**(알리지 않음)"로 분명히 쓰면 4. 문제 1 ①에는 "자동 렌더링이 안 돼서"로 씀
- (3) "setCount는 예약, 기존 값이 보임" ✅
  - 보강: "console이 먼저 실행돼서"보다 "이 함수 안의 `count`는 **이번 화면의 값으로 고정**(스냅샷), 새 값은 다음 렌더링에서"가 정확
