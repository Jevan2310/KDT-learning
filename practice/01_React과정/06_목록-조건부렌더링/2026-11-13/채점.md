## 문제와 피드백

### 문제 1 — ✅ (힌트 받고 완성 → 처음부터 다시 작성)
초안에서 막힌 곳 (중간 확인 때 힌트):
1. `App.jsx` 1줄 `import { TodoList }` ↔ `TodoList.jsx` `export default` — 짝이 안 맞아 화면 전체가 하얌 (Console: `does not provide an export named 'TodoList'`) → default로 고침 (06 #10)
2. map 안에서 `{title} - {minutes}분` — `title`이라는 변수가 없음 (`todo.title`이어야 함, ESLint `'todo' is defined but never used`) → 고침 (06 #1)
3. `<li>{todo.key} …</li>` — `key`를 태그 속성이 아니라 **내용**으로 씀 → 빈칸 + key 경고 → `<li key={todo.id}>`로 고침 (06 #3). `<li>`가 `<ul>` 없이 `<section>` 안에 있던 것도 고침
- 힌트 받고 완성한 코드 사본: `문제1_힌트받고완성/`

처음부터 다시 작성 (사용자가 스스로 하겠다고 함):
- `TodoList.jsx`는 힌트 없이 한 번에 동작 — `todos` 4개, `<h2>오늘 할 일 {todos.length}개</h2>`, `<ul>` 안 map, `key={todo.id}`, `todo.title`·`todo.minutes`
- `App.jsx`를 `const App = () => { <>…</> }`로 써서 빈 화면 → 힌트("화살표 함수의 중괄호에도 map과 같은 규칙") 듣고 `return <>`으로 고침 (06 #2)
- 참고: 재작성에서는 map을 중괄호 + `return`으로 씀 (요구는 소괄호). 초안이 소괄호였고, "계속 중괄호로 써도 되나" 질문 → 써도 됨, 읽을 때는 둘 다 (질문 노트)
- 참고: `<TodoList/ >` → 보통 `<TodoList />`

  - ✅ `BookList.jsx` 3~8줄 함수 바깥 `books` 3개
  - ✅ 11~14줄 `const bookCards = books.map((book)=>{ return <BookCard … /> })` — 중괄호 + `return`, `return`과 JSX를 같은 줄에서 시작

- 참고: 처음에 `App.jsx`에 쓰지 않는 `import BookCard`가 있었음 (ESLint `no-unused-vars`) → 지움. `BookCard`는 `BookList`가 가져다 씀
- 참고: 사본 `components/BookList.jsx`는 공개 저장소용으로 지은이 이름 하나를 `김자바`로 바꿔 저장함

### 문제 3 — ✅ (힌트 2번)
- 빌드·ESLint·화면 확인, Console key 경고 0건:
  - Console: `[25000, 6000, 28000, 4000]`
  - `장보기 4` / `감자 5000원 × 5개 = 25000원` / `우유 1500원 × 4개 = 6000원` / `고구마 4000원 × 7개 = 28000원` / `간장 2000원 × 2개 = 4000원`

  1. 10~12줄 `items.map((item)=>{ item.price * item.count })` — 중괄호에 `return`이 없어 `[undefined × 4]` → `return` 추가 (06 #2). 오늘 `return` 빠짐 두 번째 (App 컴포넌트, `totals`)
  2. 2~5줄 `id`가 모두 `1` (복사 후 안 고침) — "key로 쓸 값에 문제" 힌트 → `1~4`로 고침 (06 #3, 마무리 확인)
- 요구사항 체크
  - ✅ 9줄 `export function ShoppingList()` ↔ `App.jsx` 4줄 `import { ShoppingList }` — 이름 붙인 export 짝 (06 #10, 힌트 없이)
  - ✅ 10~13줄 `totals` 숫자 배열 + `console.log(totals)`
  - ✅ 15줄 `{items.length}` 배열 길이
  - ✅ 16~22줄 JSX map: 중괄호 + `return`, **17줄 `key={item.id}`가 가장 바깥 `<div className="card">`에** 있음
  - ✅ 20줄 합계 `{item.price * item.count}`를 JSX 안에서 계산
- 참고: 15줄 `장보기 {items.length}` 뒤에 "개"가 빠짐 (문구 차이, 감점 안 함)

## 모범 답안 (참고: 소괄호 모양으로 쓴 경우)

중괄호 + `return`으로 쓴 제출 코드도 정답이다. 강의 코드는 JSX 안의 map을 주로 소괄호로 쓰므로 읽는 연습용으로 남긴다.

```jsx
// src/components/ShoppingList.jsx
const items = [
  { id: 1, name: "감자", price: 5000, count: 5 },
  { id: 2, name: "우유", price: 1500, count: 4 },
  { id: 3, name: "고구마", price: 4000, count: 7 },
  { id: 4, name: "간장", price: 2000, count: 2 },
];

export function ShoppingList() {
  const totals = items.map((item) => item.price * item.count);
  console.log(totals); // [25000, 6000, 28000, 4000]

  return (
    <section>
      <h2>장보기 {items.length}개</h2>
      {items.map((item) => (
        <div className="card" key={item.id}>
          <h3>{item.name}</h3>
          <p>{item.price}원 × {item.count}개 = {item.price * item.count}원</p>
        </div>
      ))}
    </section>
  );
}
```

제출한 코드 (사본: 이 폴더의 `App.jsx`, `components/`):
```jsx
// src/components/BookList.jsx (11~18줄)
const BookList = () =>{
    const bookCards = books.map((book)=>{
        return <BookCard key={book.id} id={book.id} title={book.title} 
        writer={book.writer} pages={book.pages}/>
    })
    return <section>
            <h2>읽을 책</h2>
            {bookCards}
        </section>
}
```

## 잘한 점
- 문제 1을 힌트로 완성한 뒤 **스스로 처음부터 다시 작성** — 손에 익히려는 방법이 좋았고, `TodoList`는 한 번에 동작함
- 문제 2의 함정(key는 자식에 안 감 → `id`를 따로 넘김)을 힌트 없이 처리 (06 #4 → 3)
- 이름 붙인 export(`export function` ↔ `import { }`)를 문제 3에서 혼자 맞춤 — 문제 1에서 틀린 짝을 바로 적용
- `console.log(totals)`로 찍어 보고 `undefined`를 스스로 발견해 질문함 — 확인 습관
- 문제 2·3에서 map 결과를 변수에 담기 / JSX 안에 바로 쓰기 두 방식을 다 써 봄

## 약한 점 → 다음에 볼 것
- **중괄호 `{ }`에 `return` 빠뜨리기** — 오늘 2번 (App 컴포넌트, `totals` map). 중괄호를 열면 "`return` 썼나?"를 바로 확인하기 (06 #2, 복습 대기열 유지)
- map 콜백 안에서 **매개변수 이름으로 속성 읽기** (`todo.title`) — 초안에서 `{title}`만 씀 (06 #1)
- `key`는 태그에 붙이는 **속성**이지 화면에 보여 주는 내용이 아님 (`{todo.key}` → `key={todo.id}`) (06 #3)
- 마무리 확인: 복사한 데이터의 `id` 중복, 쓰지 않는 import — 다 쓰면 Console·ESLint를 한 번 보기
