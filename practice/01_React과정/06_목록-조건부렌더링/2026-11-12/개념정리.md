## 1부

### ① 데이터를 배열로

05회차에서는 카드를 늘릴 때마다 `<ProfileCard name="…" />`를 **한 줄씩 직접** 썼다. 카드가 100장이면 100줄이다.
06회차에서는 **데이터를 배열에 모아 두고**, 배열을 보고 카드를 **자동으로** 만든다.

```text
프로필 데이터 배열 → map() → 프로필 카드 목록
```

객체 하나 = 프로필 하나, 배열 = 프로필 여러 개 (JS 2부 ⑩).
```javascript
const profiles = [
  { id: 1, name: "한코딩", intro: "프론트엔드를 공부합니다." },
  { id: 2, name: "파이썬", intro: "데이터를 다룹니다." },
  { id: 3, name: "자바", intro: "서버를 만듭니다." },
];
```
- `id`: 프로필마다 **겹치지 않는 번호** (④ `key`에 쓴다)
- 개수는 `profiles.length` → `<p>프로필 {profiles.length}개</p>` → "프로필 3개"
- 강의에서는 `profiles`를 `App` 함수 **바깥**(파일 위쪽)에 두었다

---

### ② `map()` — 배열을 카드 목록으로

- **무엇**: 배열의 항목을 **하나씩 꺼내 바꾼 값**으로 **새 배열**을 만드는 함수. 원본 배열은 그대로다
- **왜**: 데이터 배열 → JSX 배열로 바꾸면 React가 그걸 목록으로 그려 준다

먼저 숫자로 보면:
```javascript
const numbers = [1, 2, 3];

const doubled = numbers.map((number) => {
  return number * 2;
});
// doubled = [2, 4, 6], numbers는 그대로 [1, 2, 3]
```
- `number` — 지금 꺼낸 항목. 이름은 마음대로 정한다 (`n`, `item` …)
- `return` 한 값이 새 배열에 차례로 들어간다

**JSX를 return하면** 카드 목록이 된다.
```jsx
function App() {
  return (
    <div>
      <p>프로필 {profiles.length}개</p>
      {profiles.map((profile) => (
        <ProfileCard key={profile.id} name={profile.name} intro={profile.intro} />
      ))}
    </div>
  );
}
```
→ 카드 3장: 한코딩, 파이썬, 자바. 배열에 객체를 하나 더하면 카드도 **저절로** 하나 는다.

- `{ }` 안에 `map()`을 쓴다 — JSX 안에서 JavaScript를 쓰는 자리 (04회차 ⑥)
- 데이터 속성 이름과 props 이름은 달라도 된다: `intro={profile.introduction}` → 자식은 `intro`로 읽음
- `map()` 결과를 변수에 담아 `{cards}`처럼 넣어도 된다

### ③ 소괄호 `( )` vs 중괄호 `{ }` + `return`

화살표 함수 줄여 쓰기와 같은 규칙이다 (JS 2부, 03_JavaScript 13장).

```jsx
// ✅ 소괄호 — JSX를 바로 돌려준다 (return 없음)
profiles.map((profile) => (
  <ProfileCard key={profile.id} name={profile.name} />
));

// ✅ 중괄호 — 함수 본문이라 return이 필요하다
profiles.map((profile) => {
  return <ProfileCard key={profile.id} name={profile.name} />;
});

// ❌ 중괄호인데 return이 없다 → 카드가 하나도 안 나온다 (오류도 안 남)
profiles.map((profile) => {
  <ProfileCard key={profile.id} name={profile.name} />;
});
```

| 화살표 뒤 | `return` |
|---|---|
| `( )` 소괄호 | 안 씀 — 안의 값이 바로 돌려짐 |
| `{ }` 중괄호 | **꼭 씀** — 없으면 `undefined` |

**흔한 실수**: 중괄호를 쓰고 `return`을 빼먹는다 → 빈 화면인데 오류가 없어서 찾기 어렵다

---

### ④ `key` — 목록 항목의 이름표

- **무엇**: `map()`으로 만든 항목마다 붙이는 **고유한 이름표**
- **왜**: 목록은 나중에 추가·삭제·순서 변경이 생긴다. React는 `key`를 보고 "이전 목록의 이 카드 = 지금 목록의 이 카드"를 구분한다
- **어떻게**: `map()`이 돌려주는 **가장 바깥 요소**에 `key={데이터의 id}`

```jsx
{profiles.map((profile) => (
  <ProfileCard key={profile.id} name={profile.name} />
))}
```
- `key`가 없으면 화면은 나오지만 개발자 도구 Console에 경고가 뜬다: `Each child in a list should have a unique "key" prop.`

| key 값 | 괜찮나 |
|---|---|
| 데이터의 `id` | ✅ 강의 방식 |
| `Math.random()` | ❌ 그릴 때마다 바뀌어서 구분이 안 된다 |
| 배열 순서 번호 (index) | ❌ 추가·삭제·정렬이 있는 목록에서 문제가 생긴다 |

**`key`는 props로 전달되지 않는다.** React가 목록 관리에만 쓰고 자식에게 안 준다. 자식에서도 id가 필요하면 **따로** 보낸다.
```jsx
<ProfileCard key={profile.id} id={profile.id} name={profile.name} />
// 자식에서 props.key → undefined, props.id → 1
```

**흔한 실수**
- `ProfileCard` **안쪽**의 `<div>`에 key를 붙인다 → `map()`이 돌려주는 바깥 요소(`<ProfileCard>`)에 붙여야 한다
- `id`가 겹친다 (`id: 1`이 두 개)

### ⑤ `export default` vs 이름 붙인 `export`

05회차에서는 파일마다 `export default` 하나만 썼다. 강의 코드에는 **이름을 붙여 내보내는** 방식도 나왔다.

`src/components/ProfileCard.jsx`
```jsx
function ProfileCard({ name }) {
  return <h2>{name}</h2>;
}

export function MyHobby() {              // 이름 붙인 export
  return <p>취미: 코딩</p>;
}

export default ProfileCard;              // default export
```
`src/App.jsx`
```jsx
import ProfileCard from "./components/ProfileCard.jsx";   // default → 중괄호 없이
import { MyHobby } from "./components/ProfileCard.jsx";   // 이름 붙인 → 중괄호 안에 같은 이름
```

| | `export default` | 이름 붙인 `export` |
|---|---|---|
| 내보내기 | `export default ProfileCard;` | `export function MyHobby()`, `export const MyMovie = () => …` |
| 한 파일에 | **하나만** | 여러 개 |
| 가져오기 | `import ProfileCard from …` (중괄호 ❌) | `import { MyHobby } from …` (중괄호 ⭕) |
| 가져올 때 이름 | 바꿔도 된다 | 내보낸 이름 **그대로** |

- 강의 코드처럼 경로의 `.jsx`는 빼도 Vite가 찾아 준다: `from './components/ProfileCard'`
- React의 `import { useState } from 'react'`(07회차)도 이름 붙인 export를 가져오는 모양이다

**흔한 실수**
- default로 내보낸 것을 `import { ProfileCard }`로 가져온다 → 그런 이름의 export가 없다는 오류
- 이름 붙인 것을 `import MyHobby from …`로 가져온다 → 중괄호가 없으니 **default(ProfileCard)**가 들어온다

### 🔁 복습 포인트 (05 채점에서)
- 보내는 props 이름과 받는 이름이 같아야 한다 — 06에서는 `name={profile.name}`처럼 **데이터 → props**로 한 번 더 옮기니 이름을 잘 맞춘다
- 문제 요구를 한 줄씩 대조하기 (05 2부에서 이유 두 줄·문제 4를 빠뜨림)

### 1부 한 줄 정리
- 데이터는 **객체 배열**로 모으고, `{배열.map((항목) => <Card … />)}`로 카드 목록을 만든다
- 화살표 뒤 `( )`면 `return` 없이, `{ }`면 `return` 필수
- `map()`이 돌려주는 바깥 요소에 `key={항목.id}` — 고유하게, 자식 props로는 안 간다
- `export default` → `import X from`, `export function X` → `import { X } from`
