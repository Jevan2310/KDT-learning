
## 문제 1 (코드 읽기)

화면에 보이는 것을 표에 쓰세요. ②는 세 줄, ③은 안 보이면 (없음)이라고 써요. 그리고 ②의 번호 자리와 ③이 왜 그렇게 나오는지 이유를 한 줄씩 쓰세요.
const fruits = [
  { id: 1, name: "사과", price: 1000 },
  { id: 2, name: "바나나", price: 2000 },
  { id: 3, name: "포도", price: 3000 },
];

function FruitItem(props) {
  return <li>{props.key}번 {props.name}: {props.price}원</li>;
}

function App() {
  const prices = fruits.map((fruit) => fruit.price * 2);

  return (
    <div>
      <p>과일 {fruits.length}개, 두 배 가격: {prices[0]}원</p>
      <ul>
        {fruits.map((fruit) => (
          <FruitItem key={fruit.id} name={fruit.name} price={fruit.price} />
        ))}
      </ul>
      <ol>
        {fruits.map((fruit) => {
          <li key={fruit.id}>{fruit.name}</li>;
        })}
      </ol>
    </div>
  );
}
| 번호 | 화면에 보이는 것 | 이유 (②·③만) |
|---|---|---|
| ① `<p>` | 과일 3개, 두 배 가격: 2000원 | |
| ② `<ul>` | • 번 사과: 1000원 / • 번 바나나: 2000원/ • 번 포도: 3000원 | 자녀 컴포넌트에 key는 prop으로 보내지지 않음 따라서 00번을 보이게 하려면 id = {fruit.id}를 추가하고 props.id로 수정해야함 |
| ③ `<ol>` | (없음) | {}중괄호로 맵핑한것은 return으로 반환해야 보임 |

문제 2 (버그 찾기)

영화 카드 3장(제목·연도)을 보여 주려는데 버그가 4개 있어요.
- MovieCard.jsx는 고치지 않아요. 버그는 모두 App.jsx에 있어요.
- 두 파일을 답안.md에 붙여 넣고 표에 쓰세요. 줄 번호는 답안.md 기준이에요.

src/components/MovieCard.jsx
export function MovieCard({ title, year }) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <p>{year}년</p>
    </div>
  );
}
src/App.jsx
import MovieCard from "./components/MovieCard.jsx";

const movies = [
  { id: 1, title: "첫 번째 영화", year: 2020 },
  { id: 2, title: "두 번째 영화", year: 2022 },
  { id: 3, title: "세 번째 영화", year: 2024 },
];

function App() {
  return (
    <div>
      <p>영화 {movies.length}개</p>
      {movies.map((movie) => {
        <MovieCard
          key={Math.random()}
          title={movie.name}
          year={movie.year}
        />;
      })}
    </div>
  );
}

export default App;
| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 58 | import MovieCard from "./components/MovieCard.jsx"; | {MovieCard} | 이름 export를 불러올때 {}가 꼭 필요함|
| 70 | <MovieCard | return <MovieCard | {}로 맵핑을 이용할때는 return으로 호출해야힘.|
| 72 | key={Math.random()} | key={movie.id} | key는 movie.id로 불러와야함.|
| 73 | title={movie.name} | title={movie.title} | name이라는 객체는 없음. title을 이용해야함.|
