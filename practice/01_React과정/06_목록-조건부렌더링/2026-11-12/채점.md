제출한 코드 (사본: 이 폴더의 `App.jsx`, `components/ProfileCard.jsx`):
```jsx
// src/App.jsx
import ProfileCard from "./components/ProfileCard.jsx";
import { ListTitle } from "./components/ProfileCard.jsx";

const profiles = [
  { id: 1, name: "한코딩", intro: "프론트엔드 개발자입니다.", goalCount: 3},
  { id: 2, name: "파이썬", intro: "벡엔드 언어1", goalCount: 5},
  { id: 3, name: "자바", goalCount: 2},
  { id: 4, name: "리액트", intro: "프레임워크", goalCount: 6},
];

function App() {
  return (
    <div>
      <ListTitle count = {profiles.length} />

      {profiles.map((profile) => {
        return <ProfileCard 
          key={profile.id}
          name={profile.name}
          intro={profile.intro}
          goalCount={profile.goalCount}
        />
      })}
    </div>
  );
}
export default App;
```

### 문제 3
React는 `key`로 이전 목록과 지금 목록에서 **어느 항목이 같은 항목인지** 구분한다. `Math.random()`은 그릴 때마다 바뀌고, 순서 번호는 추가·삭제·정렬하면 다른 항목을 가리키게 되므로, 항목마다 고정된 데이터의 `id`를 쓴다.

## 잘한 점
- `props.key`가 빈칸인 이유를 짚고, 고치는 방법(`id`를 따로 보내기)까지 스스로 씀
- 중괄호 `map()`의 `return` 빠짐을 읽기·버그·작성 세 번 모두 정확히 처리
- default와 이름 붙인 export를 한 파일에서 내보내고 짝 맞춰 가져옴 — 처음 써 본 방식을 한 번에 동작시킴
