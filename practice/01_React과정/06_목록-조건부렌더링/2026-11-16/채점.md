## 푸는 중 질문

### 문제 2 — "지금 왜 오류나지?" (2026-11-16)
- `BookList.jsx` 1줄 `import BookCard from "./components/BookCard";` → `Failed to resolve import` (빌드로 확인). `BookList.jsx`가 이미 `components/` 안에 있어 경로가 `components/components/BookCard`가 됨 (05 #3 파일 분리·import 경로)
- 설명: `./` = 이 파일이 있는 폴더. 같은 폴더끼리는 `./BookCard`
- 같이 보인 ESLint `'TodoList'`·`'BookCard' is defined but never used`는 아직 안 써서 생긴 경고 — 화면을 멈추지 않음

### 문제 2 — "뭐가 오류가 생기는데" (2026-11-16, 경로 고친 뒤)
- 빌드는 통과. 화면 그리기에서 `Cannot access 'BookCard' before initialization` (Claude가 사본으로 확인)
- 원인: `BookList.jsx` 10줄 `const BookCard = books.map(… <BookCard … /> …)` — map 결과 변수 이름이 가져온 컴포넌트 이름과 같음 → 가져온 `BookCard`가 가려져 ESLint `'BookCard' is defined but never used`, map 안 `<BookCard>`는 아직 만드는 중인 변수 자신을 가리킴
- 설명: 컴포넌트는 대문자, map 결과를 담는 변수는 다른 이름(소문자). 변수 이름은 직접 고치게 함. 나머지 요구사항은 제출 전에 체크리스트로 대조하도록 안내

### 문제 2 — "아직도 오류가 있는데" (2026-11-16, 변수 이름 고친 뒤)
- 10줄 `const bookCard = …` + 21줄 `{bookCard}` 로 고침 → 이름 충돌 해결. (요구 이름은 `bookCards`, 채점 때 참고)
- 화면 그리기에서 `Objects are not valid as a React child (found: object with keys {id, title, author, pages})` (Claude가 사본으로 확인)
- 원인: `BookCard.jsx` 2줄 `(id, title, author, pages) =>` — 구조 분해 중괄호 빠짐 → `id`에 props 객체 전체가 들어가 `{id}`가 객체를 그리려 함 (🔁 05 #7 — 05 2부 버그 찾기에서 찾았던 `(name, price)`와 같은 실수)
- 힌트: props는 객체 하나로 첫 번째 칸에 들어온다, 05 개념정리 구조 분해 모양 확인. 고치는 코드는 주지 않음

## 정답 — 문제 4 (풀지 않고 공개)

| 번호 | 답 | 이유 |
|---|---|---|
| ① Console `doubled` | `[undefined, undefined]` | 콜백이 중괄호 `{ }`인데 `return`이 없어 아무것도 돌려주지 않음 (06 #2) |
| ② 첫 번째 `<li>` | `한코딩 0 []` | `score`가 `0` → `0 && …`은 `0`을 돌려주고 React는 숫자 `0`을 그림 (06 #5). `<Badge>{s.name}</Badge>`는 태그 사이에 넣은 것이라 `label`로 전달되지 않음 → `label`은 `undefined` → `[]` (05 #4) |
| ③ 두 번째 `<li>` | `파이썬 ★3 []` | `3 && "★3"` → `"★3"`. Badge는 ②와 같은 이유로 `[]` |
| ④ 고친 코드 | `const doubled = scores.map((s) => s.score * 2);` | 소괄호(또는 괄호 없이)로 바로 돌려줌. 중괄호를 쓰면 `{ return s.score * 2; }` |
| ⑤ 고친 코드 | `<Badge label={s.name} />` | props는 `이름={값}` 속성으로 보낸다 |

## 약한 점 → 다음에 볼 것
- **중괄호 `{ }`에 `return`** (06 #2) — 문제 3 `totals`에서 `return` 대신 `console.log`만 씀. 지난번과 **같은 자리**에서 같은 실수 → 숫자 계산 map에서 특히 조심. 복습 대기열 유지
- **import 경로의 `./`** (05 #3) — 컴포넌트끼리 가져올 때 `./components/…`를 씀. `./` = 이 파일이 있는 폴더 → 3 → 2, 복습 대기열
- **props 구조 분해 중괄호** (05 #7) — `(id, title, …)`로 받아 `Objects are not valid as a React child` → 3 → 2, 복습 대기열
- **변수 이름 vs 컴포넌트 이름** — map 결과를 `BookCard`로 지어 컴포넌트를 가림. 컴포넌트는 대문자, 값은 소문자
- **마무리 확인** — 요구사항의 모양 지정(문제 1 소괄호, 문제 3 이름 붙인 export)을 놓침. 다 쓰면 체크리스트를 한 줄씩 대조
