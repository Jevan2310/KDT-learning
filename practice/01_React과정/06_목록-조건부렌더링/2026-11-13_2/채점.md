### 문제 3
1. `&&`: 조건이 참일 때만 **한 조각을 보이거나 숨길 때** (예: 출석한 학생 옆에만 "출석" 배지). 삼항: 조건에 따라 **A 아니면 B** 둘 중 하나를 보일 때 (예: 참석이면 사탕, 불참이면 벌점)
2. 배열이 비면 `map()` 결과도 비어 화면에 아무것도 안 나온다. 사용자는 데이터가 없는 건지 화면이 고장 난 건지 알 수 없다 → "아직 없습니다"처럼 **데이터가 없다는 걸 알려 준다**

## 모범 답안 — 문제 4

제출 코드(사본: 이 폴더의 `App.jsx`, `components/MemberList.jsx`)도 정답이다. 강의처럼 소괄호 map과 `return ( )`로 쓴 모양:

```jsx
// src/components/MemberList.jsx
const members = [
  { id: 1, name: "한코딩", isLearning: false, stars: 3 },
  { id: 2, name: "파이썬", isLearning: true, stars: 0 },
  { id: 3, name: "자바", isLearning: false, stars: 1 },
  { id: 4, name: "리액트", isLearning: true, stars: 5 },
];

function MemberList() {
  const learningMembers = members.filter((member) => member.isLearning);

  return (
    <section>
      <h2>전체 {members.length}명</h2>
      <ul>
        {members.map((member) => (
          <li key={member.id}>
            {member.name} - {member.isLearning ? "학습 중" : "학습 예정"} {member.stars > 0 && "★" + member.stars}
          </li>
        ))}
      </ul>

      <h2>학습 중 {learningMembers.length}명</h2>
      {learningMembers.length === 0 ? (
        <p>학습 중인 사람이 없습니다.</p>
      ) : (
        <ul>
          {learningMembers.map((member) => (
            <li key={member.id}>{member.name}</li>
          ))}
        </ul>
      )}
    </section>
  );
}

export default MemberList;
```
