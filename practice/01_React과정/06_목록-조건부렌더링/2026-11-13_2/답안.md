## 문제 1 (코드 읽기)

화면에 보이는 것을 표에 쓰세요. ③은 세 줄을 다 쓰고, 이유는 파이썬과 자바 줄만 쓰면 돼요. 띄어쓰기는 신경 쓰지 않아도 돼요.
```jsx
const members = [
  { id: 1, name: "한코딩", isLearning: true, stars: 3 },
  { id: 2, name: "파이썬", isLearning: false, stars: 0 },
  { id: 3, name: "자바", isLearning: "false", stars: 5 },
];

function Member({ name, isLearning, stars }) {
  return (
    <li>
      {name} {isLearning && <span>[학습 중]</span>} {stars && <span>★{stars}</span>}
    </li>
  );
}

function App() {
  const learning = members.filter((member) => member.isLearning);
  const waiting = members.filter((member) => {
    member.isLearning === false;
  });

  return (
    <div>
      <p>학습 중 {learning.length}명</p>
      {waiting.length === 0 ? <p>대기 없음</p> : <p>대기 {waiting.length}명</p>}
      <ul>
        {members.map((member) => (
          <Member key={member.id} name={member.name} isLearning={member.isLearning} stars={member.stars} />
        ))}
      </ul>
    </div>
  );
}
```

| 번호 | 화면에 보이는 것 | 이유 |
|---|---|---|
| ① 첫 번째 `<p>` | 학습 중 3명 | 배열의 길이 3을 그대로 받아옴.|
| ② 두 번째 줄 | 대기 없음 | 화살표 함수에서 중괄호가 나왔으니 return이 필요한데, 없어서 waiting 배열에 아무것도 안들어가짐|
| ③ `<ul>` 3줄 | (파이썬·자바 줄만) 파이썬 0 / 자바 [학습 중] ★5 |  파이썬은 &&조건으로 학습중, 별점은 스타수와 직접 비교되기때문에 0이 나옴, 자바는 문자열이 true로 읽히면서 학습중 출력됨

## 문제 2 (버그 찾기)
문제 2 (버그 찾기)

완료하지 않은(done이 거짓인) 할 일만 개수와 목록으로 보여 주려는 코드예요.
- 남은 할 일이 없으면 안내 문구를 보여 줘요.
- "오늘도 화이팅!"은 남은 할 일이 있을 때만 보여요. 없을 때는 다른 글자도 보이면 안 돼요.

버그는 4개예요. 코드를 답안.md에 붙여 넣고 표에 쓰세요. 줄 번호는 답안.md 기준이에요.
```jsx
const tasks = [
  { id: 1, title: "React 복습", done: true },
  { id: 2, title: "filter 연습", done: "false" },
  { id: 3, title: "CSS 복습", done: false },
];

function App() {
  const leftTasks = tasks.filter((task) => task.done);

  return (
    <div>
      <h2>남은 할 일 {leftTasks.length}개</h2>
      {leftTasks.length === 0 ? (
        <p>남은 할 일이 없습니다.</p>
      ) : (
        <ul>
          {tasks.map((task) => (
            <li key={task.id}>{task.title}</li>
          ))}
        </ul>
      )}
      {leftTasks.length && <p>오늘도 화이팅!</p>}
    </div>
  );
}


export default App;
```

| 줄 | 틀린부분 | 고친코드 | 이유 |
|---|---|---|---|
| 56 | { id: 2, title: "filter 연습", done: "false" } | { id: 2, title: "filter 연습", done: false } | 불린값이 "false"이면 문자열로 읽히고 안에 값이 있어서 true 읽힘|
| 61 | const leftTasks = tasks.filter((task) => task.done); | const leftTasks = tasks.filter((task) => !task.done); | 남은 작업은 done이 false여야해서 앞에 부정어 !를 추가|
| 70 | tasks.map((task));| leftTasks.map((task)) |남은 업무만 남기려면 doen 값이 false인것만 보여줘야함. leftTasks에 false인 것들 넣어뒀으니 leftTasks로 변경|
| 75 | {leftTasks.length && <p>오늘도 화이팅!</p>} | {leftTasks.length > 0 && <p>오늘도 화이팅!</p>} |
숫자가 있으면 false일때 0이 출력됨. 따라서 조건 값을 불린으로 바꿔주는게 깔끔함.|







## 문제 3 (설명하기)

내 말로 써 주세요.
1. &&와 삼항 연산자(? :)는 각각 언제 쓰나요? 고르는 기준을 쓰고, 상황 예를 하나씩 드세요. 오늘 코드 말고 직접 생각한 예로요.
- &&은 조건이 참일때만 보이기. 여러 학생이 있는데 오늘 수업에 참여한 학생만 구분할때
- 조건 ? a:b 조건이 참일때 a 거짓일때 b만 보여줘 상황에 따라 사용할때. 한 학생이 수업에 참석했으면 사탕 불참했으면 벌점을 줄때
2. 목록이 비었을 때 안내 문구를 왜 보여 줘야 하나요? 안내가 없으면 사용자에게 화면이 어떻게 보이는지도 함께 쓰세요.
- 빈목록은 화면에 아무것도 안나와서 화면에 문제가 있는지 확인할수 없음. 따라서 오류 관리를 위해 사용.
