"서버를 배운다면서 왜 터미널 프로그램이지?" 싶을 수 있어요. 오늘 프로그램이 하는 일이 서버가 하는 일과 **모양이 똑같기** 때문이에요.

| 오늘 (콘솔 프로그램) | 03부터 (서버) |
|---|---|
| 터미널에서 입력 받기 | 브라우저가 보낸 요청 받기 |

그리고 오늘 처음으로 **npm 프로젝트**를 만들고 **패키지를 설치**해요. 01에서 "npm은 장보기 + 메모 담당, 메모지(`package.json`)는 02에서 만든다"고 했던 그 부분이에요.

> 💬 **쉽게 말하면** — 오늘은 식당 문 열기 전 **주방 리허설**이에요. 아직 손님이 없으니 내가 직접 주문서를 써서(터미널 입력) 주방에 넣고, 나온 요리(출력)도 내가 받아 봐요. "주문 받기 → 확인 → 요리 → 내주기" 순서를 몸에 익혀 두면, 03에서 진짜 손님(브라우저)이 와도 같은 순서로 일하면 돼요.

**팀 프로젝트에서**: 팀 프로젝트(실시간 채팅)의 백엔드가 Node.js예요. 오늘 배우는 `npm install`, `require`, 입력 검사, 함수로 나누기가 그대로 쓰여요.

### 파이썬으로 보면 거의 아는 내용이에요

| 하고 싶은 것 | 파이썬 | 오늘 쓰는 JavaScript |
|---|---|---|
| 패키지 설치 | `pip install 이름` | `npm install 이름` |
| 가져오기 | `import 이름` | `const 이름 = require("이름");` |
| 입력 받기 | `input("이름: ")` | `readline.question("이름: ")` |
| 양끝 공백 지우기 | `.strip()` | `.trim()` |
| 무한 반복 / 빠져나가기 / 건너뛰기 | `while True:` / `break` / `continue` | `while (true) { }` / `break` / `continue` |
| 리스트 끝에 추가 | `a.append(x)` | `a.push(x)` |
| 위치로 지우기 | `del a[i]` | `a.splice(i, 1)` |
| 개수 | `len(a)` | `a.length` |
| 번호 붙여 출력 | `for i in range(len(a)):` + `f"{i + 1}번: {a[i]}"` | `for (let i = 0; i < a.length; i++)` + `` `${i + 1}번: ${a[i]}` `` |

**다른 점 3개만 조심하면 돼요** (② ⑤에서 직접 봐요)

| 코드 | 파이썬 | JavaScript |
|---|---|---|
| `"20" + 1` | 오류 | `"201"` (글자를 이어 붙임) |
| 숫자로 못 바꾸는 글자 | `int("스물")` → 오류로 멈춤 | `Number("스물")` → `NaN`, **오류 없이 계속 진행** |
| `"20" == 20` | `False` | `==`는 `true`, `===`는 `false` |

파이썬의 `==`는 JavaScript의 `===`와 비슷해요.

오늘 볼 개념 5묶음 (예시 파일 3개)
- ① npm 프로젝트 준비 — `package.json`, `npm install`, `require()`

- ③ 메뉴 반복 — `while (true)`, `break`, `continue` → `menu.js`
- ④ 학생 목록 관리 + 함수로 나누기 → `students.js` (강의 최종 코드)

## 🛠 시작하기 — 연습장을 npm 프로젝트로 만들기

01에서 만든 `_node연습장`을 그대로 써요. VS Code로 그 폴더를 열고 터미널(`` Ctrl + ` ``)에서 해요.

**1. 강의 명령을 먼저 쳐 봐요**
```bash
npm init -y
```
```text
npm error Invalid name: "_node연습장"
```
오류가 나고 아무것도 만들어지지 않아요. `npm init -y`는 **폴더 이름을 프로젝트 이름으로** 쓰는데, npm 프로젝트 이름에는 한글을 쓸 수 없고 `_`로 시작할 수도 없어요. 강의 폴더 `student-manager`는 영어 소문자라 괜찮았던 거예요.

**2. 그래서 메모지(`package.json`)를 직접 만들어요**
- VS Code 왼쪽 목록에서 새 파일 `package.json`을 만들고 아래를 붙여 넣고 저장해요.
```json
{
  "name": "node-practice",
  "version": "1.0.0"
}
```

**3. 패키지 설치 (처음 한 번만)**
```bash
npm install readline-sync
```
끝나면 폴더가 이렇게 돼요.
```text
_node연습장
├─ node_modules/        ← 설치된 패키지 실제 파일 (GitHub에는 안 올라가요)
├─ package.json         ← 프로젝트 이름 + 설치한 패키지 목록
├─ package-lock.json    ← 설치한 정확한 버전 기록 (직접 고치지 않아요)
├─ hello.js, tasks.js, request-flow.js, browser-only.js   ← 01에서 만든 파일
└─ (오늘 만들 파일) ask.js, menu.js, students.js
```
`package.json`을 열어 보면 `"dependencies"`에 `"readline-sync"`가 추가돼 있어요. npm이 메모지에 "이거 샀음"이라고 적어 둔 거예요.

**기억할 것**
- `npm install`은 **처음 한 번**이에요. 실행은 매번 `node 파일이름.js`예요.
- 입력은 VS Code 아래쪽 **TERMINAL** 탭에서 해요. OUTPUT 탭이나 ▶ 실행 버튼 확장에서는 입력을 못 받아요.
- 프로그램을 강제로 끝낼 때는 `Ctrl + C`예요.

## ① npm 프로젝트 준비 — `package.json`, `npm install`, `require()`

**🧭 맥락**: 입력을 받는 기능을 직접 만들면 코드가 길어요. 그래서 남이 만들어 둔 **패키지**(코드 묶음) `readline-sync`를 가져다 써요. 패키지를 쓰려면 "메모지 만들기 → 장보기 → 꺼내 쓰기" 3단계가 필요해요. 03에서 서버를 만들 때 쓰는 `express`도 같은 3단계로 가져와요.

| 단계 | 명령·코드 | 하는 일 |
|---|---|---|
| 메모지 만들기 | `npm init -y` (오늘은 직접 만듦) | `package.json` 생성 |
| 장보기 | `npm install readline-sync` | `node_modules/`에 내려받고 `package.json`에 기록 |
| 꺼내 쓰기 | `const readline = require("readline-sync");` | 코드에서 가져와 `readline`이라는 이름으로 쓰기 |

- `readline`은 **내가 정한 변수 이름**이에요. 파이썬의 `import readline_sync as readline`과 같아요.
- React에서 쓴 `import … from …`도 가져오는 방법이에요. 이번 Node 코드는 `require()`를 써요. 둘을 한 프로젝트에 섞으면 오류가 나요 (아래 AI 표).

> 💬 **쉽게 말하면** — `package.json`은 냉장고에 붙인 **장보기 목록**, `node_modules`는 사 온 재료가 든 **냉장고**예요. 재료는 무거워서 GitHub로 보내지 않고 목록(`package.json`)만 보내요. 받은 사람은 목록을 보고 `npm install`로 다시 장을 봐요.

**팀 프로젝트에서**: 팀원 코드를 받으면 `node_modules`가 없어요. 폴더에서 `npm install`(이름 없이)을 치면 `package.json` 목록대로 한 번에 설치돼요. React 연습장을 처음 만들 때 친 `npm install`도 이거였어요. 백엔드에 필요한 `express`나 실시간 채팅용 패키지도 `npm install 이름`으로 넣어요.

## ② 입력 받기 — 입력은 언제나 문자열

**🧭 맥락**: 01까지 값은 코드에 박혀 있었어요 (`const userName = "한코딩";`). 이제 실행 중에 사람이 넣어요. 08에서 입력창 값 `event.target.value`도 늘 문자열이었죠? 터미널 입력도 똑같아요. 03부터는 이 "입력" 자리에 브라우저가 보낸 요청이 들어와요.

```javascript
const name = readline.question("이름: ");
```
- 질문을 찍고, **Enter를 칠 때까지 멈춰서 기다렸다가**, 입력한 글자를 **문자열**로 돌려줘요. 파이썬 `input()`과 같아요.
- 앞뒤 공백은 `.trim()`으로 지워요: `readline.question("이름: ").trim()`
- 숫자로 계산하려면 `Number()`로 바꿔요. 숫자로 못 바꾸는 글자는 오류 대신 `NaN`(Not a Number, "숫자 아님")이 돼요.
- 비교할 때는 `===` + 문자열로 해요: `cmd === "1"`. `==`는 자료형을 알아서 맞춰 줘서 `"1" == 1`도 참이지만, 헷갈리지 않게 `===`를 써요.

> 💬 **쉽게 말하면** — 입력은 늘 **글자 카드**로 들어와요. "20"이라고 쳐도 숫자 20이 아니라 '2'와 '0'이 적힌 카드예요. 카드에 1을 더하면 카드 뒤에 '1'을 이어 붙여서 "201"이 돼요. 계산하려면 `Number()`로 카드를 숫자로 바꿔야 해요. 카드에 "스물"이라고 적혀 있으면 숫자로 못 바꿔서 `NaN`이 돼요.

### ▶ 붙여 넣어 보기 — `ask.js`
```javascript
// ask.js — 실행 중에 입력을 받아요. 입력 결과는 언제나 "문자열"이에요.
const readline = require("readline-sync");

const name = readline.question("이름: ").trim();
const age = readline.question("나이: ");

console.log(`${name}님, 반가워요!`);
console.log("age + 1         →", age + 1);
console.log("Number(age) + 1 →", Number(age) + 1);
console.log('age == 20       →', age == 20);
console.log('age === 20      →', age === 20);
console.log('age === "20"    →', age === "20");
```
```bash
node ask.js
```
이름에 `  한코딩  `(앞뒤에 공백), 나이에 `20`을 넣으면:
```text
이름:   한코딩  
나이: 20
한코딩님, 반가워요!
age + 1         → 201
Number(age) + 1 → 21
age == 20       → true
age === 20      → false
age === "20"    → true
```

**해 볼 것**
1. `한코딩님`에 공백이 없어요. `.trim()`이 지웠어요.
2. `age + 1`은 `201`, `Number(age) + 1`은 `21`이에요. 터미널에서 잘 보면 `21`과 `true`·`false`는 **노란색**, `201`은 흰색이에요. Node는 숫자와 참·거짓을 색으로 구분해 보여 줘요. 노란색이 아니면 문자열이라는 뜻이에요.
3. `age === 20`은 `false`, `age === "20"`은 `true`예요. 입력이 문자열이라서예요.
4. 다시 실행해서 나이에 `스물`을 넣어 보세요. `Number(age) + 1 → NaN`이 나오고, 프로그램은 **멈추지 않고 끝까지** 가요. 파이썬이면 `int("스물")`에서 오류로 멈췄을 거예요. JavaScript는 조용히 넘어가서 ⑤에서 문제가 돼요.

## ③ 메뉴 반복 — `while (true)`, `break`, `continue`

**🧭 맥락**: 01의 `hello.js`는 두 줄 찍고 바로 끝났어요. 서버는 **끄기 전까지 계속 켜져서** 요청을 기다려야 해요. 오늘은 그 첫걸음으로 0을 누를 때까지 안 끝나는 메뉴를 만들어요. 파이썬 `while True:`와 같아요.

| 코드 | 하는 일 |
|---|---|
| `while (true) { … }` | `true`는 항상 참이라 `{ }` 안을 끝없이 반복 |
| `if / else if / else` | 입력한 메뉴에 맞는 일만 실행 |
| `break` | **반복문 밖으로** 나가기 (뒤에 코드가 없으면 프로그램 끝) |
| `continue` | **이번 바퀴만** 여기서 끝내고 다시 메뉴로 |

> 💬 **쉽게 말하면** — `while (true)`는 **회전문**이에요. 계속 돌다가 `break`를 만나야 밖으로 나가요. `continue`는 "이번 바퀴는 여기까지, 처음(메뉴)으로" 버튼이에요. `break`를 빼먹으면 회전문에서 못 나와요. 그때는 `Ctrl + C`로 강제로 멈춰요.

### ▶ 붙여 넣어 보기 — `menu.js`
```javascript
// menu.js — 0을 누를 때까지 메뉴를 계속 보여 주는 반복 (while + break + continue)
const readline = require("readline-sync");

let count = 0;

while (true) {
  console.log("\n[메뉴] 1. 인사하기  2. 횟수 보기  0. 종료");
  const cmd = readline.question("선택: ").trim();

  if (cmd === "1") {
    if (count === 3) {
      console.log("인사는 세 번까지만 해요.");
      continue; // 아래 코드를 건너뛰고 다시 메뉴로
    }
    count++;
    console.log(`안녕하세요! (${count}번째 인사)`);
  } else if (cmd === "2") {
    console.log(`지금까지 ${count}번 인사했어요.`);
  } else if (cmd === "0") {
    console.log("프로그램을 종료합니다.");
    break; // 반복문 밖으로 나가기
  } else {
    console.log("0, 1, 2 중에서 골라 주세요.");
  }
}

console.log("반복문 밖으로 나왔어요. 여기서 프로그램이 끝나요.");
```
```bash
node menu.js
```
`1` → `1` → `1` → `1` → `2` → `abc` → `0` 순서로 넣으면:
```text
선택: 1
안녕하세요! (1번째 인사)
…
선택: 1
안녕하세요! (3번째 인사)

[메뉴] 1. 인사하기  2. 횟수 보기  0. 종료
선택: 1
인사는 세 번까지만 해요.

[메뉴] 1. 인사하기  2. 횟수 보기  0. 종료
선택: 2
지금까지 3번 인사했어요.

[메뉴] 1. 인사하기  2. 횟수 보기  0. 종료
선택: abc
0, 1, 2 중에서 골라 주세요.

[메뉴] 1. 인사하기  2. 횟수 보기  0. 종료
선택: 0
프로그램을 종료합니다.
반복문 밖으로 나왔어요. 여기서 프로그램이 끝나요.
```

**해 볼 것**
1. 네 번째 `1`은 `continue`를 만나서 인사를 건너뛰고 바로 메뉴로 돌아가요.
2. **바꿔 보기 — `break` 빼기**: `break;` 줄 앞에 `//`를 붙이고 저장 → 다시 실행 → `0`을 눌러도 "프로그램을 종료합니다."만 찍히고 메뉴가 또 나와요. `Ctrl + C`로 멈추고 `//`를 지워 되돌려요.
3. **바꿔 보기 — 숫자와 비교**: `cmd === "1"`을 `cmd === 1`(따옴표 없이)로 바꾸고 실행 → `1`을 눌러도 "0, 1, 2 중에서 골라 주세요."가 나와요. 입력은 문자열 `"1"`이라서 숫자 `1`과 `===`로 같지 않아요. 되돌려요.
4. **바꿔 보기 — 팀원 코드를 처음 받은 상황**: VS Code 왼쪽 목록에서 `node_modules` 폴더를 우클릭 → **Delete**. `node menu.js` → `Error: Cannot find module 'readline-sync'`. 이제 `npm install`(이름 없이)을 치면 `package.json` 목록을 보고 다시 설치해요. `node menu.js`가 다시 돼요.

## ④ 학생 목록 관리 + 함수로 나누기

**🧭 맥락**: 01 `request-flow.js`에서 백엔드 함수가 하던 "목록 보기, 추가"를 이번엔 진짜 입력으로 해요. 삭제도 생겨요. 그리고 08 React와 배열 다루는 방식이 다르니 비교해 봐요.

| 하는 일 | 오늘 (일반 배열) | 08 React (state 배열) |
|---|---|---|
| 추가 | `students.push(name)` | `setTasks((prev) => [...prev, newTask])` |
| 목록 | `for` + `` `${i + 1}번: ${students[i]}` `` | `tasks.map((task) => <li key={task.id}>…)` |
| 삭제 | `students.splice(index, 1)` | `setTasks((prev) => prev.filter((task) => task.id !== id))` |

- **오늘은 원본을 직접 바꿔요** (`push`, `splice`). React state가 아니라 그냥 배열이라 괜찮아요. React가 화면을 다시 그려야 하는 상황이 아니니까요. 03·04의 서버 코드도 이렇게 해요.
- **`const` 배열인데 `push`가 돼요?** `const`는 "다른 배열로 **바꿔 끼우기**"(`students = []`)만 막아요. 배열 안의 내용은 바뀌어요.
- **번호 ↔ 인덱스**: 화면 번호는 1부터, 배열 인덱스는 0부터예요. 출력할 때 `i + 1`, 지울 때 `번호 - 1`.
- **지우면 뒤 번호가 당겨져요.** 2번을 지우면 3번이 2번이 돼요. 번호는 "지금 몇 번째"일 뿐 그 학생의 고유한 이름표가 아니에요. 그래서 08 할 일 앱은 번호 대신 바뀌지 않는 `id`로 지웠어요. 서버·DB에서도 데이터마다 바뀌지 않는 `id`를 둬요.

**함수로 나누기** — 강의 최종 코드는 기능마다 함수를 만들었어요.

| 함수 | 하는 일 |
|---|---|
| `printMenu()` | 메뉴 출력 |
| `createStudent()` | 등록 (3명까지) |
| `printStudents()` | 목록 출력 |
| `deleteStudent()` | 번호로 삭제 |
| 맨 아래 `while` (강사 주석: "controller") | 입력을 받아 **알맞은 함수를 부르기만** 함 |

- 함수 안에서 중간에 끝낼 때는 `continue` 대신 `return`을 써요 (`continue`는 반복문 안에서만 써요).

> 💬 **쉽게 말하면** — 함수로 나누기 전(강의 최종 코드 ①)은 직원 한 명이 주문 받고, 요리하고, 서빙까지 다 하는 가게예요. 나눈 뒤(최종 코드 ②)는 카운터 직원(`while`)이 "등록이요!" 하면 등록 담당(`createStudent`)을 부르는 가게예요. 03의 서버도 이 모양이에요. "이 주소로 요청이 오면 이 함수"라고 적어 둬요.

### ▶ 붙여 넣어 보기 — `students.js` (강의 최종 코드 ②)
```javascript
const readline = require("readline-sync");

// 세 명이 등록 가능한 배열이 필요하다.
const students = [];

console.log("=== 학생 관리 프로그램 ===");

let count = 0;

// 프로그램 메뉴 출력
function printMenu() {
    console.log("1. 학생 등록");
    console.log("2. 학생 목록");
    console.log("3. 학생 삭제");
    console.log("0. 프로그램 종료");
}

// 학생 등록
function createStudent() {
    if (count == 3) {
        console.log("더 이상 학생을 등록할 수 없습니다.");
        return;
    }

    const name = readline.question("input name:");
    students.push(name);

    count++;

    console.log("학생 등록이 완료되었습니다.");
}

// 학생 목록 출력
function printStudents() {
    // 학생이 한 명도 등록되어 있지 않은 경우
    if (count == 0) {
        console.log("등록된 학생이 존재하지 않습니다.");
        return;
    }

    for (let i = 0; i < students.length; i++) {
        console.log(`${i + 1}번: ${students[i]}`)
    }

}

// 학생 삭제
function deleteStudent() {
    if (count == 0) {
        console.log("등록된 학생이 존재하지 않습니다.");
        return;
    }

    // 사람 눈에 보이는 숫자
    // 1. -> 0
    // 2. -> 1
    // 3. -> 2
    const deleteNo = readline.question("delete Student No: ");
    const deleteIdx = Number(deleteNo) - 1; // 입력 받은 번호에서 1을 뺌으로써 삭제할 학생의 인덱스를 구한다.

    if (deleteNo > count || deleteNo < 0) {
        console.log("해당 학생은 존재하지 않습니다.");
        return;
    } else {
        students.splice(deleteIdx, 1);
        console.log(`${deleteNo}번째 학생을 삭제했습니다.`);
        count--;
    }

}










// controller 컨트롤을 하는 역할
while (true) {
    printMenu();
    const cmd = readline.question("command: ");

    if (cmd == 1) {
        createStudent();
    } else if (cmd == 2) {
        printStudents();
    } else if (cmd == 3) {
        deleteStudent();
    } else if (cmd == 0) {
        console.log("프로그램을 종료합니다.");
        break;
    } else {
        console.log("해당 명령어는 존재하지 않습니다.");
    }

}
```
```bash
node students.js
```

**해 볼 것**
1. `1` → 이름 입력을 세 번 해서 3명 등록 → 한 번 더 `1` → "더 이상 학생을 등록할 수 없습니다."
2. `2` → `1번: …`, `2번: …`, `3번: …`
3. `3` → `2` → "2번째 학생을 삭제했습니다." → `2` → 원래 3번 학생이 **2번**이 돼 있어요.
4. `0`으로 끝내고 `node students.js`를 다시 실행 → `2` → "등록된 학생이 존재하지 않습니다." 목록은 프로그램 메모리에만 있어서 끄면 사라져요. 01 ②의 "서버 배열은 재시작하면 초기화"와 같은 이야기예요.

## ⑤ 입력값 검사 — 강의 코드의 구멍 찾고 막기

**🧭 맥락**: 01 ③에서 "입력값은 서버에서도 검사해요, 진짜 문지기는 서버"라고 했죠. 그런데 강의 최종 코드에 **검사 구멍**이 있어요. 직접 뚫어 보고 막아 봐요. AI가 짠 서버 코드를 볼 때도 "이상한 값을 넣으면 어떻게 되지?"를 이 눈으로 봐요.

### ▶ 바꿔 보기 1 — 구멍 뚫어 보기
`students.js` 그대로 실행해서, 학생 3명(가, 나, 다)을 등록한 뒤 아래를 하나씩 넣어 봐요. 매번 `0`으로 끄고 다시 실행해요.

| 이렇게 넣으면 | 결과 | 왜 |
|---|---|---|
| 등록에서 이름 없이 Enter | `1번: ` 빈 학생이 등록됨 | 빈 이름 검사가 없어요 |
| 삭제 번호 `0` | "0번째 학생을 삭제했습니다." → **마지막 학생(다)**이 지워짐 | `0 - 1 = -1`. `splice(-1, 1)`은 끝에서 첫 번째를 지워요 |
| 삭제 번호 없이 Enter | "번째 학생을 삭제했습니다." → **마지막 학생**이 지워짐 | `Number("")`는 `0`이라 위와 같아요 |
| 삭제 번호 `abc` | "abc번째 학생을 삭제했습니다." → **첫 학생(가)**이 지워짐 | `NaN`은 무엇과 비교해도 `false`라서 범위 검사를 그냥 통과해요. `splice`는 `NaN`을 `0`으로 처리해요 |
| 삭제 번호 `1.5` | 첫 학생이 지워짐 | 소수도 범위 검사를 통과하고, `splice(0.5, 1)`은 `0`번을 지워요 |

> 💬 **쉽게 말하면** — 원래 문지기는 "3보다 크니? 0보다 작니?" 두 가지만 물어요. 번호표에 "사과"라고 적혀 있으면 "3보다 크지도, 0보다 작지도 않네" 하고 들여보내요. 고친 문지기는 "**정수야? 1 이상이야? 인원수 이하야?**" 세 가지를 다 물어봐요.

### ▶ 바꿔 보기 2 — 구멍 막기
`students.js`에서 `createStudent` 함수와 `deleteStudent` 함수를 각각 **함수 전체**(위의 `// 학생 등록` 주석부터 닫는 `}`까지) 아래 코드로 바꿔요.

```javascript
// 학생 등록 — 빈 이름 검사 추가
function createStudent() {
    if (count == 3) {
        console.log("더 이상 학생을 등록할 수 없습니다.");
        return;
    }

    const name = readline.question("input name:").trim();

    if (name === "") {
        console.log("이름을 입력해주세요.");
        return;
    }

    students.push(name);

    count++;

    console.log("학생 등록이 완료되었습니다.");
}
```

```javascript
// 학생 삭제 — 정수·범위 검사 추가
function deleteStudent() {
    if (count == 0) {
        console.log("등록된 학생이 존재하지 않습니다.");
        return;
    }

    const deleteNo = readline.question("delete Student No: ");
    const number = Number(deleteNo); // "2" → 2, "abc" → NaN

    if (!Number.isInteger(number) || number < 1 || number > count) {
        console.log("해당 학생은 존재하지 않습니다.");
        return;
    }

    const deleteIdx = number - 1; // 목록 번호 → 배열 인덱스
    const deletedName = students[deleteIdx];

    students.splice(deleteIdx, 1);
    console.log(`${deletedName} 학생을 삭제했습니다.`);
    count--;
}
```

바꾼 점:
- 등록: 입력 뒤에 `.trim()`을 붙이고, 빈 문자열이면 안내만 하고 `return`해요.
- 삭제: 먼저 `Number()`로 숫자로 바꾸고, `!Number.isInteger(number)`(정수가 아니면) `||`(또는) `number < 1` `||` `number > count`이면 거절해요. 지운 학생 이름(`deletedName`)도 보여 줘요.

다시 실행해서 같은 값을 넣어 보면:
- 이름 없이 Enter → "이름을 입력해주세요." (목록에 안 들어가요)
- `0`, Enter, `abc`, `1.5`, `4` → 모두 "해당 학생은 존재하지 않습니다." (아무도 안 지워져요)
- `2` → "나 학생을 삭제했습니다."

**팀 프로젝트에서**: 채팅방 번호, 메시지 내용처럼 서버로 들어오는 값마다 "빈 값이면? 숫자가 아니면? 범위 밖이면?"을 검사해요. 화면(React)에서 막아도 서버에서 또 막아요.

## 팀 프로젝트에서 AI가 짠 코드가 이상할 때 볼 곳

| 증상 | 먼저 볼 곳 |
|---|---|
| `npm error Invalid name` (`npm init -y`) | 폴더 이름에 한글·대문자가 있거나 `_`로 시작하나 → 영어 소문자 폴더 이름 쓰기 |
| `Cannot find module 'readline-sync'` (또는 `'express'`) | 그 폴더에서 `npm install` 했나, `node_modules`가 있나 |
| `require is not defined in ES module scope` | `package.json`에 `"type": "module"`이 있나 → `require`와 `import`를 섞지 않기 |
| 입력을 못 받음, `doesn't support interactive reading from TTY` | OUTPUT 탭이나 ▶ 실행 버튼이 아니라 **TERMINAL**에서 `node 파일.js` |
| 메뉴 `1`을 눌러도 반응 없음 | `=== 1`이 아니라 `=== "1"`인가 (입력은 문자열) |
| `0`을 눌러도 안 끝남 | `break`가 있나 (급하면 `Ctrl + C`) |
| 숫자가 `201`처럼 붙어서 나옴 | `Number()`로 바꿨나 |
| 엉뚱한 항목이 지워짐 | 번호 `- 1` 했나, `Number.isInteger`·범위 검사가 있나 |
| 빈 값이 저장됨 | `trim()` 뒤 `=== ""` 검사가 있나 |
| 다시 켜니 목록이 비어 있음 | 정상이에요 (메모리). 남기려면 데이터베이스 |

## 🔁 이어지는 개념
- **01 ② 서버 배열은 재시작하면 초기화** — `students.js`도 끄면 목록이 사라져요.
- **01 ③ 서버에서도 검사** — ⑤에서 직접 해 봤어요.
- **08 ③ 배열 state는 새로 만들어 바꾸기** — 오늘은 일반 배열이라 `push`·`splice`로 직접 바꿔도 돼요.
- **08 ③ `id`로 지우기** (`crypto.randomUUID()`) — 번호는 지울 때마다 바뀌니까요.
- **08 ② `trim()`으로 빈 입력 막기** — 같은 검사를 서버 쪽 코드에서 해요.
- **React 03 JavaScript `for`·`while`·`break`·`continue`** — ([03_JavaScript wiki](../../../../wiki/01_React과정/03_JavaScript.md) 7장)

**02 한 줄 정리**
- 패키지는 메모지(`package.json`) → `npm install 이름` → `require("이름")` 순서로 쓴다. 팀원 코드를 받으면 `npm install`.
- `readline.question()`은 Enter까지 기다렸다가 **문자열**을 준다. 계산은 `Number()`, 비교는 `=== "1"`.
- `while (true)` + `break`(나가기) + `continue`(다시 메뉴로).
- 일반 배열은 `push`·`splice`로 직접 바꿔도 된다 (React state는 안 됨). 번호 = 인덱스 + 1.
- 입력은 믿지 않는다: 빈 값, 숫자 아님(`NaN`), 소수, 범위 밖을 검사한다.

다음은 **03. 서버에서 데이터 보내기** — `express`로 진짜 서버를 켜고, 브라우저 주소창으로 학생 목록(JSON)을 받아 봐요.
